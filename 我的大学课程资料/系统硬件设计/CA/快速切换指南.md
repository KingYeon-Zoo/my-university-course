# ⚡ 快速模式切换指南

> 仿真模式 ⇄ 上板模式 快速切换参考

---

## 🔄 一分钟切换步骤

### 📱 切换到仿真模式

```
1. 打开 SYSTEM_DEF.vh
2. 找到第28行左右
3. 确保这一行被注释:
   // `define FPGA_BOARD
4. 保存文件
5. Vivado: Set Top → RISCV_CPU_tb
6. Run Simulation
```

### 📟 切换到上板模式

```
1. 打开 SYSTEM_DEF.vh
2. 找到第28行左右
3. 取消注释这一行:
   `define FPGA_BOARD
4. 保存文件
5. Vivado: Set Top → RISCV_CPU_Wrapper
6. 添加约束: constraints/RISCV_CPU.xdc
7. Run Synthesis → Implementation → Generate Bitstream
```

## 📋 检查清单

### ✅ 仿真模式检查
- [ ] `FPGA_BOARD` 已注释
- [ ] 顶层 = `RISCV_CPU_tb`
- [ ] 无约束文件（或约束文件被禁用）
- [ ] testbench/IM.dat 存在

### ✅ 上板模式检查
- [ ] `FPGA_BOARD` 已定义
- [ ] 顶层 = `RISCV_CPU_Wrapper`
- [ ] 约束文件已添加
- [ ] `seven_seg_driver.v` 在工程中

---

## 🚨 常见错误速查

| 错误现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 端口未声明 | 宏未定义 | 检查 `FPGA_BOARD` 定义 |
| 找不到模块 | 文件未添加 | 添加 `RISCV_CPU_Wrapper.v` |
| 约束端口不匹配 | 顶层错误 | 确认顶层为 `Wrapper` |
| LED不亮 | 未烧录/未复位 | 重新烧录，按复位按钮 |
