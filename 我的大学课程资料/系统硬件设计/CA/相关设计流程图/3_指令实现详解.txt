═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════
  流程图 1: R-Type 指令执行流程 (寄存器-寄存器运算)
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  示例指令: ADD x3, x1, x2  (x3 = x1 + x2)
  指令格式: 0110011 | x3 | 000 | x1 | x2 | 0000000

  ┌──────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │                                    五级流水线执行时序                                                         │
  └──────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ IF 阶段 (取指)                                                                                               │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. PC → I_Mem[PC]                     读取指令                                                              │
  │  2. IF_Instr = 0x003100B3              取得 ADD x1,x2,x3 指令                                                │
  │  3. PC_Plus_4 = PC + 4                 计算下一条指令地址                                                    │
  │  4. 分支预测: Predict_Taken = 0        R型指令不涉及分支预测                                                 │
  │                                                                                                             │
  │  → IF/ID 寄存器 ← {IF_PC, IF_Instr, Predict_Taken=0}                                                        │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ ID 阶段 (译码)                                                                                               │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 指令字段提取:                                                                                            │
  │     Opcode   = Instr[6:0]   = 0110011  (R-Type)                                                             │
  │     Rd_Addr  = Instr[11:7]  = 00011    (x3)                                                                 │
  │     Funct3   = Instr[14:12] = 000      (ADD)                                                                │
  │     Rs1_Addr = Instr[19:15] = 00001    (x1)                                                                 │
  │     Rs2_Addr = Instr[24:20] = 00010    (x2)                                                                 │
  │     Funct7   = Instr[31:25] = 0000000  (ADD, 非SUB)                                                         │
  │                                                                                                             │
  │  2. Control 单元译码:                                                                                        │
  │     ALU_op = 2'b10        (R-Type运算)                                                                      │
  │     ALU_src1 = 0          (使用 Rs1)                                                                        │
  │     ALU_src2 = 0          (使用 Rs2)                                                                        │
  │     Mem_w = 0             (不写内存)                                                                        │
  │     Mem_r = 0             (不读内存)                                                                        │
  │     Reg_w = 1             (写寄存器)                                                                        │
  │     WB_sel = 2'b00        (写回ALU结果)                                                                     │
  │     Branch = 0            (非分支指令)                                                                      │
  │     Jump = 0              (非跳转指令)                                                                      │
  │                                                                                                             │
  │  3. 寄存器堆读取:                                                                                            │
  │     Rs1_Data = RF[x1]     读取 x1 的值                                                                      │
  │     Rs2_Data = RF[x2]     读取 x2 的值                                                                      │
  │                                                                                                             │
  │  4. 立即数生成:                                                                                              │
  │     Imm = 0               (R型指令不使用立即数)                                                              │
  │                                                                                                             │
  │  5. 冒险检测:                                                                                                │
  │     Hazard_Unit: 检测 Load-Use 冒险 → 无冒险                                                                │
  │                                                                                                             │
  │  → ID/EX 寄存器 ← {控制信号, PC, Rs1_Data, Rs2_Data, Imm, Rs1_Addr, Rs2_Addr, Rd_Addr, Funct3, Funct7}     │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ EX 阶段 (执行)                                                                                               │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 数据前递检测:                                                                                            │
  │     Forwarding_Unit:                                                                                        │
  │       检测 MEM 阶段: MEM_Rd == Rs1? → Forward_A                                                             │
  │       检测 MEM 阶段: MEM_Rd == Rs2? → Forward_B                                                             │
  │       检测 WB 阶段:  WB_Rd == Rs1?  → Forward_A                                                             │
  │       检测 WB 阶段:  WB_Rd == Rs2?  → Forward_B                                                             │
  │                                                                                                             │
  │  2. ALU 操作数选择:                                                                                          │
  │     Src1_Data = (Forward_A==00)? EX_Rs1_Data :                                                              │
  │                 (Forward_A==01)? WB_Data :                                                                  │
  │                 (Forward_A==10)? MEM_ALU_Result : 0                                                         │
  │                                                                                                             │
  │     Src2_Data = (Forward_B==00)? EX_Rs2_Data :                                                              │
  │                 (Forward_B==01)? WB_Data :                                                                  │
  │                 (Forward_B==10)? MEM_ALU_Result : 0                                                         │
  │                                                                                                             │
  │     Src1 = Src1_Data          (ALU_src1=0, 使用Rs1)                                                         │
  │     Src2 = Src2_Data          (ALU_src2=0, 使用Rs2)                                                         │
  │                                                                                                             │
  │  3. ALU_Control 生成控制码:                                                                                  │
  │     根据 ALU_op=10, Funct3=000, Funct7=0000000                                                              │
  │     → ALU_Ctrl_op = 5'b00000  (ADD 操作)                                                                    │
  │                                                                                                             │
  │  4. ALU 执行运算:                                                                                            │
  │     ALU_Result = Src1 + Src2                                                                                │
  │     Zero_Flag = (ALU_Result == 0)? 1 : 0                                                                    │
  │                                                                                                             │
  │  5. 结果选择:                                                                                                │
  │     EX_ALU_Result = ALU_Result  (非分支、非CSR指令)                                                         │
  │                                                                                                             │
  │  → EX/MEM 寄存器 ← {控制信号, ALU_Result, Mem_W_Data, Rd_Addr, PC_Plus_4, Imm}                              │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ MEM 阶段 (访存)                                                                                              │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 内存操作:                                                                                                │
  │     Mem_r = 0  → 不读内存                                                                                   │
  │     Mem_w = 0  → 不写内存                                                                                   │
  │                                                                                                             │
  │  2. 直通:                                                                                                    │
  │     MEM_ALU_Result 保持不变，直接传递                                                                        │
  │                                                                                                             │
  │  → MEM/WB 寄存器 ← {控制信号, ALU_Result, Mem_R_Data=0, Rd_Addr, PC_Plus_4, Imm}                            │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ WB 阶段 (写回)                                                                                               │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 写回数据选择:                                                                                            │
  │     WB_sel = 2'b00                                                                                          │
  │     WB_Data = WB_ALU_Result   (选择 ALU 结果)                                                               │
  │                                                                                                             │
  │  2. 寄存器堆写入:                                                                                            │
  │     if (WB_Reg_w == 1 && WB_Rd_Addr != 0)                                                                   │
  │        RF[WB_Rd_Addr] ← WB_Data                                                                             │
  │                                                                                                             │
  │     结果: RF[x3] = x1 + x2  ✓                                                                               │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  流程图 2: I-Type 算术指令执行流程 (立即数运算)
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  示例指令: ADDI x3, x1, 100  (x3 = x1 + 100)
  指令格式: 0010011 | x3 | 000 | x1 | 000001100100

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ IF 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  同 R-Type                                                                                                  │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ ID 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 指令字段提取:                                                                                            │
  │     Opcode = 0010011  (I-Type ALU)                                                                          │
  │     Rd     = x3                                                                                             │
  │     Funct3 = 000      (ADDI)                                                                                │
  │     Rs1    = x1                                                                                             │
  │     Imm12  = 000001100100  (100)                                                                            │
  │                                                                                                             │
  │  2. Control 单元:                                                                                            │
  │     ALU_op = 2'b11        (I-Type运算)                                                                      │
  │     ALU_src1 = 0          (使用 Rs1)                                                                        │
  │     ALU_src2 = 1          (使用立即数) ★                                                                    │
  │     Reg_w = 1, WB_sel = 00                                                                                  │
  │     Imm_Type = 3'b000     (I-Type)                                                                          │
  │                                                                                                             │
  │  3. 立即数生成:                                                                                              │
  │     ImmGen: 将 Imm12 符号扩展到 32 位                                                                       │
  │     Imm = {20{Instr[31]}, Instr[31:20]}                                                                     │
  │         = 32'h00000064  (100)                                                                               │
  │                                                                                                             │
  │  4. 寄存器读取:                                                                                              │
  │     Rs1_Data = RF[x1]                                                                                       │
  │     Rs2_Data = 不关心  (I型指令不使用Rs2)                                                                   │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ EX 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 数据前递: (同 R-Type)                                                                                    │
  │                                                                                                             │
  │  2. ALU 操作数:                                                                                              │
  │     Src1 = Src1_Data      (前递后的Rs1值)                                                                   │
  │     Src2 = EX_Imm         (立即数 100) ★ ALU_src2=1                                                         │
  │                                                                                                             │
  │  3. ALU_Control:                                                                                            │
  │     ALU_op=11, Funct3=000 → ALU_Ctrl_op = 5'b00000 (ADD)                                                   │
  │                                                                                                             │
  │  4. ALU 运算:                                                                                                │
  │     ALU_Result = Src1 + Src2 = Rs1_Data + 100                                                               │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ MEM & WB 阶段                                                                                                │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  同 R-Type (不访存, 写回 ALU 结果)                                                                          │
  │  结果: RF[x3] = RF[x1] + 100  ✓                                                                             │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  流程图 3: Load 指令执行流程 (I-Type 访存)
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  示例指令: LW x3, 8(x1)  (x3 = Mem[x1 + 8])
  指令格式: 0000011 | x3 | 010 | x1 | 000000001000

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ IF 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  正常取指                                                                                                    │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ ID 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. Control 译码:                                                                                            │
  │     Opcode = 0000011  (I-Type Load)                                                                         │
  │     Funct3 = 010      (LW - 加载字)                                                                         │
  │                                                                                                             │
  │     ALU_op = 2'b00        (地址计算, ADD)                                                                   │
  │     ALU_src2 = 1          (使用立即数作为偏移)                                                              │
  │     Mem_r = 1             (读内存) ★                                                                        │
  │     Mem_w = 0             (不写内存)                                                                        │
  │     Reg_w = 1             (写寄存器)                                                                        │
  │     WB_sel = 2'b10        (写回内存数据) ★                                                                  │
  │                                                                                                             │
  │  2. 立即数生成:                                                                                              │
  │     Imm = sign_extend(Instr[31:20]) = 32'h00000008  (偏移量8)                                               │
  │                                                                                                             │
  │  3. 冒险检测:                                                                                                │
  │     Hazard_Unit: 检测下一条指令是否使用 x3                                                                  │
  │     若存在 Load-Use 冒险 → 停顿流水线                                                                       │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ EX 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 地址计算:                                                                                                │
  │     Src1 = Src1_Data      (x1的值, 基址)                                                                    │
  │     Src2 = EX_Imm         (8, 偏移量)                                                                       │
  │                                                                                                             │
  │  2. ALU 运算:                                                                                                │
  │     ALU_Ctrl_op = 5'b00000  (ADD)                                                                           │
  │     ALU_Result = Src1 + Src2  (内存地址 = x1 + 8)                                                           │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ MEM 阶段                                                                                                     │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 内存读取:                                                                                                │
  │     Mem_r = 1  → 读使能                                                                                     │
  │     Addr = MEM_ALU_Result  (x1 + 8)                                                                         │
  │                                                                                                             │
  │  2. D_Mem 读取:                                                                                              │
  │     读取 32 位字，根据字节地址                                                                              │
  │     Raw_Data = D_Mem[Addr[31:2]]  (字对齐)                                                                  │
  │                                                                                                             │
  │  3. LDU (Load Data Unit) 处理:                                                                              │
  │     根据 Funct3 进行数据处理:                                                                               │
  │       Funct3 = 010 (LW)  → 直接使用 32 位                                                                   │
  │       Funct3 = 000 (LB)  → 字节符号扩展                                                                     │
  │       Funct3 = 001 (LH)  → 半字符号扩展                                                                     │
  │       Funct3 = 100 (LBU) → 字节零扩展                                                                       │
  │       Funct3 = 101 (LHU) → 半字零扩展                                                                       │
  │                                                                                                             │
  │     Mem_R_Data = LDU_Output                                                                                 │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ WB 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 写回数据选择:                                                                                            │
  │     WB_sel = 2'b10                                                                                          │
  │     WB_Data = WB_Mem_R_Data  (内存读取的数据) ★                                                             │
  │                                                                                                             │
  │  2. 寄存器写入:                                                                                              │
  │     RF[x3] ← WB_Data  (从内存加载的值)                                                                      │
  │                                                                                                             │
  │  注意: Load 指令的结果在 MEM 阶段才准备好，可能导致 Load-Use 冒险                                           │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  流程图 4: Store 指令执行流程 (S-Type 访存)
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  示例指令: SW x2, 12(x1)  (Mem[x1 + 12] = x2)
  指令格式: 0100011 | imm[11:5] | 010 | x1 | x2 | imm[4:0]

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ IF 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  正常取指                                                                                                    │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ ID 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. Control 译码:                                                                                            │
  │     Opcode = 0100011  (S-Type)                                                                              │
  │     Funct3 = 010      (SW - 存储字)                                                                         │
  │                                                                                                             │
  │     ALU_op = 2'b00        (地址计算)                                                                        │
  │     ALU_src2 = 1          (使用立即数)                                                                      │
  │     Mem_r = 0             (不读内存)                                                                        │
  │     Mem_w = 1             (写内存) ★                                                                        │
  │     Reg_w = 0             (不写寄存器) ★                                                                    │
  │                                                                                                             │
  │  2. 立即数生成 (S-Type):                                                                                     │
  │     Imm = {20{Instr[31]}, Instr[31:25], Instr[11:7]}                                                        │
  │         = 32'h0000000C  (12)                                                                                │
  │                                                                                                             │
  │  3. 寄存器读取:                                                                                              │
  │     Rs1_Data = RF[x1]  (基址)                                                                               │
  │     Rs2_Data = RF[x2]  (要存储的数据) ★                                                                     │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ EX 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 地址计算:                                                                                                │
  │     Src1 = Src1_Data      (x1, 基址)                                                                        │
  │     Src2 = EX_Imm         (12, 偏移)                                                                        │
  │     ALU_Result = Src1 + Src2  (目标地址)                                                                    │
  │                                                                                                             │
  │  2. 写数据准备:                                                                                              │
  │     EX_Mem_W_Data = Src2_Data  (x2的值，经过前递)                                                           │
  │                                                                                                             │
  │  3. 生成写使能掩码:                                                                                          │
  │     根据 Funct3 和 Addr[1:0] 生成 Mem_W_Strb:                                                               │
  │       SW (Funct3=010) → Strb = 4'b1111  (写4字节)                                                           │
  │       SH (Funct3=001) → Strb = 4'b0011 或 4'b1100  (写2字节)                                                │
  │       SB (Funct3=000) → Strb = 4'b0001/0010/0100/1000  (写1字节)                                            │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ MEM 阶段                                                                                                     │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 内存写入:                                                                                                │
  │     Mem_w = 1  → 写使能                                                                                     │
  │     Addr = MEM_ALU_Result  (x1 + 12)                                                                        │
  │     Data = MEM_Mem_W_Data  (x2的值)                                                                         │
  │     Strb = MEM_Mem_W_Strb  (写使能掩码)                                                                     │
  │                                                                                                             │
  │  2. D_Mem 写入:                                                                                              │
  │     根据 Strb 写入相应字节:                                                                                 │
  │       if Strb[0]: D_Mem[Addr][7:0]   ← Data[7:0]                                                            │
  │       if Strb[1]: D_Mem[Addr][15:8]  ← Data[15:8]                                                           │
  │       if Strb[2]: D_Mem[Addr][23:16] ← Data[23:16]                                                          │
  │       if Strb[3]: D_Mem[Addr][31:24] ← Data[31:24]                                                          │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ WB 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  WB_Reg_w = 0  → 不写寄存器 (Store指令不修改寄存器)                                                         │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘


═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════
  流程图 5: 分支指令执行流程 (B-Type)
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  示例指令: BEQ x1, x2, offset  (if x1 == x2, PC = PC + offset)
  指令格式: 1100011 | imm | 000 | x1 | x2 | imm

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ IF 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 分支预测:                                                                                                │
  │     BHT[PC[5:0]] → Predict (2-bit 饱和计数器)                                                               │
  │     BTB[PC[5:0]] → BTB_PC, BTB_Valid                                                                        │
  │     Predict_Taken = Predict && BTB_Valid                                                                    │
  │                                                                                                             │
  │  2. PC 选择:                                                                                                 │
  │     if (Predict_Taken)                                                                                      │
  │        IF_PC ← BTB_PC  (预测跳转目标)                                                                       │
  │     else                                                                                                    │
  │        IF_PC ← PC + 4  (预测不跳转)                                                                         │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ ID 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. Control 译码:                                                                                            │
  │     Opcode = 1100011  (B-Type)                                                                              │
  │     Funct3 = 000      (BEQ)                                                                                 │
  │                                                                                                             │
  │     ALU_op = 2'b01        (分支比较)                                                                        │
  │     Branch = 1            (分支指令) ★                                                                      │
  │     Reg_w = 0             (不写寄存器)                                                                      │
  │                                                                                                             │
  │  2. 立即数生成 (B-Type):                                                                                     │
  │     Imm = {19{Instr[31]}, Instr[31], Instr[7], Instr[30:25], Instr[11:8], 1'b0}                             │
  │     (B型立即数最低位固定为0，表示偶数地址)                                                                  │
  │                                                                                                             │
  │  3. 传递预测信息:                                                                                            │
  │     ID_Predict_Taken → EX_Predict_Taken                                                                     │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ EX 阶段                                                                                                      │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  1. 分支条件判断 (BPU):                                                                                      │
  │     ALU 执行比较:                                                                                            │
  │       Src1 = Src1_Data  (x1)                                                                                │
  │       Src2 = Src2_Data  (x2)                                                                                │
  │       ALU_Ctrl_op = SUB  (x1 - x2)                                                                          │
  │       Zero_Flag = (ALU_Result == 0)? 1 : 0                                                                  │
  │                                                                                                             │
  │     BPU 根据 Funct3 判断:                                                                                    │
  │       BEQ:  Taken = Zero_Flag                                                                               │
  │       BNE:  Taken = !Zero_Flag                                                                              │
  │       BLT:  Taken = ALU_Result[0]  (有符号小于)                                                             │
  │       BGE:  Taken = ALU_Result[0]  (有符号大于等于)                                                         │
  │       BLTU: Taken = ALU_Result[0]  (无符号小于)                                                             │
  │       BGEU: Taken = ALU_Result[0]  (无符号大于等于)                                                         │
  │                                                                                                             │
  │     Branch_Taken = Taken && EX_Branch                                                                       │
  │                                                                                                             │
  │  2. 计算跳转目标:                                                                                            │
  │     PC_Plus_Imm = EX_PC + EX_Imm  (分支目标地址)                                                            │
  │                                                                                                             │
  │  3. 预测验证:                                                                                                │
  │     比较 Branch_Taken 和 EX_Predict_Taken:                                                                  │
  │                                                                                                             │
  │     情况1: Branch_Taken=1, EX_Predict_Taken=0                                                               │
  │            → 实际跳转但预测不跳转 (预测错误)                                                                │
  │            → PC_sel = 2'd3 (跳转到 EX_ALU_Result)                                                           │
  │            → IF_ID_Flush = 1, ID_EX_Flush_1 = 1 (冲刷错误路径)                                              │
  │                                                                                                             │
  │     情况2: Branch_Taken=0, EX_Predict_Taken=1                                                               │
  │            → 实际不跳转但预测跳转 (预测错误)                                                                │
  │            → PC_sel = 2'd2 (恢复到 EX_PC+4)                                                                 │
  │            → IF_ID_Flush = 1, ID_EX_Flush_1 = 1 (冲刷预测路径)                                              │
  │                                                                                                             │
  │     情况3: Branch_Taken == EX_Predict_Taken                                                                 │
  │            → 预测正确，继续执行                                                                             │
  │                                                                                                             │
  │  4. 更新分支预测表:                                                                                          │
  │     BHT[EX_PC[5:0]] 更新:                                                                                   │
  │       if Branch_Taken: state++  (饱和在11)                                                                  │
  │       else: state--  (饱和在00)                                                                             │
  │                                                                                                             │
  │     if Branch_Taken:                                                                                        │
  │        BTB[EX_PC[5:0]] ← PC_Plus_Imm                                                                        │
  │        BTB_Valid[EX_PC[5:0]] ← 1                                                                            │
  │                                                                                                             │
  │  5. 结果选择:                                                                                                │
  │     EX_ALU_Result = PC_Plus_Imm  (分支目标，用于可能的跳转)                                                 │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼
  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ MEM & WB 阶段                                                                                                │
  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │  分支指令不访存、不写寄存器，仅影响 PC                                                                      │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  │ JAL      │   00   │    0    │    1    │  0   │  0   │  1   │  0   │    1    │ 01 (PC+4)             │
  │ JALR     │   00   │    0    │    1    │  0   │  0   │  1   │  0   │    1    │ 01 (PC+4)             │
  │ LUI      │   xx   │    x    │    x    │  0   │  0   │  1   │  0   │    0    │ 11 (Imm)              │
  │ AUIPC    │   00   │    1    │    1    │  0   │  0   │  1   │  0   │    0    │ 00 (ALU=PC+Imm)       │
  │ CSR      │   xx   │    x    │    x    │  0   │  0   │  1   │  0   │    0    │ 00 (CSR_R_Data)       │
  └──────────┴────────┴─────────┴─────────┴──────┴──────┴──────┴──────┴─────────┴────────────────────────┘

  ALU_op 编码:
    00 - 加法 (Load/Store 地址计算)
    01 - 分支比较
    10 - R-Type (根据 funct3/funct7)
    11 - I-Type ALU (根据 funct3)

  WB_sel 编码:
    00 - ALU_Result
    01 - PC+4
    10 - Mem_R_Data
    11 - Imm

  总结: 指令执行要点
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  1. IF 阶段要点:
     • 所有指令都从 PC 地址取指
     • 分支指令涉及分支预测 (BHT + BTB)
     • PC 更新: 顺序执行、预测跳转、预测错误恢复、实际跳转

  2. ID 阶段要点:
     • 指令译码: 提取 Opcode, Rd, Rs1, Rs2, Funct3, Funct7
     • 控制信号生成: 根据 Opcode 生成所有控制信号
     • 立即数生成: 根据指令类型 (I/S/B/U/J) 生成不同格式的立即数
     • 寄存器读取: 读取 Rs1, Rs2 (可能被前递替换)
     • 冒险检测: 检测 Load-Use 冒险

  3. EX 阶段要点:
     • 数据前递: 从 MEM/WB 阶段获取最新数据
     • ALU 运算: 根据 ALU_Ctrl_op 执行各种运算
     • 分支判断: BPU 判断分支条件，验证预测
     • CSR 操作: 读写控制状态寄存器
     • 结果选择: 根据指令类型选择 ALU/CSR/PC+Imm

  4. MEM 阶段要点:
     • Load: 从内存读取数据，LDU 处理字节/半字扩展
     • Store: 向内存写入数据，根据 Funct3 生成写使能掩码
     • 非访存指令直通

  5. WB 阶段要点:
     • 根据 WB_sel 选择写回数据: ALU/PC+4/Mem/Imm
     • 写入寄存器堆 (Rd != x0 且 Reg_w=1)
     • Store/Branch 指令不写回
