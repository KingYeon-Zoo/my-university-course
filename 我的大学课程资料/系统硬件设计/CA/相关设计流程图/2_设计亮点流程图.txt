  流程图 1: 数据前递机制 (Data Forwarding) - 解决数据冒险
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  场景说明: 当后续指令需要使用前面指令的结果,但该结果尚未写回寄存器堆时,通过旁路直接获取数据

  典型示例指令序列:
    ADD x1, x2, x3    # 在 WB 阶段写 x1
    SUB x4, x1, x5    # 在 EX 阶段需要读 x1

  │    • 源寄存器地址与目标寄存器地址匹配

  流程图 2: Load-Use 冒险检测与停顿机制
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  场景说明: Load 指令的数据在 MEM 阶段才能获得,如果下一条指令在 EX 阶段立即使用该数据,
           即使有前递机制也无法及时获取,必须停顿流水线一个周期

  典型示例指令序列:
    LW  x1, 0(x2)     # Cycle 1: 在 MEM 阶段才能读取数据到 x1
    ADD x3, x1, x4    # Cycle 2: 在 EX 阶段需要 x1,但此时 LW 还在 MEM 阶段

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │                                      Hazard Unit 工作流程                                                        │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

                                              ┌─────────────────┐
                                              │  开始 (ID 阶段)  │
                                              └────────┬────────┘
                                                       │
                                                       ▼
                          ┌────────────────────────────────────────────────────────┐
                          │  获取当前指令 (ID 阶段) 的源寄存器地址                  │
                          │    • ID_Rs1_Addr (来自 Instr[19:15])                   │
                          │    • ID_Rs2_Addr (来自 Instr[24:20])                   │
                          └──────────────────────┬─────────────────────────────────┘
                                                 │
                                                 ▼
                          ┌────────────────────────────────────────────────────────┐
                          │  获取 EX 阶段指令的信息                                 │
                          │    • EX_Rd_Addr  (目标寄存器地址)                       │
                          │    • EX_Mem_r    (是否是 Load 指令)                     │
                          └──────────────────────┬─────────────────────────────────┘
                                                 │
                                                 ▼
                          ┌────────────────────────────────────────────────────────┐
                          │  检测 Load-Use 冒险条件                                 │
                          │                                                        │
                          │  if (EX_Mem_r == 1) &&                                 │
                          │     ((EX_Rd_Addr == ID_Rs1_Addr) ||                    │
                          │      (EX_Rd_Addr == ID_Rs2_Addr))                      │
                          └──────────────────────┬─────────────────────────────────┘
                                                 │
                   ┌─────────────────────────────┴─────────────────────────────────┐
                   │                                                               │
                   ▼ 冒险检测到                                        无冒险 ▼    │
    ┌──────────────────────────────────┐                  ┌──────────────────────────┐
    │  触发流水线停顿                   │                  │  正常运行                 │
    │  ┌────────────────────────────┐  │                  │  ┌────────────────────┐  │
    │  │ 1. IF_ID_w = 0             │  │                  │  │ IF_ID_w = 1        │  │
    │  │    (停止 IF/ID 寄存器更新)  │  │                  │  │ ID_EX_Flush_0 = 0  │  │
    │  │                            │  │                  │  └────────────────────┘  │
    │  │ 2. ID_EX_Flush_0 = 1       │  │                  └──────────┬───────────────┘
    │  │    (冲刷 ID/EX 寄存器,     │  │                             │
    │  │     插入 NOP)              │  │                             │
    │  └────────────────────────────┘  │                             │
    └──────────────┬───────────────────┘                             │
                   │                                                 │
                   └─────────────────────┬───────────────────────────┘
                                         │
                                         ▼
                                   ┌─────────────┐
                                   │    结束      │
                                   └─────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │                                       停顿效果时序图                                                             │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

    无停顿情况 (正常前递可以解决):
    ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
    │Cycle │  1   │  2   │  3   │  4   │  5   │  6   │  7   │
    ├──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┤
    │ADD   │  IF  │  ID  │  EX  │ MEM  │  WB  │      │      │
    │SUB   │      │  IF  │  ID  │  EX  │ MEM  │  WB  │      │
    │AND   │      │      │  IF  │  ID  │  EX  │ MEM  │  WB  │
    └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
                                  ↑
                                  └─ 可以从 MEM 阶段前递数据


    Load-Use 冒险情况 (必须停顿):
    ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
    │Cycle │  1   │  2   │  3   │  4   │  5   │  6   │  7   │  8   │
    ├──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┤
    │LW x1 │  IF  │  ID  │  EX  │ MEM  │  WB  │      │      │      │
    │ADD   │      │  IF  │  ID  │ STALL│  EX  │ MEM  │  WB  │      │
    │      │      │      │      │ (NOP)│      │      │      │      │
    │SUB   │      │      │  IF  │  ID  │  ID  │  EX  │ MEM  │  WB  │
    └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
                            ↑      ↑      ↑
                            │      │      └─ 在 Cycle 5,LW 在 WB,可以前递
                            │      └─ 插入气泡 (NOP)
                            └─ 检测到冒险,停顿 IF 和 ID

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │  停顿机制详解:                                                                                                   │
  │                                                                                                                 │
  │  1. IF_ID_w = 0                                                                                                 │
  │     • IF/ID 流水线寄存器不更新,保持当前指令 (ADD)                                                                 │
  │     • PC_Adder 通过 IF_ID_w 控制,PC 值保持不变                                                                   │
  │                                                                                                                 │
  │  2. ID_EX_Flush_0 = 1                                                                                           │
  │     • 在 ID/EX 流水线寄存器中插入气泡 (NOP)                                                                       │
  │     • 将所有控制信号清零 (Reg_w=0, Mem_w=0, Mem_r=0)                                                             │
  │                                                                                                                 │
  │  3. 下一个周期                                                                                                   │
  │     • LW 进入 WB 阶段,数据可用                                                                                   │
  │     • ADD 重新进入 EX 阶段,此时可以通过前递从 MEM 阶段获取数据                                                     │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  流程图 3: 动态分支预测机制 (BHT + BTB)
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  场景说明: 使用 2-bit 饱和计数器 (BHT) 预测分支方向,结合分支目标缓冲 (BTB) 预测跳转地址,
           减少分支指令导致的流水线停顿

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │                                   分支预测完整流程 (IF 阶段)                                                     │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

                                              ┌─────────────────┐
                                              │  开始 (IF 阶段)  │
                                              │  当前 PC 值      │
                                              └────────┬────────┘
                                                       │
                                                       ▼
                          ┌────────────────────────────────────────────────────────┐
                          │  使用 PC[5:0] 作为索引访问 BHT 和 BTB                   │
                          │    • BHT: 64 项,每项 2-bit 饱和计数器                  │
                          │    • BTB: 64 项,每项存储 32-bit 跳转目标地址            │
                          └──────────────┬─────────────────────────────────────────┘
                                         │
                   ┌─────────────────────┴─────────────────────┐
                   │                                           │
                   ▼                                           ▼
    ┌──────────────────────────────┐           ┌──────────────────────────────┐
    │  BHT 查询                     │           │  BTB 查询                     │
    │  ┌────────────────────────┐  │           │  ┌────────────────────────┐  │
    │  │ 读取 2-bit 计数器       │  │           │  │ 读取目标地址            │  │
    │  │ Counter[1:0]:          │  │           │  │   BTB_PC[31:0]         │  │
    │  │   00 - 强不跳转        │  │           │  │ 检查有效位             │  │
    │  │   01 - 弱不跳转        │  │           │  │   BTB_Valid            │  │
    │  │   10 - 弱跳转          │  │           │  └────────────────────────┘  │
    │  │   11 - 强跳转          │  │           └──────────────┬───────────────┘
    │  └────────────────────────┘  │                          │
    └──────────────┬───────────────┘                          │
                   │                                           │
                   │ Predict                                   │ BTB_PC, BTB_Valid
                   │ = Counter[1]                              │
                   │ (最高位为 1 表示预测跳转)                  │
                   │                                           │
                   └─────────────────┬─────────────────────────┘
                                     │
                                     ▼
                          ┌────────────────────────────────────────────────────────┐
                          │  组合逻辑: 确定是否预测跳转                             │
                          │                                                        │
                          │  Predict_Taken = Predict && BTB_Valid                  │
                          │                                                        │
                          │  只有当 BHT 预测跳转 (Predict=1)                        │
                          │  且 BTB 命中 (BTB_Valid=1) 时,才预测跳转               │
                          └──────────────────────┬─────────────────────────────────┘
                                                 │
                   ┌─────────────────────────────┴─────────────────────────────────┐
                   │                                                               │
                   ▼ Predict_Taken = 1                          Predict_Taken = 0 ▼
    ┌──────────────────────────────┐                  ┌──────────────────────────────┐
    │  预测跳转                     │                  │  预测不跳转                   │
    │  ┌────────────────────────┐  │                  │  ┌────────────────────────┐  │
    │  │ PC_sel = 01            │  │                  │  │ PC_sel = 00            │  │
    │  │ 下一个 PC = BTB_PC     │  │                  │  │ 下一个 PC = PC + 4     │  │
    │  └────────────────────────┘  │                  │  └────────────────────────┘  │
    └──────────────┬───────────────┘                  └──────────────┬───────────────┘
                   │                                                 │
                   └─────────────────────┬───────────────────────────┘
                                         │
                                         ▼
                          ┌────────────────────────────────────────────────────────┐
                          │  IF/ID 寄存器保存预测信息                               │
                          │    • ID_Predict_Taken (传递到 EX 阶段用于验证)         │
                          └──────────────────────┬─────────────────────────────────┘
                                                 │
                                                 ▼
                                          (进入 ID 阶段)


  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │                                BHT 2-bit 饱和计数器状态机                                                        │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

                    ┌──────────────────────────────────────────────┐
                    │                                              ↓
              ┌─────────────┐  Branch_Taken=0   ┌─────────────┐  Branch_Taken=0
              │  00         │ ◄──────────────── │  01         │ ◄────────────────┐
              │  强不跳转    │                   │  弱不跳转    │                  │
              │ (Predict=0) │ ──────────────→   │ (Predict=0) │                  │
              └─────────────┘  Branch_Taken=1   └─────────────┘                  │
                    ↓                                  ↓                          │
                    │ Branch_Taken=1                   │ Branch_Taken=1           │
                    │                                  │                          │
                    ↓                                  ↓                          │
              ┌─────────────┐  Branch_Taken=1   ┌─────────────┐                  │
              │  11         │ ←──────────────── │  10         │                  │
              │  强跳转      │                   │  弱跳转      │                  │
              │ (Predict=1) │ ──────────────→   │ (Predict=1) │ ─────────────────┘
              └─────────────┘  Branch_Taken=0   └─────────────┘  Branch_Taken=0
                    ↑                                  ↑
                    └──────────────────────────────────┘
                                Branch_Taken=1 (跳转)

  说明:
    • 初始状态通常为 10 (弱跳转) 或 01 (弱不跳转)
    • 每次分支实际执行后,根据 Branch_Taken 更新计数器
    • 预测准确时,状态向"强"方向移动
    • 预测错误时,状态向相反方向移动

  │                                  BTB 更新流程 (EX 阶段)                                                          │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

                          │    • Branch_Taken (是否实际跳转)                        │
                          │    • EX_ALU_Result (实际跳转目标地址)                   │
                          └──────────────────────┬─────────────────────────────────┘
                                                 │
                                                 ▼
                          ┌────────────────────────────────────────────────────────┐
                          │  使用 EX_PC[5:0] 作为索引                               │
                          │  更新 BHT 和 BTB                                        │
                          └──────────────────────┬─────────────────────────────────┘
                                                 │
                   ┌─────────────────────────────┴─────────────────────────────────┐
                   │                                                               │
                   ▼                                                               ▼
    ┌──────────────────────────────┐                  ┌──────────────────────────────┐
    │  更新 BHT                     │                  │  更新 BTB                     │
    │  ┌────────────────────────┐  │                  │  ┌────────────────────────┐  │
    │  │ 根据 Branch_Taken      │  │                  │  │ if (Branch_Taken==1)   │  │
    │  │ 更新 2-bit 计数器       │  │                  │  │   BTB[index] ←        │  │
    │  │                        │  │                  │  │   EX_ALU_Result       │  │
    │  │ 例如:                  │  │                  │  │   BTB_Valid ← 1       │  │
    │  │ 10 + Taken → 11        │  │                  │  └────────────────────────┘  │
    │  │ 10 + NotTaken → 01     │  │                  └──────────────────────────────┘
    │  └────────────────────────┘  │
    └──────────────────────────────┘

  说明:
    • BHT 在每次分支指令执行后都会更新
    • BTB 只在实际发生跳转时才更新目标地址
    • 使用 PC 低位索引,避免标签匹配的复杂性

  流程图 4: 分支预测失败恢复机制
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

  场景说明: 当分支预测错误时,需要冲刷错误的指令并恢复到正确的执行路径

  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │                                  预测验证与恢复流程 (EX 阶段)                                                     │
  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

                                              ┌─────────────────┐
                                              │  开始 (EX 阶段)  │
                                              │  分支指令执行     │
                                              └────────┬────────┘
                                                       │
                                                       ▼
                          ┌────────────────────────────────────────────────────────┐
                          │  获取实际分支结果和预测信息                             │
