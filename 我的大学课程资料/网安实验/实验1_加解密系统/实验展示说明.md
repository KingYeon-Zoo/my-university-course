## 4. 密钥输出在哪里

调库版密钥统一在：

```text
keys/
```

查看命令：

```bash
find keys -maxdepth 1 -type f | sort
```

当前密钥文件：

```text
keys/aes_256.key       # AES-256-GCM 对称密钥
keys/rsa_private.pem   # RSA 私钥
keys/rsa_public.pem    # RSA 公钥
keys/sm4.iv            # SM4-CBC 初始化向量文件
keys/sm4.key           # SM4 对称密钥
```

现场不建议直接展示完整密钥内容，可展示密钥文件存在和摘要：

```bash
shasum -a 256 keys/*
```

## 5. 加密文件在哪里

调库版加密文件和解密还原文件统一在：

```text
outputs/
```

每个算法一个目录：

```text
outputs/AES_256_GCM/
outputs/RSA_OAEP_Hybrid/
outputs/SM4_CBC/
```

查看全部输出：

```bash
find outputs -type f | sort
```

文件命名规则：

- `原文件名.enc`：加密后的密文文件。
- `原文件名.restored.原后缀`：解密还原后的文件。

示例：

```text
outputs/AES_256_GCM/文本.txt.enc
outputs/AES_256_GCM/文本.txt.restored.txt
outputs/RSA_OAEP_Hybrid/图片.jpg.enc
outputs/RSA_OAEP_Hybrid/图片.jpg.restored.jpg
outputs/SM4_CBC/视频.mp4.enc
outputs/SM4_CBC/视频.mp4.restored.mp4
```

## 8. 两个版本现场展示顺序

建议先展示调库版，再展示手搓版。

第一步，展示调库版：


讲解重点：

- 输出文件都在 `outputs/`，密钥都在 `keys/`，汇总页面在 `results/dashboard.html`。

第二步，展示手搓版：

```bash

find sample_data -maxdepth 1 -type f | sort
```

讲解重点：
