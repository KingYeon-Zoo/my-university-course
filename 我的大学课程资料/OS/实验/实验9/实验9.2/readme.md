# 概述
Windows 控制台程序 boundary-identification 项目。主要用于实现动态内存分配 - 边界标识法。

本项目实现了边界标识法的完整功能，包括：
- 内存分配和回收
- 空闲块的合并（四种情况）
- 三种分配算法：首次适应、循环首次适应、最佳适应
- 完成了所有练习要求

# 功能特性

## 基本功能
1. **内存分配**：根据所选策略分配指定大小的内存块
2. **内存回收**：回收已分配的内存，自动合并相邻空闲块
3. **内存显示**：查看当前内存的分配和空闲情况
4. **策略选择**：动态切换三种分配算法

## 分配策略

### 1. 首次适应算法 (First Fit)
- 从链表头开始查找第一个满足条件的空闲块
- 优点：实现简单，速度较快
- 缺点：可能在链表前部产生碎片

### 2. 循环首次适应算法 (Next Fit)
- 从上次分配位置开始查找
- 优点：空闲块分布更均匀
- 缺点：平均查找时间可能较长

### 3. 最佳适应算法 (Best Fit)
- 遍历所有空闲块，选择最适合的
- 优点：内存利用率高
- 缺点：查找时间长，可能产生小碎片

## 回收策略
系统会自动检测并合并相邻的空闲块，包括四种情况：
1. 左右邻居都是占用块 → 独立插入链表
2. 只有左邻居是空闲块 → 与左块合并
3. 只有右邻居是空闲块 → 与右块合并
4. 左右邻居都是空闲块 → 三块合并

# 使用方法

## 编译
使用为 Linux 0.11 定制的 VSCode 克隆到本地。  
在 VSCode 的 "Terminal" 菜单中选择 "Run Build Task..."，会在 VSCode 的顶部中间位置弹出一个可以执行的 Task 列表，选择其中的 "生成项目"。  

## 运行
按 Ctrl + F5 运行程序。

## 操作说明

程序启动后会显示主菜单：
```
==================== 边界标识法内存管理系统 ====================
选择功能项：
  0 - 退出程序
  1 - 分配内存
  2 - 回收内存
  3 - 显示内存
  4 - 设置分配策略 (当前: 首次适应)
================================================================
```

### 功能1：分配内存
1. 输入 `1`
2. 输入所需内存大小（正整数）
3. 系统会根据当前策略分配内存并显示结果

### 功能2：回收内存
1. 输入 `2`
2. 输入要回收的内存块首地址（十六进制格式）
   - 地址可从功能3的输出中获取
3. 系统会自动回收并合并相邻空闲块

### 功能3：显示内存
1. 输入 `3`
2. 系统会显示所有空闲块和占用块的信息

### 功能4：设置分配策略
1. 输入 `4`
2. 选择策略编号：
   - `0` - 首次适应算法
   - `1` - 循环首次适应算法
   - `2` - 最佳适应算法
3. 系统会切换到所选策略

# 技术细节

## 数据结构
```c
typedef struct Bound{
    struct Bound * preLink;  // 头部域前驱
    struct Bound * upLink;   // 尾部域，指向结点头部
    int tag;                 // 0表示空闲,1表示占用
    int size;                // 可用空间大小（不包括头尾）
    struct Bound * nextLink; // 头部后继指针
}*Space;
```

## 关键宏定义
```c
#define MAX_SIZE 1000           // 总内存大小
#define ALLOC_MIN_SIZE 10       // 最小分配单位
#define FOOT_LOC(p) ((p)+(p->size)-1)  // 尾部位置
```

# 注意事项

1. **地址格式**：回收内存时输入的地址必须是十六进制格式
2. **策略切换**：建议在内存完全空闲时切换分配策略
3. **边界检查**：系统会自动检查内存边界，防止越界访问
4. **碎片管理**：系统自动合并相邻空闲块，减少碎片
