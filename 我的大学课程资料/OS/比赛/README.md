# BUGOS - 基于MonkeyOS的高性能增强型异步操作系统内核


## 📜 序言与致谢

**BUGOS** 是在 [MonkeyOS](https://gitlab.eduxiji.net/educg-group-32146-2710490/T202510056995244-2537) 基础上深度开发与增强的操作系统内核项目。

我们要特别鸣谢天津大学在 **ByteOS/MonkeyOS** 项目中展现出的卓越开源精神。MonkeyOS 为本项目提供了一个稳定、现代且基于异步并发模型的 Rust 内核基础。BUGOS 在此基础上，通过深度参考 **Linux 5.15.0 内核源码**，在网络协议栈、进程调度算法、内存缓存机制及安全权限模型等方面进行了全方位的工业级加固与功能扩展。

## 🎯 项目愿景

BUGOS 旨在构建一个**“安全、快速、全能”**的国产操作系统内核原型。我们通过 Rust 语言的内存安全性，结合异步（Async/Await）执行模型，解决了传统内核在处理高并发 I/O 时的复杂性问题。同时，我们不断吸收 Linux 内核的优秀设计，使 BUGOS 在兼容 POSIX 标准的同时，具备现代服务器级操作系统的核心特性。

## 🏗️ 系统架构总览

BUGOS 采用了清晰的分层架构，确保了高度的可移植性和模块化：

1.  **用户空间 (User Space)**：通过标准系统调用接口与内核交互，支持编译自 musl 或 glibc 的应用。
2.  **系统调用层 (Syscall Layer)**：提供 100+ 个 POSIX 兼容接口，涵盖进程、文件、网络及系统管理。
3.  **内核核心 (Kernel Core)**：
    *   **异步执行器 (Executor)**：基于协程的任务调度模型。
    *   **任务管理**：支持多线程、多进程模型及复杂的信号机制。
4.  **服务层 (Kernel Services)**：
    *   **网络栈 (Lose-Net-Stack)**：深度增强的 TCP/IP 协议簇。
    *   **文件系统 (VFS)**：支持 Ext4, FAT32, ProcFS 等。
    *   **内存管理**：包含物理页分配、虚拟内存管理及 Page Cache。
5.  **硬件抽象层 (PolyHAL)**：屏蔽底层硬件差异，支持 RISC-V 64 和 LoongArch 64 架构。

## 🚀 核心功能子系统

### 1. 异步任务管理与高级调度

BUGOS 继承了 MonkeyOS 的异步基因，并将其推向了**优先级感知的完全公平调度**。

*   **异步执行引擎**：内核原生支持 `Future`，任务切换开销极低，天然免疫 C10K 级并发压力。
*   **优先级调度器 (Priority Scheduler)**：
    *   **数据结构**：引入了基于 `BinaryHeap` 的优先级队列，确保 $O(1)$ 时间复杂度获取最高优先级任务。
    *   **Nice值支持**：完全兼容 UNIX 的 nice 值（-20 到 19），动态调整任务权重。
    *   **时间片轮转 (RR)**：针对不同优先级任务分配 50ms-200ms 的动态时间片，平衡系统响应性与吞吐量。
*   **多线程支持**：完善的线程组概念，支持 TLS（线程本地存储）和复杂的 Futex 同步原语。

### 2. 工业级网络协议栈

这是 BUGOS 改进最深入的部分，参考 Linux 5.15 实现了准生产级的网络能力。

*   **Socket Buffer (SkBuff) 管理**：
    *   实现了类 Linux 的 `sk_buff` 结构，支持头部空间预留（Headroom）和尾部追加（Tailroom）。
    *   通过 `push/pull` 操作实现跨层协议封装的零拷贝，极大降低了 CPU 负载。
*   **TCP 高级特性**：
    *   **CUBIC 拥塞控制**：实现了 Linux 默认的 CUBIC 算法，包含慢启动、拥塞避免及丢包后的快速收敛。
    *   **SACK (选择性确认)**：通过 RFC 2018 协议实现，在丢包环境下可避免重传已收到的数据，吞吐量提升显著。
*   **IP 路由与分片**：
    *   **LPM 路由表**：基于最长前缀匹配算法的路由查找，支持默认网关和多网卡转发。
    *   **自动分片重组**：完美处理超过 MTU（1500字节）的大数据包，支持分片超时自动清理。
*   **基础协议支持**：
    *   **ICMP**：完整支持 Echo Request/Reply（Ping 功能）。
    *   **IPv6**：预留了 IPv6 头部解析框架，具备下一代互联网协议的扩展能力。

### 3. VFS与高性能文件系统

BUGOS 提供了一个极其灵活且高性能的文件系统抽象层。

*   **VFS (虚拟文件系统)**：统一的 `INodeInterface` 抽象，使得各种文件系统可以无缝挂载。
*   **Page Cache (页缓存)**：
    *   **核心机制**：实现了基于内存的 4KB 页级缓存，彻底终结了“裸读磁盘”的历史。
    *   **替换算法**：内置智能 **LRU (最近最少使用)** 算法，在内存受限时自动置换冷数据。
    *   **写策略**：采用 Write-Through 与定期后台 Write-Back 结合，兼顾数据安全与性能。
*   **多文件系统支持**：
    *   **Ext4**：通过 `lwext4_rust` 提供完整的日志文件系统支持。
    *   **FAT32**：良好的嵌入式设备兼容性。
    *   **ProcFS & DevFS**：提供内核运行状态监控及设备访问接口。

### 4. 现代内存管理子系统

*   **分页管理**：支持多级页表，实现了细粒度的内存保护（读、写、执行权限）。
*   **动态分配**：内核使用 Buddy System (伙伴系统) 进行大块内存管理，Slub 分配器处理小对象。
*   **高级特性**：
    *   **mmap**：支持文件映射与匿名映射，是用户态高性能 I/O 的基石。
    *   **共享内存**：实现了跨进程的内存共享，加速 IPC 通信。
    *   **COW (写时复制)**：在进程 Fork 时利用 COW 机制极大减少内存开销。

### 5. UNIX安全与权限模型

BUGOS 引入了完整的 UNIX 权限体系，从单用户系统进化为多用户安全内核。

*   **进程凭证 (Credentials)**：每个进程 PCB 拥有 6 个核心 ID：`uid`, `gid`, `euid`, `egid`, `suid`, `sgid`。
*   **权限校验引擎**：
    *   实现了 `generic_permission` 函数，严格执行“Root 绕过、Owner 检查、Group 检查、Other 检查”的经典安全逻辑。
    *   **SUID 位处理**：在 `exec` 时自动识别文件 SUID 标志位，实现安全的特权提升（如 passwd 工具）。
*   **系统调用**：完整提供 `getuid`, `setuid`, `geteuid`, `chmod` 等权限管理接口。

## 🛠️ 技术亮点

1.  **Async-Everything**：从驱动到协议栈，从文件 I/O 到任务调度，全链路异步化，榨干多核 CPU 的每一分性能。
2.  **Rust 驱动安全性**：利用 Rust 的所有权与生命周期机制，在内核开发中消除了 90% 以上的缓冲区溢出与空指针崩溃。
3.  **零拷贝设计**：在网络包处理和文件缓存中使用引用计数与 SkBuff 结构，尽量避免内存拷贝。
4.  **Linux 5.15 对标**：不仅仅是实现功能，更是在数据结构和算法细节（如 CUBIC 公式、SACK 块合并）上向 Linux 工业标准看齐。

*   **Rust**: Nightly 2024-08-01+

## 📁 项目结构

BUGOS/
├── kernel/                # 内核核心层
│   ├── src/
│   │   ├── tasks/         # 进程/线程/调度算法/SUID处理
│   │   ├── syscall/       # 100+ POSIX 系统调用实现
│   │   ├── permission.rs  # UNIX 权限检查引擎
│   │   └── main.rs        # 内核启动与初始化入口
├── filesystem/            # 文件系统子系统
│   ├── vfscore/           # VFS 抽象与 Page Cache 核心
│   └── fs/                # 具体 FS 实现 (Ext4, FAT32, RamFS)
├── driver/                # 硬件驱动程序 (VirtIO, UART, PLIC)
├── crates/
│   └── executor/          # 异步执行器与优先级调度逻辑
├── vendor/                # 增强型第三方库
│   ├── lose-net-stack/    # BUGOS 网络协议栈 (SkBuff, CUBIC, SACK)
│   └── lwext4_rust/       # Ext4 适配层
└── All_debug/             # 详细的技术改进报告与调试脚本---
