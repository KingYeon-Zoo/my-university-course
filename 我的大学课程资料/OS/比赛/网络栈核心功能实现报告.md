### 1. **Socket Buffer (sk_buff)** 📦
**参考**: `~/linux-5.15.0/include/linux/skbuff.h` (4800+行)

**实现**: `vendor/lose-net-stack/src/skbuff.rs` (280行)

**功能**:
- ✅ 统一的数据包缓冲结构
- ✅ 头部空间预留 (headroom)
- ✅ 尾部空间管理 (tailroom)
- ✅ push/pull/put/trim 操作
- ✅ 头部偏移记录 (mac/network/transport)
- ✅ 协议类型标记
- ✅ 时间戳支持
- ✅ 零开销克隆

**核心API**:
```rust
pub struct SkBuff {
    data: Vec<u8>,              // 数据缓冲区
    mac_header: Option<u16>,    // MAC头偏移
    network_header: Option<u16>, // 网络层头偏移
    transport_header: Option<u16>, // 传输层头偏移
    protocol: SkbProtocol,      // 协议类型
    tstamp: u64,                // 时间戳
}

impl SkBuff {
    pub fn new(capacity: usize) -> Self;
    pub fn push(&mut self, data: &[u8]) -> &mut [u8];  // 头部添加
    pub fn pull(&mut self, len: usize) -> Option<()>;  // 头部移除
    pub fn put(&mut self, data: &[u8]) -> usize;       // 尾部添加
    pub fn clone(&self) -> Self;                       // 深拷贝
}
```

### 2. **IP路由系统** 🗺️
**参考**: `~/linux-5.15.0/net/ipv4/route.c` (2900+行)

**实现**: `vendor/lose-net-stack/src/route.rs` (246行)

**功能**:
- ✅ 路由表管理
- ✅ 最长前缀匹配（LPM）
- ✅ 默认网关支持
- ✅ 多路由优先级
- ✅ 直连路由 vs 网关路由
- ✅ 路由添加/删除
- ✅ 本地网络自动配置

**核心API**:
```rust
pub struct RoutingTable {
    entries: RwLock<Vec<RouteEntry>>,
}

pub struct RouteEntry {
    destination: Ipv4Addr,      // 目标网络
    netmask: Ipv4Addr,         // 子网掩码
    gateway: Ipv4Addr,         // 网关
    interface: usize,          // 出接口
    metric: u32,               // 优先级
}

impl RoutingTable {
    pub fn lookup(&self, dst: Ipv4Addr) -> Option<(Ipv4Addr, usize, u32)>;
    pub fn add_route(&self, entry: RouteEntry);
    pub fn add_default_gateway(&self, gateway: Ipv4Addr, interface: usize);
}
```

**路由查找算法**:
```
1. 遍历路由表（已按前缀长度排序）
2. 检查 (dst_ip & netmask) == destination
3. 返回第一个匹配的路由（最长前缀）
4. 时间复杂度: O(n)，空间复杂度: O(n)
```

### 3. **IP分片与重组** 🧩
**参考**: `~/linux-5.15.0/net/ipv4/ip_fragment.c` (750+行)

**实现**: `vendor/lose-net-stack/src/ip_fragment.rs` (250行)

**功能**:
- ✅ IP分片发送（MTU > 1500）
- ✅ IP分片重组
- ✅ 分片超时处理（30秒）
- ✅ DF标志支持
- ✅ MF标志处理
- ✅ 8字节对齐分片

**核心API**:
```rust
pub struct IpFragmenter {
    queues: Mutex<HashMap<(Ipv4Addr, Ipv4Addr, u16, u8), FragmentQueue>>,
}

impl IpFragmenter {
    // 添加分片并尝试重组
    pub fn add_fragment(
        &self,
        src_ip: Ipv4Addr,
        dst_ip: Ipv4Addr,
        id: u16,
        protocol: u8,
        offset: u16,
        more_fragments: bool,
        data: &[u8],
        timestamp: u64,
    ) -> Option<Vec<u8>>;
    
    // 清理过期队列
    pub fn cleanup_expired(&self, current_time: u64);
}

// 分片发送
pub fn fragment_ip_payload(
    payload: &[u8],
    mtu: usize,
) -> Vec<(u16, bool, Vec<u8>)>;
```

**分片重组流程**:
```
接收分片 → 存入队列（按offset排序）
    ↓
检查是否收到最后分片（MF=0）
    ↓
是否收齐所有分片？
    ↓
重组为完整数据包 → 返回给上层
```
