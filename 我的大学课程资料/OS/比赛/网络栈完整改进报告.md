## 🔬 技术细节

### CUBIC 算法实现
```rust
// 核心公式: W_cubic(t) = C(t-K)³ + W_max
// - W_max: 上次丢包前的最大窗口
// - K: 从当前窗口增长到 W_max 的时间
// - C: CUBIC 参数（影响增长速度）

pub fn cubic_update(ca: &mut CubicState, cwnd: u32, acked: u32, 
                    current_time: u32, rtt_us: u32) -> u32 {
    // 1. 计算时间 t
    let t = current_time - ca.epoch_start + rtt_us/1000;
    
    // 2. 计算 (t-K)
    let offs = if t < ca.bic_k { ca.bic_k - t } else { t - ca.bic_k };
    
    // 3. 计算目标窗口: W_max ± C(t-K)³
    let delta = (offs³ * C) / RTT;
    let bic_target = ca.bic_origin_point ± delta;
    
    // 4. 计算增长速率
    ca.cnt = cwnd / (bic_target - cwnd);
    
    // 5. TCP 友好性调整
    tcp_friendliness(ca, cwnd);
}
```

### ICMP Echo 处理流程
```
接收 ICMP Echo Request
    ↓
解析 ICMP 头部（type=8）
    ↓
提取 ID 和 Sequence
    ↓
构造 Echo Reply（type=0）
    ↓
计算校验和
    ↓
发送回复包
```
