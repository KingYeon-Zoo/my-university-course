# 实验 2 截图说明

## 截图前准备

1. 打开 Blender。
2. 在菜单中选择 `文件`，再选择 `打开`。
3. 打开文件 `/Users/zoo/Desktop/数字媒体技术/实验02_三维模型Blender/tiangong/output/tiangong_manual_modeling.blend`。
4. 确认右上角场景集合中存在 `手动建模_展示与贴图` 集合。
5. 建议将截图保存到 `/Users/zoo/Desktop/数字媒体技术/实验02_三维模型Blender/tiangong/screenshots`。

## 截图 1：国旗正面渲染效果

1. 在右侧大纲视图中找到相机 `相机01_国旗正面`。
2. 选中该相机后按 `Ctrl` 加 `0`，或者在菜单中选择 `视图`，再选择 `相机`，再选择 `设置活动对象为相机`。
3. 按小键盘 `0` 进入相机视图。
4. 将视口显示模式切换为 `渲染`，确认画面中可以看到空间站主体、太阳能板、星空背景和核心舱附近的国旗贴图。
5. 在菜单中选择 `渲染`，再选择 `渲染图像`。
6. 渲染完成后选择 `图像`，再选择 `另存为`。
7. 建议保存为 `/Users/zoo/Desktop/数字媒体技术/实验02_三维模型Blender/tiangong/screenshots/图1_国旗正面渲染.png`。
8. 将该图插入报告中“图 1 截图占位：国旗正面渲染效果”的位置。

## 截图 2：空间站整体斜俯视效果

1. 在右侧大纲视图中找到相机 `相机02_空间站斜俯视`。
2. 选中该相机后按 `Ctrl` 加 `0`，将其设为活动相机。
3. 按小键盘 `0` 进入相机视图。
4. 将视口显示模式切换为 `渲染`，确认画面中可以看到空间站整体结构、多个舱段、太阳能板展开状态和星空环境。
5. 在菜单中选择 `渲染`，再选择 `渲染图像`。
6. 渲染完成后选择 `图像`，再选择 `另存为`。
7. 建议保存为 `/Users/zoo/Desktop/数字媒体技术/实验02_三维模型Blender/tiangong/screenshots/图2_整体斜俯视渲染.png`。
8. 将该图插入报告中“图 2 截图占位：空间站整体斜俯视渲染效果”的位置。

## 截图 3：材质与贴图设置界面

1. 在右侧大纲视图中选择对象 `国旗贴图_核心舱`。
2. 切换到顶部 `Shading` 工作区。
3. 在下方节点区域确认材质 `核心舱国旗贴图` 中有 Image Texture 节点，并且贴图文件为 `国旗1024 官方.png`。
4. 同时可在 World 节点中确认 `星空环境贴图` 使用了 `星空全景图.jpg`。
5. 使用 macOS 快捷键 `Command` 加 `Shift` 加 `4` 截取 Blender 界面。
6. 建议保存为 `/Users/zoo/Desktop/数字媒体技术/实验02_三维模型Blender/tiangong/screenshots/图3_材质与贴图节点.png`。
7. 将该图插入报告中“图 3 截图占位：国旗贴图与星空环境节点设置”的位置。

## 截图 4：手动建模集合与新增对象结构

1. 切换回 `Layout` 工作区。
2. 在右侧大纲视图中展开 `手动建模_展示与贴图` 集合。
3. 确认集合中包含 `国旗贴图_核心舱`、`展示说明牌`、`展示轨道线`、`相机01_国旗正面`、`相机02_空间站斜俯视`、`贴图坐标观察_平面`、`贴图坐标观察_立方体`、`贴图坐标观察_球体` 和 `贴图坐标观察_柱体`。
4. 使用 macOS 快捷键 `Command` 加 `Shift` 加 `4` 截取大纲视图和模型视口。
5. 建议保存为 `/Users/zoo/Desktop/数字媒体技术/实验02_三维模型Blender/tiangong/screenshots/图4_手动建模集合结构.png`。
6. 将该图插入报告中“图 4 截图占位：手动建模集合与新增对象结构”的位置。

## 截图 5：贴图坐标观察区

1. 在 `Layout` 工作区中找到场景左侧偏下的 `贴图坐标观察区`。
2. 如果视角不方便，可在大纲视图中依次选择 `贴图坐标观察_平面`、`贴图坐标观察_立方体`、`贴图坐标观察_球体` 和 `贴图坐标观察_柱体`，按小键盘 `.` 聚焦。
3. 将视口显示模式切换为 `材质预览` 或 `渲染`。
4. 截取四种基本几何体使用彩色棋盘贴图后的显示差异。
5. 建议保存为 `/Users/zoo/Desktop/数字媒体技术/实验02_三维模型Blender/tiangong/screenshots/图5_贴图坐标观察区.png`。
6. 将该图插入报告中“图 5 截图占位：平面、立方体、球体、柱体默认贴图坐标观察”的位置。
