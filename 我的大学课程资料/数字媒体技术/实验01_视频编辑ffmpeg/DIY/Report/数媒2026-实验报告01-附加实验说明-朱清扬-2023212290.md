## FFmpeg 编辑过程

实验继续使用项目目录内隔离的 FFmpeg 环境 `.conda-ffmpeg`，原始 NASA 素材只保存在 `DIY/Sources` 目录，脚本、中间文件、日志、最终视频和独立报告分别保存在对应的 `DIY` 子目录中，未修改原实验报告及原实验结果。

主要编辑过程如下：

1. 从三段 NASA 官方视频中选取地球、火箭和深空代表性片段。
2. 将各片段统一为 1280×720、25 fps 和 `yuv420p` 像素格式。
3. 使用 `drawtext` 添加中文片头、片尾、姓名学号和叙事字幕。
4. 使用 `fade` 为片段添加淡入淡出效果，使用 `eq` 调整画面对比度和饱和度。
5. 从韦布视频中提取纯净深空画面，使用 `zoompan` 制作缓慢缩放动画。
6. 使用 concat demuxer 拼接各段视频，循环背景音乐并使用 `afade` 制作音频淡入淡出。
7. 使用 H.264 和 AAC 编码输出最终 MP4 文件，并通过 FFprobe 和完整解码测试检查结果。

附加实验可以使用以下命令在隔离环境中重复执行：

核心处理命令示例如下：

```bash
# 统一画面参数、添加中文字幕和淡入淡出
ffmpeg -ss 20 -t 10 -i nasa_earth_views_medium.mp4 \
  -vf "scale=1280:720,crop=1280:720,fps=25,drawtext=...,fade=..." \
  -an -c:v libx264 -pix_fmt yuv420p earth.mp4

# 拼接片段
ffmpeg -f concat -safe 0 -i concat.txt -c copy diy_silent.mp4

# 添加循环背景音乐并输出最终视频
ffmpeg -stream_loop -1 -i Audio/a0001.mp3 -i diy_silent.mp4 \
  -map 1:v:0 -map 0:a:0 -t 46 -c:v libx264 -c:a aac \
  -af "volume=0.32,afade=t=in:st=0:d=2,afade=t=out:st=43:d=3" \
  DIY/Results/2023212290_附加实验.mp4
```
