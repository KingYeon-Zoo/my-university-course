# 餐厅管理系统

基于Qt的现代化餐厅管理系统，提供完整的餐品、订单和顾客管理功能。

## 功能特性

### 餐品管理
- 显示所有餐品信息和评分
- 根据编号或名称查询餐品
- 添加/删除餐品
- 修改餐品信息

### 订单管理
- 显示所有订单信息和状态
- 根据编号或时间查询订单
- 添加/删除订单
- 修改订单状态

### 顾客管理
- 显示所有顾客信息
- 根据编号或姓名查询顾客
- 添加/删除顾客
- 修改顾客信息

## 项目结构
```
restaurant_qt/
├── src/
│   ├── models/           # 数据模型类
│   │   ├── dish.h/cpp    # 餐品类
│   │   ├── order.h/cpp   # 订单类
│   │   └── customer.h/cpp # 顾客类
│   ├── restaurant.h/cpp   # 餐厅管理类
│   └── utils/            # 工具类
├── resources/            # 资源文件
└── data/                # 数据存储目录
```

## 编译要求
- Qt 6.0+
- C++17
- CMake 3.1+

## 使用说明
1. 克隆项目
2. 使用Qt Creator打开项目
3. 编译并运行

## 数据存储
系统使用文件系统进行数据持久化存储，所有数据将保存在data目录下：
- dishes.dat: 餐品信息
- orders.dat: 订单信息
- customers.dat: 顾客信息
