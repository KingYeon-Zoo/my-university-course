# 实验1-题目2报告：约瑟夫环

**一、实验目的和要求**

本题目是经典的约瑟夫环问题，要求解决以下场景：
- N个小朋友排成一个圆圈，编号为1到N
- 第1个小朋友从1开始报数
- 报到M的小朋友离开座位
- 下一个小朋友继续从1开始报数
- 求最后剩下的小朋友的初始编号

**输入要求**：
- 两个整数N和M（1 ≤ N, M ≤ 1000）

**输出要求**：
- 输出最后一个小朋友的初始编号

**二、解题思路和复杂度分析**

**解题思路**：

本题提供两种解法：

**方法1：模拟法**
1. 使用列表存储所有小朋友的编号（1到N）
2. 使用一个变量记录当前报数起始位置
3. 每次计算第M个位置：`(当前位置 + M - 1) % 当前人数`
4. 删除该位置的小朋友
5. 更新起始位置为删除位置（如果删除的是最后一个，则从0开始）
6. 重复步骤3-5，直到只剩一个小朋友

**方法2：数学公式法**
- 约瑟夫环有经典的递推公式：
  - `f(n, m) = (f(n-1, m) + m) % n`
  - 边界条件：`f(1, m) = 0`（编号从0开始）
- 这个公式表示：n个人时最后剩下的位置，可以从n-1个人的情况推导
- 需要注意编号的转换（0-based转为1-based）

**算法原理**（数学公式）：
- 当有n个人时，假设最后剩下的位置是f(n)
- 删除第m个人后，剩下n-1个人，这n-1个人重新编号
- 新编号0对应的是原编号(m % n)
- 因此：`f(n) = (f(n-1) + m) % n`

**复杂度分析**：

方法1（模拟法）：
- 时间复杂度：O(n²)，外层循环n-1次，每次pop操作O(n)
- 空间复杂度：O(n)，存储列表

方法2（数学公式）：
- 时间复杂度：O(n)，只需循环n-1次
- 空间复杂度：O(1)，只需常数空间

**三、解题过程（流程图/伪代码）**

**伪代码（模拟法）**：

```
函数 josephus_circle(n, m):
    // 初始化小朋友列表
    children = [1, 2, 3, ..., n]
    current_index = 0
    
    当 children的长度 > 1:
        // 计算要离开的小朋友索引
        leave_index = (current_index + m - 1) % len(children)
        
        // 移除该小朋友
        从children中删除leave_index位置的元素
        
        // 更新起始位置
        current_index = leave_index % len(children)
    
    返回 children[0]

主函数:
    读取 n, m
    result = josephus_circle(n, m)
    输出 result
```

**伪代码（数学公式法）**：

```
函数 josephus_formula(n, m):
    result = 0  // 从1个人开始，编号为0
    
    对于 i 从 2 到 n:
        result = (result + m) % i
    
    返回 result + 1  // 转换为1-based编号

主函数:
    读取 n, m
    result = josephus_formula(n, m)
    输出 result
```
