# 实验1-题目3报告：特殊质数（纯质数）

**一、实验目的和要求**

本题目要求判断并统计"纯质数"的个数。

**纯质数定义**：
- 本身是质数
- 首位数字是质数
- 末位数字是质数

**输入要求**：
- 第一行：整数N（1 ≤ N ≤ 20），表示有N个数
- 第二行：N个正整数（每个数不超过10^9）

**输出要求**：
- 输出符合"纯质数"条件的数的个数
- 如果没有，输出0

**二、解题思路和复杂度分析**

**解题思路**：

1. **质数判断**：
   - 特殊情况：小于2的数不是质数，2是质数
   - 偶数（除2外）不是质数
   - 对于奇数，只需检查从3到√n的奇数因子
   - 使用试除法判断质数

2. **纯质数判断**：
   - 首先判断数本身是否为质数
   - 提取首位数字：将数字转为字符串，取第一个字符
   - 提取末位数字：将数字转为字符串，取最后一个字符
   - 判断首位和末位是否都在质数集合{2, 3, 5, 7}中

3. **统计**：
   - 遍历所有输入的数字
   - 对每个数字调用is_pure_prime函数
   - 统计返回True的个数

**关键观察**：
- 一位数的质数：2, 3, 5, 7都是纯质数
- 多位数的质数：首位和末位必须是2, 3, 5, 7之一
- 如果末位是偶数（如2），则该数必须是2才可能是质数
- 如果末位是5，则该数必须是5才可能是质数
- 因此，多位数的纯质数末位只能是3或7

**复杂度分析**：

**is_prime函数**：
- 时间复杂度：O(√n)，其中n是待判断的数
- 空间复杂度：O(1)

**is_pure_prime函数**：
- 时间复杂度：O(√n) + O(log n)（字符串转换）≈ O(√n)
- 空间复杂度：O(log n)（存储字符串）

**整体算法**：
- 时间复杂度：O(N × √M)，其中N是数字个数，M是数字的最大值
- 空间复杂度：O(N)（存储输入数组）

**三、解题过程（流程图/伪代码）**

**伪代码**：

```
函数 is_prime(n):
    如果 n < 2:
        返回 False
    如果 n == 2:
        返回 True
    如果 n是偶数:
        返回 False
    
    // 试除法
    i = 3
    当 i * i <= n:
        如果 n % i == 0:
            返回 False
        i = i + 2
    
    返回 True

函数 is_pure_prime(n):
    // 判断本身是否为质数
    如果 not is_prime(n):
        返回 False
    
    // 提取首位和末位
    num_str = 将n转为字符串
    first_digit = num_str的第一个字符转为整数
    last_digit = num_str的最后一个字符转为整数
    
    // 判断首位和末位是否都是质数
    prime_digits = {2, 3, 5, 7}
    返回 (first_digit在prime_digits中) 且 (last_digit在prime_digits中)

主函数:
    读取 n
    读取 numbers数组
    
    count = 0
    对于 numbers中的每个num:
        如果 is_pure_prime(num):
            count = count + 1
    
    输出 count
```
