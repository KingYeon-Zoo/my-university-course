# 实验3-题目1报告：序列操作

**一、实验目的和要求**

本题目要求实现一个支持动态插入和区间查询的序列数据结构。

**操作类型**：
1. 操作1：在序列尾部插入元素x
2. 操作2：查询以i为左/右端点，和为x的子段个数

**输入要求**：
- 第一行：正整数N，表示操作次数
- 接下来N行：
  - `1 x`：在序列尾部插入元素x
  - `2 i x`：输出以i为左/右端点，和为x的子段个数

**输出要求**：
- 对于每个操作2，输出符合条件的子段个数

**数据范围**：
- N ≤ 100000
- i ≤ 已执行的操作1的次数
- x在int范围内

**二、解题思路和复杂度分析**

**解题思路**：

**关键理解**：
- "以i为左/右端点"的含义：
  - i为左端点：子段形式为[i, j]，i ≤ j
  - i为右端点：子段形式为[j, i]，j ≤ i
  - 两种情况都要统计

**算法步骤**：

1. **维护序列**：
   - 使用列表（数组）存储序列
   - 支持O(1)的尾部插入

2. **查询子段**：
   - **情况1：i为左端点**
     - 从位置i开始，向右扩展到位置j
     - 计算子段[i, j]的和
     - 如果和等于x，计数器加1
     
   - **情况2：i为右端点**
     - 从位置i开始，向左扩展到位置j
     - 计算子段[j, i]的和
     - 如果和等于x，计数器加1
     
   - **去重**：
     - 只包含i自己的子段[i, i]会被计算两次
     - 需要判断并减去重复计数

**示例分析**（样例：[1,2,1,2,3]，查询i=2, x=3）：
```
序列：[1, 2, 1, 2, 3]
索引： 1  2  3  4  5

情况1：i=2为左端点
  [2]      = 2  ✗
  [2,1]    = 3  ✓ (count = 1)
  [2,1,2]  = 5  ✗
  [2,1,2,3]= 8  ✗

情况2：i=2为右端点
  [2]      = 2  ✗ (重复，会被减去)
  [1,2]    = 3  ✓ (count = 2)

去重：
  [2]不等于3，不需要减1

结果：2
```

**复杂度分析**：

**插入操作**：
- 时间复杂度：O(1)
- 空间复杂度：O(1)

**查询操作**：
- 时间复杂度：O(n)，n为当前序列长度
  - 向右扩展：O(n)
  - 向左扩展：O(n)
  - 总计：O(2n) = O(n)
- 空间复杂度：O(1)

**整体算法**：
- 时间复杂度：O(N × M)，N是操作数，M是序列平均长度
- 空间复杂度：O(N)，存储序列

**优化可能性**：
- 使用前缀和数组可以优化区间和的计算
- 但本题数据范围适中，暴力算法足够

**三、解题过程（流程图/伪代码）**

**伪代码**：

```
函数 count_subsequences(sequence, i, x):
    n = len(sequence)
    count = 0
    
    // 情况1：i为左端点，向右扩展
    current_sum = 0
    对于 j 从 i-1 到 n-1:  // 0-based索引
        current_sum += sequence[j]
        如果 current_sum == x:
            count++
    
    // 情况2：i为右端点，向左扩展
    current_sum = 0
    对于 j 从 i-1 到 0（递减）:
        current_sum += sequence[j]
        如果 current_sum == x:
            count++
    
    // 去重：单元素子段[i]被计算两次
    如果 sequence[i-1] == x:
        count--
    
    返回 count

主函数:
    读取 n
    sequence = []
    
    重复 n 次:
        读取 operation
        
        如果 operation[0] == 1:
            // 插入操作
            x = operation[1]
            sequence.append(x)
        否则如果 operation[0] == 2:
            // 查询操作
            i = operation[1]
            x = operation[2]
            result = count_subsequences(sequence, i, x)
            输出 result
```
