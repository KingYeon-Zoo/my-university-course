# 实验3-题目3报告：扑克牌比较

**一、实验目的和要求**

本题目要求实现扑克牌比较系统，判断两副牌的大小。

**牌型定义**（从小到大）：
1. **High Card（高牌）**：根据牌从大到小依次比较
2. **Pair（一对）**：有一个对子和3张其他牌，先比较对子，再比较其他牌
3. **Two Pairs（两对）**：有两个对子和1张其他牌，从大到小比较对子，再比较其他牌
4. **Three of a Kind（三条）**：有3张面值相同的牌，比较这个值
5. **Straight（顺子）**：5张牌连续，比较最大的牌
6. **Flush（同花）**：5张牌花色相同，根据牌从大到小依次比较
7. **Full House（葫芦）**：有3张面值相同的牌和一个对子，比较3个值相同的牌
8. **Four of a Kind（四条）**：有4张牌面值相同，比较这个值
9. **Straight Flush（同花顺）**：5张牌花色相同且面值连续，比较面值最大的牌

**输入要求**：
- 第一行：整数n，表示需要比较的牌序列组数
- 之后n行：每行10个牌面描述（前5张黑方，后5张白方）
- 牌面格式：第一个字符表示面值，第二个表示花色

**输出要求**：
- 对于每组牌，输出"Black wins."、"White wins."或"Tie."

**二、解题思路和复杂度分析**

**解题思路**：

**1. 数据结构设计**：

- **Card类**：表示单张牌
  - value：面值（2-14，A为14）
  - suit：花色（C/D/H/S）

**2. 牌型判断流程**：

```
1. 统计面值出现次数
2. 判断是否同花（所有牌花色相同）
3. 判断是否顺子（面值连续）
4. 根据统计结果确定牌型：
   - 同花 + 顺子 → 同花顺
   - 4张相同 → 四条
   - 3张相同 + 2张相同 → 葫芦
   - 同花 → 同花
   - 顺子 → 顺子
   - 3张相同 → 三条
   - 2对 → 两对
   - 1对 → 一对
   - 其他 → 高牌
```

**3. 比较逻辑**：

```
1. 先比较牌型编号（编号大的牌型大）
2. 牌型相同时，比较关键值：
   - 四条/三条/对子：先比较重复的牌
   - 两对：先比较大对，再小对，最后单牌
   - 高牌/同花：从大到小依次比较
   - 顺子：比较最大的牌
```

**4. 特殊情况处理**：

- **A-2-3-4-5顺子**：A算作1（最小）
- **面值相同的牌**：按花色不同区分，但大小相同

**复杂度分析**：

**parse_hand函数**：
- 时间复杂度：O(5) = O(1)
- 空间复杂度：O(5) = O(1)

**get_hand_type函数**：
- 统计面值：O(5)
- 排序：O(5 log 5) = O(1)
- 判断牌型：O(5)
- 总计：O(1)

**compare_hands函数**：
- get_hand_type：O(1) × 2
- 比较：O(5)
- 总计：O(1)

**整体算法**：
- 时间复杂度：O(n)，n为测试组数
- 空间复杂度：O(1)，每组牌占用常数空间

**三、解题过程（流程图/伪代码）**

**伪代码**：

```
类 Card:
    VALUE_MAP = {'2':2, ..., 'A':14}

函数 get_hand_type(cards):
    values = 提取并排序面值

    // 统计面值出现次数

    // 按出现次数排序

    // 判断同花和顺子
    is_flush = (所有花色相同)
    is_straight = (面值连续)
    
    // 判断牌型（按优先级）
    如果 is_flush 且 is_straight:
        返回 (9, values)  // 同花顺
    如果 counts[0][1] == 4:
        返回 (8, [四条值, 单牌值])
    如果 counts[0][1] == 3 且 counts[1][1] == 2:
        返回 (7, [三条值, 对子值])
    如果 is_flush:
        返回 (6, values)
    如果 is_straight:
        返回 (5, values)
    如果 counts[0][1] == 3:
        返回 (4, [三条值, 其他值...])
    如果 counts[0][1] == 2 且 counts[1][1] == 2:
        返回 (3, [大对, 小对, 单牌])
    如果 counts[0][1] == 2:
        返回 (2, [对子值, 其他值...])
    返回 (1, values)  // 高牌

函数 compare_hands(black_cards, white_cards):
    (black_type, black_values) = get_hand_type(black_cards)
    (white_type, white_values) = get_hand_type(white_cards)
    
    // 比较牌型
    如果 black_type > white_type:
        返回 "Black wins."
    如果 white_type > black_type:
        返回 "White wins."
    
    // 牌型相同，比较关键值
    对于 每对(b, w) in zip(black_values, white_values):
        如果 b > w:
            返回 "Black wins."
        如果 w > b:
            返回 "White wins."
    
    返回 "Tie."

主函数:
    读取 n

        读取 牌面字符串
        black_cards = 解析前5张
        white_cards = 解析后5张
```

**四、实验结果及相关测试样例**

**测试样例1**（题目给出的样例）：

**输入**：
```
4
2H 3D 5S 9C KD 2C 3H 4S 8C AH
2H 4S 4C 2D 4H 2S 8S AS QS 3S
2H 3D 5S 9C KD 2C 3H 4S 8C KH
2H 3D 5S 9C KD 2D 3H 5C 9S KH
```

**输出**：
```
White wins.
Black wins.
Black wins.
Tie.
```

**详细分析**：

**第1组**：
- 黑方：2H 3D 5S 9C KD
  - 牌型：高牌 [K, 9, 5, 3, 2]
- 白方：2C 3H 4S 8C AH
  - 牌型：高牌 [A, 8, 4, 3, 2]
- 比较：都是高牌，A > K
- 结果：**White wins.** ✓

**第2组**：
- 黑方：2H 4S 4C 2D 4H
  - 牌型：葫芦 [4, 2]（三个4，一对2）
- 白方：2S 8S AS QS 3S
  - 牌型：同花（全是S）
- 比较：葫芦(7) > 同花(6)
- 结果：**Black wins.** ✓

**第3组**：
- 黑方：2H 3D 5S 9C KD
  - 牌型：高牌 [K, 9, 5, 3, 2]
- 白方：2C 3H 4S 8C KH
  - 牌型：高牌 [K, 8, 4, 3, 2]
- 比较：K相同，9 > 8
- 结果：**Black wins.** ✓

**第4组**：
- 黑方：2H 3D 5S 9C KD
  - 牌型：高牌 [K, 9, 5, 3, 2]
- 白方：2D 3H 5C 9S KH
  - 牌型：高牌 [K, 9, 5, 3, 2]
- 比较：完全相同
- 结果：**Tie.** ✓
