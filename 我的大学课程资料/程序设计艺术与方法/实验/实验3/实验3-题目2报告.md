# 实验3-题目2报告：读者到访记录

**一、实验目的和要求**

本题目要求实现图书馆读者到访记录系统。

**任务**：
- 记录每天读者的到访情况
- 对于每条记录，输出该读者是第几次出现

**输入要求**：
- 第一行：整数n，表示记录条数
- 第二行：n个整数，依次表示每位读者的编号

**输出要求**：
- 输出一行，包含n个整数，用空格分隔
- 依次表示每条记录中的读者编号是第几次出现

**二、解题思路和复杂度分析**

**解题思路**：

这是一个典型的**计数问题**，需要实时统计每个读者的出现次数。

**数据结构选择**：
- 使用**哈希表（字典）**存储每个读者的出现次数
- 键：读者编号
- 值：该读者已出现的次数

**算法步骤**：
1. **初始化**：
   - 创建空字典visit_count
   - 创建结果列表result

2. **遍历记录**：
   - 对于每个读者编号：
     - 如果编号已在字典中，次数加1
     - 如果编号不在字典中，初始化为1
     - 将当前次数添加到结果列表

3. **输出结果**：
   - 将结果列表转换为字符串输出

**示例分析**（样例：[1, 2, 1, 1, 3]）：
```
读者1（第1次）：visit_count={1:1}, result=[1]
读者2（第1次）：visit_count={1:1, 2:1}, result=[1,1]
读者1（第2次）：visit_count={1:2, 2:1}, result=[1,1,2]
读者1（第3次）：visit_count={1:3, 2:1}, result=[1,1,2,3]
读者3（第1次）：visit_count={1:3, 2:1, 3:1}, result=[1,1,2,3,1]
```

**复杂度分析**：

**时间复杂度**：
- 遍历所有记录：O(n)
- 哈希表查询和更新：O(1)
- 总计：O(n)

**空间复杂度**：
- visit_count字典：O(k)，k为不同读者数量，最坏O(n)
- result列表：O(n)
- 总计：O(n)

**为什么使用哈希表？**
- 查询速度快：O(1)
- 更新方便：O(1)
- 适合动态计数场景

**其他可能的方法**：
- 排序后统计：破坏了原始顺序，不适用
- 数组计数：如果读者编号范围很大，会浪费空间

**三、解题过程（流程图/伪代码）**

**伪代码**：

```
函数 record_visits(n, readers):
    visit_count = {}  // 空字典
    result = []       // 空列表
    
    对于 readers中的每个reader_id:
        // 更新计数
        如果 reader_id 在 visit_count中:
            visit_count[reader_id] += 1
        否则:
            visit_count[reader_id] = 1
        
        // 记录当前次数
        result.append(visit_count[reader_id])
    
    返回 result

主函数:
    读取 n
    读取 readers数组（n个元素）
    
    result = record_visits(n, readers)
    
    输出 result（空格分隔）
```

**流程图**：

```

  ↓

  ↓                 │

```
