# 实验2-题目1报告：矩阵边界元素统计

**一、实验目的和要求**

本题目要求对二维矩阵的边界元素进行统计分析。

**任务**：
- 输出二维矩阵四周（边界）中出现次数最多的元素
- 如果有多个元素出现次数相同，按数值从大到小的次序依次输出

**输入要求**：
- 第一行：整数N（0 < N < 10000），表示矩阵的维度
- 接下来N行：每行N个整数，表示矩阵元素

**输出要求**：
- 输出边界中出现次数最多的元素
- 多个元素时，按数值从大到小排序输出，用空格分隔

**二、解题思路和复杂度分析**

**解题思路**：

1. **边界元素提取**：
   - 矩阵的边界由四部分组成：
     - 第一行：所有列
     - 最后一行：所有列（如果N>1）
     - 第一列：中间的行（排除已计入的角）
     - 最后一列：中间的行（排除已计入的角）
   - 需要注意避免重复计数角上的元素

2. **频率统计**：
   - 使用字典（哈希表）统计每个元素的出现次数
   - 遍历边界元素，更新频率字典

3. **结果筛选**：
   - 找出最大出现次数
   - 筛选所有出现次数等于最大次数的元素
   - 按数值从大到小排序

**边界元素计数示例**（4×4矩阵）：
```
[1] [2] [3] [4]    第一行：1,2,3,4
[2]  3   4  [1]    第一列：2,3,4  最后一列：1,2,1
[3]  4   1  [2]    
[4] [1] [2] [3]    最后一行：4,1,2,3
```
边界元素：1,2,3,4, 4,1,2,3, 2,3, 1,2
统计：1出现3次，2出现4次，3出现3次，4出现2次
最大次数：4次
结果：2

**复杂度分析**：

**get_boundary_elements函数**：
- 时间复杂度：O(n)，遍历边界元素，边界元素总数约为4n-4（N×N矩阵）
- 空间复杂度：O(n)，存储边界元素列表

**find_most_frequent函数**：
- 时间复杂度：O(n) + O(k log k)，其中k是不同元素的个数
  - 统计频率：O(n)
  - 排序：O(k log k)，最坏情况k=O(n)
- 空间复杂度：O(k)，存储频率字典

**整体算法**：
- 时间复杂度：O(n²)，读取矩阵O(n²) + 处理边界O(n log n) = O(n²)
- 空间复杂度：O(n²)，存储矩阵

**三、解题过程（流程图/伪代码）**

**伪代码**：

```
函数 get_boundary_elements(matrix, n):
    boundary = []
    
    // 第一行
    对于 j 从 0 到 n-1:
        boundary.append(matrix[0][j])
    
    // 最后一行（如果n > 1）
    如果 n > 1:
        对于 j 从 0 到 n-1:
            boundary.append(matrix[n-1][j])
    
    // 第一列（排除第一行和最后一行）
    对于 i 从 1 到 n-2:
        boundary.append(matrix[i][0])
    
    // 最后一列（排除第一行和最后一行）
    如果 n > 1:
        对于 i 从 1 到 n-2:
            boundary.append(matrix[i][n-1])
    
    返回 boundary

函数 find_most_frequent(boundary):
    // 统计频率
    frequency = {}
    对于 boundary中的每个num:
        frequency[num] = frequency[num] + 1
    
    // 找最大频率
    max_count = frequency中的最大值
    
    // 收集所有最大频率的元素
    result = []
    对于 frequency中的每个(num, count):
        如果 count == max_count:
            result.append(num)
    
    // 从大到小排序
    result.sort(降序)
    
    返回 result

主函数:
    读取 n
    读取 n×n 矩阵
    
    boundary = get_boundary_elements(matrix, n)
    result = find_most_frequent(boundary)
    
    输出 result（空格分隔）
```

**流程图**：

```
开始
  ↓
读取矩阵维度n
  ↓
读取n×n矩阵
  ↓
提取边界元素
  ├─ 第一行 ────┐
  ├─ 最后一行 ──┤
  ├─ 第一列 ────┤→ boundary列表
  └─ 最后一列 ──┘
  ↓
统计每个元素的频率
  ↓
找出最大频率max_count
  ↓
筛选频率=max_count的元素
  ↓
按数值从大到小排序
  ↓
输出结果
  ↓
结束
```
