# 实验2-题目3报告：矩形数量

**一、实验目的和要求**

本题目要求统计小明几何绘画中的矩形数量。

**问题定义**：
- 画面由'-'和'#'两种字符组成
- 所有的'#'组成了相互不重叠的矩形
- 矩形之间不会在边上或四角相邻
- 统计画面上的矩形数量

**输入要求**：
- 第一行：两个整数N和M（1000以内的正整数），表示画面的高和宽
- 接下来N行：每行M个字符，由'-'和'#'组成

**输出要求**：
- 输出画面上的矩形数量

**二、解题思路和复杂度分析**

**解题思路**：

这是一个典型的**连通区域计数问题**，可以使用图的遍历算法解决。

**问题转化**：
- 将画面看作一个二维网格图
- '#'代表可访问的节点
- '-'代表不可访问的节点
- 相邻的'#'属于同一个矩形（连通分量）
- 问题转化为：统计图中有多少个连通分量

**算法1：深度优先搜索（DFS）**

1. **遍历网格**：
   - 扫描整个画面，逐个检查每个位置
   
2. **发现新矩形**：
   - 遇到'#'且未访问过，说明发现了一个新矩形
   - 矩形计数器加1
   
3. **标记矩形**：
   - 从当前位置开始DFS，访问所有相邻的'#'
   - 将访问过的位置标记，避免重复计数
   
4. **递归搜索**：
   - 对于当前位置，递归访问上、下、左、右四个方向
   - 如果相邻位置是'#'且未访问，继续递归

**算法2：广度优先搜索（BFS）**

1. 使用队列实现
2. 发现新矩形时，将起点加入队列
3. 逐层访问所有相邻的'#'
4. 直到队列为空，一个矩形访问完毕

**两种方法对比**：

| 特性 | DFS | BFS |
|------|-----|-----|
| 实现方式 | 递归/栈 | 队列 |
| 空间复杂度 | O(min(N, M)) | O(N×M) |
| 代码简洁度 | ★★★★★ | ★★★★ |
| 适用场景 | 深度优先 | 广度优先 |

**复杂度分析**：

**DFS方法**：
- 时间复杂度：O(N×M)
  - 每个格子最多访问一次
  - 遍历整个网格
- 空间复杂度：O(N×M)
  - visited数组：O(N×M)
  - 递归栈深度：最坏O(N×M)（退化为链状）

**BFS方法**：
- 时间复杂度：O(N×M)
  - 每个格子最多访问一次
- 空间复杂度：O(N×M)
  - visited数组：O(N×M)
  - 队列：最坏O(N×M)（所有格子都是'#'）

**三、解题过程（流程图/伪代码）**

**伪代码（DFS方法）**：

```
函数 count_rectangles_dfs(grid, n, m):
    visited = n×m的False数组
    count = 0
    
    对于 i 从 0 到 n-1:
        对于 j 从 0 到 m-1:
            如果 grid[i][j] == '#' 且 not visited[i][j]:
                // 发现新矩形
                dfs(grid, visited, i, j, n, m)
                count = count + 1
    
    返回 count

函数 dfs(grid, visited, i, j, n, m):
    // 边界检查
    如果 i < 0 或 i >= n 或 j < 0 或 j >= m:
        返回
    
    // 已访问或不是'#'
    如果 visited[i][j] 或 grid[i][j] != '#':
        返回
    
    // 标记为已访问
    visited[i][j] = True
    
    // 递归访问四个方向
    dfs(grid, visited, i-1, j, n, m)  // 上
    dfs(grid, visited, i+1, j, n, m)  // 下
    dfs(grid, visited, i, j-1, n, m)  // 左
    dfs(grid, visited, i, j+1, n, m)  // 右

主函数:
    读取 n, m
    读取 n×m 的grid
    
    result = count_rectangles_dfs(grid, n, m)
    输出 result
```

**伪代码（BFS方法）**：

```
函数 count_rectangles_bfs(grid, n, m):
    visited = n×m的False数组
    count = 0
    
    对于 i 从 0 到 n-1:
        对于 j 从 0 到 m-1:
            如果 grid[i][j] == '#' 且 not visited[i][j]:
                // 发现新矩形，BFS
                queue = [(i, j)]
                visited[i][j] = True
                
                当 queue不为空:
                    (x, y) = queue.dequeue()
                    
                    // 检查四个方向
                    对于 (dx, dy) 在 [(-1,0), (1,0), (0,-1), (0,1)]:
                        nx = x + dx
                        ny = y + dy
                        
                        如果 0 <= nx < n 且 0 <= ny < m:
                            如果 grid[nx][ny] == '#' 且 not visited[nx][ny]:
                                visited[nx][ny] = True
                                queue.enqueue((nx, ny))
                
                count = count + 1
    
    返回 count
```

**流程图（DFS）**：

```
开始
  ↓
读取n, m和grid
  ↓
visited = [[False]*m]*n
count = 0
  ↓
遍历grid[i][j] ────────┐
  ↓                     │
grid[i][j]=='#' ──否──→ 继续
且not visited[i][j]?    │
  ↓ 是                  │
调用dfs(i,j)标记连通区域│
  ↓                     │
count++                 │
  ↓                     │
  └─────────────────────┘
  ↓
输出count
  ↓
结束
```

**DFS递归过程**：

```
dfs(i, j)
  ↓
边界检查? ──越界或已访问或不是'#'──→ 返回
  ↓ 合法且是'#'
标记visited[i][j] = True
  ↓
递归调用四个方向
  ├─ dfs(i-1, j)  上
  ├─ dfs(i+1, j)  下
  ├─ dfs(i, j-1)  左
  └─ dfs(i, j+1)  右
  ↓
返回
```

本题成功实现了连通区域的计数。通过DFS或BFS遍历图，能够准确识别和统计画面上的矩形数量。算法的核心是图的遍历，通过visited数组避免重复访问，确保每个矩形只被计数一次。代码结构清晰，逻辑简单，易于理解和实现。这类问题在图像处理、地图分析等领域有广泛应用。
