
**一、实验目的和要求** 

给定长度为n的数列，可以擦掉任意个数，剩余的数重新编号后（保持相对顺序），求最多能有多少个数满足"值等于位置"（即A[i] = i）。

**输入要求**：
- 第一行：整数n，数列长度
- 第二行：n个正整数，表示数列元素

**输出要求**：
- 输出一个整数，表示最多能有多少个数在自己的位置上

**二、解题思路和复杂度分析**  

**解题思路**：

这是一个动态规划问题。关键观察：

1. **位置重新编号**：擦掉一些数后，剩余的数会重新编号为1, 2, 3, ..., k
2. **条件分析**：如果保留原位置p₁, p₂, ..., pₖ（递增），它们变成新位置1, 2, ..., k
   - 要使新位置j满足条件，需要 A[pⱼ] = j
3. **状态定义**：dp[i][j] = 考虑前i个元素，选了j个，其中满足A[i]=i的最大个数

**状态转移**：
- 不选第i个元素：`dp[i][j] = dp[i-1][j]`
- 选第i个元素（它成为第j+1个）：
  - 如果 A[i] = j+1（满足条件）：`dp[i][j+1] = dp[i-1][j] + 1`
  - 否则（不满足条件）：`dp[i][j+1] = dp[i-1][j]`

**初始状态**：dp[0][0] = 0（选0个元素，0个满足）

**答案**：max{dp[n][j]} for all j

**示例分析**（[1, 1, 2, 5, 4]）：
```
原位置:  1  2  3  4  5
值:      1  1  2  5  4

选择原位置1, 3, 4, 5 → 新位置1, 2, 3, 4，值[1, 2, 5, 4]
- 新位置1，值1 ✓
- 新位置2，值2 ✓
- 新位置3，值5 ✗
- 新位置4，值4 ✓
共3个满足
```

**复杂度分析**：
- 时间复杂度：O(n²)，双重循环
- 空间复杂度：O(n)，使用滚动数组优化

**三、解题过程（流程图/伪代码）** 

```
函数 max_position_match(n, numbers):
    // 初始化DP数组
    prev = [-∞, -∞, ..., -∞]  // 长度n+1
    prev[0] = 0  // 选0个，0个满足
    
    // 遍历每个元素
    对于 i 从 0 到 n-1:
        curr = [-∞, -∞, ..., -∞]
        
        对于 j 从 0 到 i+1:
            // 情况1: 不选第i个元素
            如果 j <= i:
                curr[j] = max(curr[j], prev[j])
            
            // 情况2: 选第i个元素（成为第j+1个）
            如果 j <= i 且 prev[j] != -∞:
                如果 numbers[i] == j+1:
                    // 满足条件
                    curr[j+1] = max(curr[j+1], prev[j] + 1)
                否则:
                    // 不满足条件  
                    curr[j+1] = max(curr[j+1], prev[j])
        
        prev = curr
    
    // 返回最大值
    返回 max(prev[0], prev[1], ..., prev[n])

主函数:
    读取 n
    读取 numbers
    result = max_position_match(n, numbers)
    输出 result
```

**流程图**：
```
开始
  ↓
读取n和数列numbers
  ↓
初始化DP数组: prev[0]=0, 其余=-∞
  ↓
对于每个元素i (0到n-1) ───┐
  ↓                        │
  创建新数组curr             │
  ↓                        │
  对于每个选择数j (0到i+1) ┐│
    ↓                      ││
    考虑不选i: curr[j]     ││
    ↓                      ││
    考虑选i成为第j+1个:    ││
    - 如果numbers[i]=j+1   ││
      curr[j+1]=prev[j]+1  ││
    - 否则                 ││
      curr[j+1]=prev[j]    ││
    ↓                      ││
  ←──────────────────────┘│
  ↓                        │
  prev = curr              │
  ↓                        │
←────────────────────────┘
  ↓
返回max(prev)
  ↓
输出结果
  ↓
结束
```

**总结**：
本题是典型的动态规划问题，通过状态转移求解最优子序列选择。关键在于理解位置重新编号的机制，以及如何用DP维护"选了j个元素，其中k个满足条件"的状态。该问题展示了动态规划在序列优化中的应用，算法时间复杂度O(n²)，适用于中等规模数据。
