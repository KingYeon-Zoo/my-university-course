# 实验4-题目1报告：重排数字

**一、实验目的和要求**

本题目要求重新排列数字A的各位数字，得到新数字C，使得C在不超过B的前提下尽可能大。

**要求**：
- C由A的各位数字重新排列得到
- C不能有前导0
- C ≤ B
- C尽可能大
- 如果不存在这样的C，输出-1

**输入要求**：
- 一行两个整数A和B（1 ≤ A, B < 10^9）

**输出要求**：
- 输出符合条件的C的最大值，或-1

**二、解题思路和复杂度分析**

**解题思路**：

这是一个典型的**排列组合优化问题**。

**方法1：全排列枚举**（适用于位数较少）

1. **生成所有排列**：
   - 使用Python的permutations生成A的所有排列
   - 去除重复排列

2. **过滤有效排列**：
   - 去除前导0的排列
   - 去除大于B的排列

3. **选择最大值**：
   - 从有效排列中选择最大的

**方法2：贪心构造**（更优化，但实现复杂）

1. **位数比较**：
   - 如果A位数 > B位数：无解
   - 如果A位数 < B位数：直接降序排列（最大值）
   - 如果A位数 = B位数：需要仔细构造

2. **从高位到低位构造**：
   - 尝试在每一位放置尽可能大的数字
   - 同时保证后续位能构造出不超过B的数

**算法选择**：
- 由于A < 10^9，最多9位数字
- 9! = 362,880，可以接受
- 使用全排列方法，简单可靠

**复杂度分析**：

**全排列方法**：
- 时间复杂度：O(n! × n)
  - 生成排列：O(n!)
  - 每个排列转换和比较：O(n)
  - n最大为9，9! ≈ 360,000
- 空间复杂度：O(n!)，存储所有排列

**贪心方法**（理论分析）：
- 时间复杂度：O(n² × n!)，最坏情况需要回溯
- 空间复杂度：O(n)

**实际选择**：
- 对于本题数据范围，全排列方法足够高效
- 代码简洁，易于实现和调试

**三、解题过程（流程图/伪代码）**

**伪代码**：

```
函数 construct_max_valid(digits, target):
    // 生成所有排列
    all_perms = permutations(digits)去重
    
    // 过滤前导0
    valid_perms = [p for p in all_perms if p[0] != '0']
    
    // 过滤大于target的
    target_val = int(target)
    valid_nums = [int(p) for p in valid_perms if int(p) <= target_val]
    
    // 返回最大值
    如果 valid_nums为空:
        返回 None
    返回 max(valid_nums)

函数 find_max_arrangement(a_str, b):
    digits = list(a_str)
    b_str = str(b)
    
    // 比较位数
    如果 len(digits) > len(b_str):
        返回 -1  // 位数太多，无解
    如果 len(digits) < len(b_str):
        // 位数较少，直接降序排列
        digits.sort(降序)
        如果 digits[0] == '0':
            返回 -1
        返回 int(join(digits))
    
    // 位数相同，构造最大有效值
    result = construct_max_valid(digits, b_str)
    
    如果 result 为 None:
        返回 -1
    返回 result

主函数:
    读取 a, b
    result = find_max_arrangement(str(a), b)
    输出 result
```

**四、实验结果及相关测试样例**

**测试样例1**（题目给出的样例1）：

**输入**：
```
1234 3456
```

**输出**：
```
3421
```

**分析**：
- A = 1234，数字：[1, 2, 3, 4]
- B = 3456
- 位数相同（4位）
- 需要找到≤3456的最大排列
- 可能的排列：
  - 4321 > 3456 ✗
  - 4312 > 3456 ✗
  - 4231 > 3456 ✗
  - ...
  - 3421 ≤ 3456 ✓
  - 3412 ≤ 3456 ✓
  - 最大的是3421

**结果正确** ✓
