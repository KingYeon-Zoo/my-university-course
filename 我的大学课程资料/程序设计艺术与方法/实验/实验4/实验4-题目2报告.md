# 实验4-题目2报告：买蛋糕

**一、实验目的和要求**

本题目要求在蛋糕店选择k个连续的蛋糕，使得这些蛋糕中最高和第二高的差值最小。

**问题定义**：
- 蛋糕排列成一行，每个蛋糕有不同的高度
- 需要买k个连续的蛋糕
- 目标：使这k个蛋糕中最高的和第二高的差值最小

**输入要求**：
- 第一行：正整数n和k（1 ≤ k ≤ n ≤ 1,000,000）
- 第二行：n个正整数，表示每个蛋糕的高度（0 < height < 10,000,000）

**输出要求**：
- 输出一个正整数，表示最小的差值

**二、解题思路和复杂度分析**

**解题思路**：

这是一个典型的**滑动窗口问题**。

**核心思想**：
1. 遍历所有长度为k的连续子数组（滑动窗口）
2. 对于每个窗口，找到最大值和第二大值
3. 计算差值
4. 记录所有差值中的最小值

**算法步骤**：

1. **特殊情况处理**：
   - 如果k = 1，只买一个蛋糕，差值为0

2. **滑动窗口**：
   - 窗口大小固定为k
   - 从位置0滑动到位置n-k
   - 共有n-k+1个窗口

3. **每个窗口的处理**：
   - 提取窗口中的k个元素
   - 排序（或找最大和次大）
   - 计算差值

4. **记录最小差值**：
   - 遍历所有窗口，更新最小差值

**示例分析**（样例：[1, 2, 3, 5, 8, 5]，k=3）：
```
窗口1：[1, 2, 3] → 排序[3, 2, 1] → 差值=3-2=1
窗口2：[2, 3, 5] → 排序[5, 3, 2] → 差值=5-3=2
窗口3：[3, 5, 8] → 排序[8, 5, 3] → 差值=8-5=3
窗口4：[5, 8, 5] → 排序[8, 5, 5] → 差值=8-5=3

最小差值=1
```

**优化可能性**：

**方法1：暴力排序**（本实现）
- 每个窗口排序：O(k log k)
- 总时间：O(n × k log k)

**方法2：优化找最大和次大**
- 不需要完全排序，只需找两个最大值
- 每个窗口：O(k)
- 总时间：O(n × k)

**方法3：维护有序数据结构**
- 使用平衡树或堆维护窗口
- 窗口滑动：O(log k)
- 总时间：O(n log k)
- 实现复杂度高

**复杂度分析**：

**暴力排序方法**：
- 时间复杂度：O(n × k log k)
  - n-k+1个窗口
  - 每个窗口排序O(k log k)
- 空间复杂度：O(k)，存储窗口

**优化方法（找两个最大值）**：
- 时间复杂度：O(n × k)
- 空间复杂度：O(k)

**实际选择**：
- 对于k较小的情况，排序方法足够快
- 对于k接近n的情况，优化方法更好
- 本题k ≤ n ≤ 10^6，排序方法在可接受范围

**三、解题过程（流程图/伪代码）**

**伪代码**：

```
函数 find_min_difference(n, k, heights):
    如果 k == 1:
        返回 0
    
    min_diff = 无穷大
    
    // 滑动窗口
    对于 i 从 0 到 n-k:
        // 提取窗口
        window = heights[i:i+k]
        
        // 排序找最大和次大
        window_sorted = sort(window, 降序)
        
        // 计算差值
        diff = window_sorted[0] - window_sorted[1]
        
        // 更新最小差值
        min_diff = min(min_diff, diff)
    
    返回 min_diff

主函数:
    读取 n, k
    读取 heights数组
    
    result = find_min_difference(n, k, heights)
    输出 result
```

**伪代码（优化版 - 只找两个最大值）**：

```
函数 find_min_difference_optimized(n, k, heights):
    如果 k == 1:
        返回 0
    
    min_diff = 无穷大
    
    对于 i 从 0 到 n-k:
        // 找窗口中最大和第二大
        max1 = -无穷大
        max2 = -无穷大
        
        对于 j 从 i 到 i+k-1:
            如果 heights[j] > max1:
                max2 = max1
                max1 = heights[j]
            否则如果 heights[j] > max2:
                max2 = heights[j]
        
        diff = max1 - max2
        min_diff = min(min_diff, diff)
    
    返回 min_diff
```
