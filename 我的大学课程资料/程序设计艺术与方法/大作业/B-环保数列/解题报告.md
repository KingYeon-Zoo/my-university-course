# 题目B 环保数列

## 题目描述

有一天，小C梦到了许多神奇的数排列组成的神奇数列，定义如下：如果一个正整数n可以被表示成 $a^2 - b^2 = n$ (a, b均为正整数)，那么n则被小C称为神奇数。

神奇数列是将所有神奇数按照从小到大的顺序排列。例如：
- 第一项：3 = 2² - 1²
- 第二项：5 = 3² - 2²  
- 第三项：7 = 4² - 3²
- 第四项：8 = 3² - 1²

**输入说明**：
- 第一行一个整数T (1 ≤ T ≤ 10)，表示数据组数
- 对于每组数据，输入一行一个整数x (1 ≤ x ≤ 10⁹)，表示询问的项数

**输出说明**：
- 对于每组数据，输出一行一个整数，表示神奇数列第x项的值

## 解题思路

这道题目的关键在于理解什么样的数可以表示成两个平方数之差，以及如何快速找到第x个这样的数。

### 数学原理分析

首先，我们利用平方差公式对表达式进行因式分解：

$$a^2 - b^2 = (a+b)(a-b) = n$$

设 $p = a + b$，$q = a - b$，则：
- $pq = n$
- $a = \frac{p+q}{2}$
- $b = \frac{p-q}{2}$

要使a和b都是正整数，必须满足：
1. $p + q$ 必须是偶数（即p和q同奇偶）
2. $p > q > 0$（因为a, b都是正整数且a > b）

### 神奇数的特征

基于上述分析，我们可以得出：

**一个正整数n能表示成平方差的充要条件是**：n能分解为两个同奇偶性的正整数之积。

让我们分类讨论：

1. **奇数**：任何奇数n都可以表示为 n = n × 1
   - 因为n和1都是奇数（同奇偶）
   - 此时 $a = \frac{n+1}{2}$，$b = \frac{n-1}{2}$
   - 例如：5 = 5×1，则 a=3, b=2，验证：3² - 2² = 9 - 4 = 5 ✓

2. **4的倍数**：形如4k的数可以表示为 4k = 2k × 2
   - 因为2k和2都是偶数（同奇偶）
   - 此时 $a = k+1$，$b = k-1$
   - 例如：8 = 4×2，则 a=3, b=1，验证：3² - 1² = 9 - 1 = 8 ✓

3. **形如4k+2的数**：这类数只能分解为 (4k+2) × 1
   - 4k+2是偶数，1是奇数（奇偶性不同）
   - 无法满足同奇偶性条件
   - 例如：6 = 6×1 = 3×2，但6和1奇偶不同，3和2也奇偶不同

4. **特殊情况**：
   - 1 = 1×1，但需要 a=1, b=0，而b必须是正整数，所以1不是神奇数
   - 2 = 2×1，奇偶性不同，所以2不是神奇数

### 结论

神奇数列 = {所有大于2的奇数} ∪ {8, 12, 16, 20, ...（4的倍数且≥8）}

非神奇数 = {1, 2, 4, 6, 10, 14, 18, 22, ...} = {1, 2, 4} ∪ {4k+2 | k ≥ 1}

## 具体解法

### 方法一：直接计数（会超时）

最直接的方法是从3开始遍历每个数，判断是否为神奇数，直到找到第x个。但当x很大（如10⁹）时，这种方法会超时。

### 方法二：二分查找 + 数学公式（推荐）

我们可以通过数学公式计算：在前n个正整数中，有多少个神奇数。

**计算公式推导**：

在1到n的范围内：
- 总共有n个数
- 非神奇数包括：
  - 数字1, 2, 4：共3个（当n≥4时）
  - 形如4k+2的数：6, 10, 14, ..., 最大不超过n

形如4k+2的数，满足 4k+2 ≤ n，即 k ≤ (n-2)/4

所以4k+2形式的数有 ⌊(n-2)/4⌋ 个

因此，1到n中神奇数的个数为：
$$count(n) = n - 2 - \lfloor\frac{n-2}{4}\rfloor - 1 = n - 3 - \lfloor\frac{n-2}{4}\rfloor$$（当n≥4时）

**算法流程**：

使用二分查找找到第x个神奇数：

```
初始化：left = 1, right = x * 3（上界足够大）
while left < right:
    mid = (left + right) / 2
    if count(mid) < x:
        left = mid + 1
    else:
        right = mid
返回 left
```

### 算法复杂度分析

- **时间复杂度**：O(T × log(x))
  - 每组数据二分查找需要 O(log(x)) 次
  - 每次二分判断需要 O(1) 时间
  - 共T组数据
  
- **空间复杂度**：O(1)

### 正确性验证

让我们验证样例：
- 神奇数列：3, 5, 7, 8, 9, 11, 12, 13, 15, 16, ...
- 第4项 = 8 ✓
- 第6项 = 11 ✓

验证count函数：
- count(8) = 8 - 3 - ⌊6/4⌋ = 8 - 3 - 1 = 4（神奇数：3,5,7,8，共4个）✓
- count(11) = 11 - 3 - ⌊9/4⌋ = 11 - 3 - 2 = 6（去掉：1,2,4,6,10，剩余6个）✓

## 代码实现

```python
def count_magic_numbers_up_to(n):
    """
    计算不大于n的神奇数个数
    """
    if n < 3:
        return 0
    
    # 形如4k+2的数的个数
    count_4k_plus_2 = (n - 2) // 4
    
    # 去掉1, 2和所有4k+2的数
    magic_count = n - 2 - count_4k_plus_2
    
    return magic_count

def find_kth_magic(k):
    """
    找到第k个神奇数
    使用二分查找
    """
    left, right = 1, k * 3
    
    while left < right:
        mid = (left + right) // 2
        if count_magic_numbers_up_to(mid) < k:
            left = mid + 1
        else:
            right = mid
    
    return left

def solve():
    T = int(input())
    for _ in range(T):
        x = int(input())
        result = find_kth_magic(x)
        print(result)
```

## 算法优化技巧

### 优化点1：二分上界的选择

为什么选择 `right = k * 3`？

- 在前n个数中，最多去掉 2 + n/4 个数
- 所以至少保留 n - 2 - n/4 = 3n/4 - 2 个神奇数
- 要获得k个神奇数，需要 3n/4 - 2 ≥ k
- 解得 n ≥ 4(k+2)/3 < 2k（当k足够大时）
- 为保险起见，取 3k 作为上界

### 优化点2：避免浮点运算

全程使用整数除法，避免浮点误差。
