# 题目H 电能输送

## 题目描述

随着全球环保意识的提升，西部地区发展了大量可再生能源发电站，如风电、光伏等。为了满足东部城市对清洁能源的需求，中国西电公司计划建设一套输电系统，从西部的可再生能源发电站将电力输送到东部城市。

该系统包括发电站、输电站和变电站等站点和一套输电线路，用于将电力从一个地方输送到另一个地方。每个站点都被编号：
- 发电站的编号为 **1**
- 变电站的编号为 **N**
- 中间的输电站的编号从 2 到 N-1

沿途的每段输电线路连接一对输电站，每条输电线路可以**向任意方向**输送**有限数量**的电力。

需要根据地图和输电线路容量，计算该输电系统最多可以输送多少电力。

**输入说明**：
- 第一行包含两个整数 N, M，其中 N 表示站点数量，M 表示输电线路数量 (2 ≤ N ≤ 10000)
- 接下来的 M 行描述输电线路的规格：三个数字描述连接的一对站点以及其输电容量（1 到 10⁸ 的整数）
- 保证输送的电量不会是负数

**输出说明**：
- 输出可以输送的最大电力数量

## 解题思路

这道题目是一个经典的**网络最大流问题（Maximum Flow Problem）**。

### 问题建模

可以将输电系统建模为一个**网络流图**：
- **节点（顶点）**：发电站、输电站、变电站
- **边**：输电线路
- **容量**：每条线路的输电容量
- **源点**：发电站（节点1）
- **汇点**：变电站（节点N）

**目标**：求从源点1到汇点N的最大流量。

### 什么是网络最大流？

在一个有向图中，每条边有一个容量限制，要找到从源点s到汇点t的最大流量，使得：
1. **容量约束**：每条边的流量不超过其容量
2. **流量守恒**：除了源点和汇点，其他节点的流入量等于流出量

### 常用算法

解决最大流问题有多种算法：

1. **Ford-Fulkerson算法**：基于增广路径的思想
   - 时间复杂度：O(E × MaxFlow)，其中E是边数
   - 适用于容量较小的情况

2. **Edmonds-Karp算法**：Ford-Fulkerson的BFS实现
   - 时间复杂度：O(V × E²)
   - 适用于中等规模

3. **Dinic算法**：使用层次图优化
   - 时间复杂度：O(V² × E)
   - 适用于大规模问题，**本题选用**

4. **Push-Relabel算法**：
   - 时间复杂度：O(V² × E) 或 O(V³)

### Dinic算法原理

Dinic算法是目前最常用的最大流算法之一，核心思想：

**阶段1：构建层次图（Level Graph）**
- 使用BFS从源点开始，给每个节点分配层次
- 层次 = 从源点到该节点的最短距离

**阶段2：在层次图中寻找增广路**
- 使用DFS在层次图中寻找增广路径
- 只在层次递增的边上前进（level[v] = level[u] + 1）
- 找到增广路后，更新残留网络

**阶段3：重复**
- 重复阶段1和2，直到无法构建层次图（汇点不可达）

### 残留网络（Residual Network）

残留网络是算法的核心数据结构：
- **正向边**：剩余容量 = 原容量 - 已流量
- **反向边**：剩余容量 = 已流量（用于"反悔"）

每次找到增广路，流量为f时：
- 正向边容量减少f
- 反向边容量增加f

## 具体解法

### 算法流程

```
初始化：
  创建残留网络图 graph[u][v] = capacity
  total_flow = 0

While True:
  # 阶段1：BFS构建层次图
  level = BFS(source, sink)
  If sink不可达:
    Break  # 无法继续增广
  
  # 阶段2：DFS寻找增广路
  While True:
    flow = DFS(source, sink, ∞)
    If flow == 0:
      Break  # 当前层次图已无增广路
    total_flow += flow

返回 total_flow
```

### 详细伪代码

```python
class MaxFlow:
    def __init__(self, n):
        self.n = n
        self.graph = defaultdict(lambda: defaultdict(int))
    
    def add_edge(self, u, v, cap):
        """添加双向边（无向图）"""
        self.graph[u][v] += cap
        self.graph[v][u] += cap
    
    def bfs(self, s, t):
        """BFS构建层次图"""
        self.level = [-1] * (self.n + 1)
        self.level[s] = 0
        queue = [s]
        
        while queue:
            u = queue.pop(0)
            for v in self.graph[u]:
                if self.level[v] < 0 and self.graph[u][v] > 0:
                    self.level[v] = self.level[u] + 1
                    queue.append(v)
        
        return self.level[t] >= 0  # 汇点可达？
    
    def dfs(self, u, t, flow):
        """DFS寻找增广路"""
        if u == t:
            return flow
        
        for v in self.graph[u]:
            if self.level[v] == self.level[u] + 1 and self.graph[u][v] > 0:
                # 递归寻找路径
                min_flow = min(flow, self.graph[u][v])
                pushed = self.dfs(v, t, min_flow)
                
                if pushed > 0:
                    # 更新残留网络
                    self.graph[u][v] -= pushed
                    self.graph[v][u] += pushed
                    return pushed
        
        return 0
    
    def max_flow(self, s, t):
        """计算最大流"""
        total = 0
        
        while self.bfs(s, t):  # 能否构建层次图
            while True:
                pushed = self.dfs(s, t, ∞)
                if pushed == 0:
                    break
                total += pushed
        
        return total
```

### 复杂度分析

**Dinic算法**：
- **时间复杂度**：O(V² × E)
  - BFS：O(V + E)
  - 层次图最多V层
  - 每层DFS：O(E)
  - 总共：O(V) × O(V + E) = O(V² × E)
  
- **空间复杂度**：O(V + E)
  - 邻接表存储图：O(E)
  - 层次数组：O(V)
  - 递归栈：O(V)

**对于本题**：
- N ≤ 10000，M ≤ 很大（题目未说明，假设≤100000）
- 理论最坏：10000² × 100000 = 10¹³，但实际远小于此
- Dinic算法在随机图上的实际表现接近O(V × E)

## 样例分析

**输入**：
```
3 2
1 2 2
2 3 1
```

**解析**：
- 3个站点：发电站(1)、输电站(2)、变电站(3)
- 2条线路：
  - 1→2，容量2
  - 2→3，容量1

**网络图**：
```
  1 -----(2)-----> 2 -----(1)-----> 3
发电站           输电站           变电站
```

**算法执行过程**：

**第1轮**：
1. BFS构建层次图：
   - level[1] = 0
   - level[2] = 1
   - level[3] = 2

2. DFS寻找增广路：
   - 路径：1→2→3
   - 瓶颈容量：min(2, 1) = 1
   - 更新：
     - graph[1][2] = 2 - 1 = 1
     - graph[2][1] = 0 + 1 = 1
     - graph[2][3] = 1 - 1 = 0
     - graph[3][2] = 0 + 1 = 1
   - total_flow = 1

3. 继续DFS：
   - graph[2][3] = 0，无法到达3
   - 本轮结束

**第2轮**：
1. BFS构建层次图：
   - graph[2][3] = 0，无法到达3
   - 返回False

**算法结束**，total_flow = **1**

**为什么不是2？**
- 虽然1→2的容量是2，但2→3的容量只有1
- 根据流量守恒，节点2的流入量必须等于流出量
- 所以最大流被2→3的容量1限制

**输出：1** ✓

## 代码实现

```python
from collections import deque, defaultdict

class MaxFlow:
    def __init__(self, n):
        self.n = n
        self.graph = defaultdict(lambda: defaultdict(int))
        
    def add_edge(self, u, v, cap):
        """添加边（双向）"""
        self.graph[u][v] += cap
        self.graph[v][u] += cap
    
    def bfs(self, s, t):
        """BFS构建层次图"""
        self.level = [-1] * (self.n + 1)
        self.level[s] = 0
        queue = deque([s])
        
        while queue:
            u = queue.popleft()
            for v in self.graph[u]:
                if self.level[v] < 0 and self.graph[u][v] > 0:
                    self.level[v] = self.level[u] + 1
                    queue.append(v)
        
        return self.level[t] >= 0
    
    def dfs(self, u, t, flow):
        """DFS寻找增广路"""
        if u == t:
            return flow
        
        for v in list(self.graph[u].keys()):
            if self.level[v] == self.level[u] + 1 and self.graph[u][v] > 0:
                min_flow = min(flow, self.graph[u][v])
                pushed = self.dfs(v, t, min_flow)
                
                if pushed > 0:
                    self.graph[u][v] -= pushed
                    self.graph[v][u] += pushed
                    return pushed
        
        return 0
    
    def max_flow(self, s, t):
        """计算最大流"""
        total_flow = 0
        
        while self.bfs(s, t):
            while True:
                pushed = self.dfs(s, t, float('inf'))
                if pushed == 0:
                    break
                total_flow += pushed
        
        return total_flow

def solve():
    N, M = map(int, input().split())
    mf = MaxFlow(N)
    
    for _ in range(M):
        u, v, cap = map(int, input().split())
        mf.add_edge(u, v, cap)
    
    result = mf.max_flow(1, N)
    print(result)

if __name__ == "__main__":
    solve()
```

### 优化2：多路增广

在一次DFS中，尝试推送尽可能多的流量，而不是每次只推送瓶颈流量。

### 优化3：使用邻接表而非邻接矩阵

对于稀疏图，邻接表的空间和时间效率都更高。
