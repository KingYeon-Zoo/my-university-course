# 题目F 太阳能板

## 题目描述

科研人员想要研发新的太阳能板材料，在n个仓库中存放了n种原始材料。有n-1条道路将这n个仓库连接在一起，每条道路连接着两个仓库。

进行新材料的合成必须使用两种原始材料。考虑到运输成本和材料成本，只能选择被一条道路直接相连的两个仓库中的原始材料进行合成，且每种原始材料只能被使用一次。

在两种原始材料合成之后，得到的新材料的吸光能力为两种原始材料的吸光能力之**乘积**。

现在科研人员想要知道，合成的新材料的吸光能力的**总和**最大是多少。

**输入说明**：
- 第一行一个正整数：n（仓库数量）
- 第二行到第n行每行两个整数：ai, bi 表示仓库ai和仓库bi之间存在道路
- 第n+1行n个正整数：vi，表示仓库i中的原始材料的吸光能力

**输出说明**：
- 能够得到的最大的吸光能力总和

**数据范围**：n ≤ 1000000

## 解题思路

这道题目是一个典型的**树上最大权匹配问题**。关键观察点：

1. **树形结构**：n个节点，n-1条边，构成一棵树
2. **匹配约束**：每个材料最多使用一次，只能与相邻节点匹配
3. **目标函数**：最大化所有匹配边的权值乘积之和

这类问题的标准解法是**树形动态规划（树形DP）**。

### 问题建模

我们可以将问题转化为：
- 在树上选择若干条边
- 被选中的边两端的节点都不能被其他边选中
- 最大化所有被选边的权值和（权值 = 两端节点值的乘积）

这是一个**独立集**的变体问题。

### 状态设计

以任意节点（如节点1）为根，进行树形DP。

**定义状态**：
- `dp[u][0]`：以u为根的子树中，节点u**不参与匹配**时的最大吸光能力总和
- `dp[u][1]`：以u为根的子树中，节点u**已与父节点匹配**时的最大吸光能力总和

为什么需要两个状态？
- 状态0表示u还没有匹配，它可以选择与某个子节点匹配，或者不匹配
- 状态1表示u已经匹配了（与父节点），所以不能再与子节点匹配

### 状态转移

对于节点u，设其子节点为 v₁, v₂, ..., vₖ。

**情况1：u已与父节点匹配 (dp[u][1])**
- u不能再与任何子节点匹配
- 所有子节点都只能选择"不匹配"状态
- 转移方程：
$$dp[u][1] = \sum_{i=1}^{k} dp[v_i][0]$$

**情况2：u不参与匹配 (dp[u][0])**

u有两种选择：

**(a) u不与任何子节点匹配**
- 每个子节点可以选择最优状态（匹配或不匹配）
- 贡献值：$\sum_{i=1}^{k} \max(dp[v_i][0], dp[v_i][1])$

**(b) u与某个子节点vⱼ匹配**
- 选择vⱼ后，获得收益：$value[u] \times value[v_j]$
- vⱼ不能再与其子节点匹配：$dp[v_j][0]$
- 其他子节点选择最优状态：$\sum_{i \neq j} \max(dp[v_i][0], dp[v_i][1])$
- 总贡献：$value[u] \times value[v_j] + dp[v_j][0] + \sum_{i \neq j} \max(dp[v_i][0], dp[v_i][1])$

取所有方案的最大值：
$$dp[u][0] = \max \begin{cases}
\sum_{i=1}^{k} \max(dp[v_i][0], dp[v_i][1]) & \text{(u不匹配)} \\
\max_{j} \left\{ value[u] \times value[v_j] + dp[v_j][0] + \sum_{i \neq j} \max(dp[v_i][0], dp[v_i][1]) \right\} & \text{(u与vⱼ匹配)}
\end{cases}$$

## 具体解法

### 算法流程

```
1. 读取输入，构建树的邻接表
2. 以节点1为根，进行DFS
3. 在DFS过程中，自底向上计算DP值
4. 返回 dp[1][0]（根节点不参与匹配的最大值）
```

### 伪代码

```
function DFS(u, parent):
    children = [v | v是u的子节点且v≠parent]
    
    // 递归计算所有子节点
    for each v in children:
        DFS(v, u)
    
    // 状态1：u已匹配
    dp[u][1] = sum(dp[v][0] for v in children)
    
    // 状态0：u不匹配
    base_value = sum(max(dp[v][0], dp[v][1]) for v in children)
    dp[u][0] = base_value
    
    // 尝试u与每个子节点v匹配
    for each v in children:
        match_value = value[u] * value[v] + dp[v][0]
        other_value = sum(max(dp[w][0], dp[w][1]) for w in children if w≠v)
        dp[u][0] = max(dp[u][0], match_value + other_value)
```

### 复杂度分析

- **时间复杂度**：O(n × d_max)
  - 其中d_max是树的最大度数
  - 每个节点遍历一次：O(n)
  - 对每个节点，需要遍历所有子节点：最坏情况O(n)（链状树）
  - 平均情况下，树的度数较小，实际复杂度接近O(n)

- **空间复杂度**：O(n)
  - DP数组：O(n)
  - 递归栈：O(树高) ≤ O(n)

## 样例分析

**输入**：
```
5
1 2
1 3
2 4
2 5
1 2 3 4 5
```

**树的结构**：
```
      1(v=1)
     / \
    2   3
   / \   (v=3)
  4   5
(v=4)(v=5)
```

其中v=i表示节点i的吸光能力值。

**DP计算过程**（从叶子到根）：

1. **节点4（叶子节点）**：
   - 无子节点
   - dp[4][0] = 0（不匹配）
   - dp[4][1] = 0（已匹配，无子节点）

2. **节点5（叶子节点）**：
   - dp[5][0] = 0
   - dp[5][1] = 0

3. **节点3（叶子节点）**：
   - dp[3][0] = 0
   - dp[3][1] = 0

4. **节点2**：
   - 子节点：4, 5
   - dp[2][1] = dp[4][0] + dp[5][0] = 0 + 0 = 0
   - dp[2][0]方案：
     - 不匹配：max(dp[4][0],dp[4][1]) + max(dp[5][0],dp[5][1]) = 0
     - 与4匹配：2×4 + dp[4][0] + max(dp[5][0],dp[5][1]) = 8 + 0 + 0 = 8
     - 与5匹配：2×5 + dp[5][0] + max(dp[4][0],dp[4][1]) = 10 + 0 + 0 = 10
   - dp[2][0] = max(0, 8, 10) = 10

5. **节点1（根）**：
   - 子节点：2, 3
   - dp[1][1] = dp[2][0] + dp[3][0] = 10 + 0 = 10（不会用到）
   - dp[1][0]方案：
     - 不匹配：max(dp[2][0],dp[2][1]) + max(dp[3][0],dp[3][1]) = 10 + 0 = 10
     - 与2匹配：1×2 + dp[2][0] + max(dp[3][0],dp[3][1]) = 2 + 10 + 0 = 12
     - 与3匹配：1×3 + dp[3][0] + max(dp[2][0],dp[2][1]) = 3 + 0 + 10 = 13
   - dp[1][0] = max(10, 12, 13) = **13**

**最优方案**：
- 节点1和节点3匹配：收益 1×3 = 3
- 节点2和节点5匹配：收益 2×5 = 10
- 总收益：3 + 10 = **13** ✓

## 代码实现

```python
from collections import defaultdict

def dfs(u, parent, graph, value, dp):
    """树形DP求解"""
    children = [v for v in graph[u] if v != parent]
    
    # 递归计算所有子节点
    for v in children:
        dfs(v, u, graph, value, dp)
        dp[u][1] += dp[v][0]
    
    # 计算dp[u][0]
    base_value = sum(max(dp[v][0], dp[v][1]) for v in children)
    dp[u][0] = base_value
    
    # 尝试u与每个子节点v匹配
    for v in children:
        match_value = value[u] * value[v] + dp[v][0]
        other_value = sum(max(dp[w][0], dp[w][1]) for w in children if w != v)
        dp[u][0] = max(dp[u][0], match_value + other_value)

def solve():
    n = int(input())
    graph = defaultdict(list)
    
    for _ in range(n - 1):
        a, b = map(int, input().split())
        graph[a].append(b)
        graph[b].append(a)
    
    values = [0] + list(map(int, input().split()))  # 1-indexed
    dp = [[0, 0] for _ in range(n + 1)]
    
    dfs(1, -1, graph, values, dp)
    print(dp[1][0])
```

## 算法优化技巧

### 优化1：避免重复计算

在计算dp[u][0]时，我们多次计算了 `sum(max(dp[w][0], dp[w][1]))`。

可以预先计算这个基础值：

```python
base = sum(max(dp[v][0], dp[v][1]) for v in children)
dp[u][0] = base

for v in children:
    # 从base中减去v的贡献，加上匹配的收益
    current = base - max(dp[v][0], dp[v][1]) + value[u] * value[v] + dp[v][0]
    dp[u][0] = max(dp[u][0], current)
```

时间复杂度从O(k²)降到O(k)（k为子节点数）。

### 优化2：使用迭代器

对于大规模数据，避免创建临时列表，使用生成器表达式。
