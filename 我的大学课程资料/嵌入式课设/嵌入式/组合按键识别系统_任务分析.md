# Task Description
根据题目.md的要求，实现查询方式识别组合按键→十进制数的嵌入式系统课程设计。具体要求：

1. 通过查询方式识别K1、K2按键组合输入的四位十进制数
   - K1按下次数表示个位
   - K2按下次数表示十位  
   - K2保持按下状态下，K1按下次数表示百位
   - K1保持按下状态下，K2按下次数表示千位

2. LED显示控制：
   - LED1对应个位，LED2对应十位，LED3对应百位，LED4对应千位
   - K3按下时：四个LED按1秒间隔闪烁对应数字次数（定时器中断实现）
   - K4按下时：根据比较值判断显示双向跑马灯或闪烁低两位数字

3. 其他功能：
   - K3+K4组合：清除设置，LED闪3次后熄灭，进入初始状态
   - 需要软件消抖和实时按键检测

## 定时器配置深度分析

### Timer初始化参数详解：
从timer_init(0,65,4,62500,0)可以看出：
- utimer=0：使用Timer0
- uprescaler=65：预分频系数为65+1=66
- udivider=4：在TCFG1中对应16分频值  
- utcntb=62500：计数初值，决定定时周期
- utcmpb=0：比较值，这里用不到

### 时钟计算公式：
- PCLK = 66.5MHz (从clock.c得出)
- Timer输入时钟 = PCLK / (prescaler+1) / divider = 66.5MHz / 66 / 16 = 62500Hz
- 定时周期 = utcntb / Timer输入时钟 = 62500 / 62500 = 1秒

### 不同时间间隔的配置：
- 1秒：tcntb = 62500
- 2秒：tcntb = 125000  
- 0.5秒：tcntb = 31250

## 题目需求深度解析

### 按键组合状态机设计：
1. **正常模式**：K1、K2独立计数
   - K1按下次数 → 个位数字(0-9)
   - K2按下次数 → 十位数字(0-9)

2. **K2保持模式**：K2按住不放，K1计数
   - K1按下次数 → 百位数字(0-9)
   - 需要检测K2的持续按下状态

3. **K1保持模式**：K1按住不放，K2计数  
   - K2按下次数 → 千位数字(0-9)
   - 需要检测K1的持续按下状态

### LED显示逻辑分析：
1. **K3触发数字显示**：
   - LED1~LED4依次闪烁对应数字次数
   - 每位数字闪烁完毕后间隔1秒再显示下一位
   - 需要状态机管理当前显示的位和闪烁次数

2. **K4触发比较判断**：
   - 计算当前日期各位数字之和作为比较值
   - 例如2025-12-19 → 2+0+2+5+1+2+1+9 = 22
   - 如果设置的四位数是22的倍数：双向跑马灯
   - 否则：闪烁低两位数字对应次数

3. **双向跑马灯模式**：
   - LED1→LED2→LED3→LED4→LED3→LED2→LED1循环
   - 每秒切换一次，同时只有一个LED亮

4. **K3+K4复合操作**：
   - 检测K3保持按下状态下K4按下
   - 清除四位数字，LED全部闪3次后熄灭

### 软件消抖策略：
- 按键按下检测到变化后延时一定时间再确认
- 按键释放也需要消抖处理
- 考虑使用状态机处理按键的稳定状态
