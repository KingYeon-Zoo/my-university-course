## 🔧 硬件配置详情

### 按键配置 (来自 Tiny6410/irq/irq.c)
- **端口**: GPN0-3 (K1-K4)
- **寄存器**: GPNCON=0x7F008830, GPNDAT=0x7F008834
- **中断**: 双边沿触发，支持按下/释放检测
- **消抖**: 50ms软件消抖

### LED配置 (来自 Tiny6410/leds_s/start.S)
- **端口**: GPK4-7 (LED1-4)
- **寄存器**: GPKCON0=0x7F008800, GPKDAT=0x7F008808
- **逻辑**: 低电平=亮，高电平=灭

### 定时器配置 (来自 Tiny6410/timer/timer.c)
- **Timer0**: 预分频66，16分频，62500Hz
- **中断**: VIC0中断控制器，Timer0中断向量
- **精度**: 1秒准确定时

## 🚀 功能演示

### 任务1：组合按键识别四位十进制数

**工作模式**：
1. **正常模式**：
   - 按K1 → 个位数字+1 (0-9循环)
   - 按K2 → 十位数字+1 (0-9循环)

2. **K2保持模式**：
   - 按住K2不放，按K1 → 百位数字+1

3. **K1保持模式**：
   - 按住K1不放，按K2 → 千位数字+1

**示例操作**：
```
按K1三次        → 个位=3  (0003)
按K2两次        → 十位=2  (0023)  
按住K2，按K1一次 → 百位=1  (0123)
按住K1，按K2五次 → 千位=5  (5123)
```

### 任务2：K3触发LED显示数字

**显示逻辑**：
- 按K3 → 开始数字显示
- LED1显示个位数字（闪烁次数=个位值）
- 1秒间隔后LED2显示十位数字
- 1秒间隔后LED3显示百位数字  
- 1秒间隔后LED4显示千位数字
- 数字0显示为闪烁10次

**示例显示**（数字1234）：
```
LED1闪1次  → 1秒间隔 → LED2闪2次 → 1秒间隔 → LED3闪3次 → 1秒间隔 → LED4闪4次
```

## 📋 关键技术特点

### 1. 五状态按键状态机
```
IDLE → COUNTING_ONES (K1计数个位)
IDLE → COUNTING_TENS (K2计数十位)
COUNTING_ONES → K2_HOLD_MODE (K2保持+K1计数百位)
COUNTING_TENS → K1_HOLD_MODE (K1保持+K2计数千位)
```

- 嵌入式系统友好

## 📝 注意事项

1. **硬件兼容性**：代码基于Tiny6410开发板设计，其他硬件需要修改寄存器地址
2. **时钟依赖性**：定时精度依赖于系统时钟66.5MHz，如有变化需调整分频系数
3. **中断处理**：确保系统支持中断嵌套和VIC中断控制器
4. **栈空间**：启动文件设置栈指针为0x50000000，确保内存可用
