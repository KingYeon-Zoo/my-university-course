## 4.2 AddCustom向量加法算子

**输入参数**：
1. x：输入张量1
2. y：输入张量2

**输出参数**：
1. z：输出张量（z = x + y）

```
Algorithm: AddCustomOperator

BEGIN
    1. 初始化阶段：
       1.1 分配本地内存缓冲区
       1.2 初始化输入队列inQueueX、inQueueY
       1.3 初始化输出队列outQueueZ
    
    2. FOR each tile in (TILE_NUM × BUFFER_NUM) DO
       
       2.1 CopyIn阶段（数据搬入）：
           2.1.1 从全局内存读取x的第i个tile到本地内存xLocal
           2.1.2 从全局内存读取y的第i个tile到本地内存yLocal
           2.1.3 将xLocal压入inQueueX
           2.1.4 将yLocal压入inQueueY
       
       2.2 Compute阶段（执行计算）：
           2.2.1 从inQueueX弹出xLocal
           2.2.2 从inQueueY弹出yLocal
           2.2.3 执行逐元素加法：zLocal = xLocal + yLocal
           2.2.4 将zLocal压入outQueueZ
       
       2.3 CopyOut阶段（结果写回）：
           2.3.1 从outQueueZ弹出zLocal
           2.3.2 将zLocal写入z的全局内存对应位置
    
    3. END FOR
    
    4. 释放资源
END
```

### 6.2 系统信息收集脚本

```bash
#!/usr/bin/env bash
set -euo pipefail

ts="$(date +%Y%m%d_%H%M%S)"
out="sys_report_${ts}.txt"

exec > >(tee -a "$out") 2>&1

sep() { echo -e "\n==================== $1 ====================\n"; }
have() { command -v "$1" >/dev/null 2>&1; }

sep "0) 基本信息（你当前环境）"
echo "User: $(whoami)"
echo "Workdir: $(pwd)"
echo "Time: $(date)"
echo "Report file: $out"

sep "1) CPU 信息"
if have lscpu; then
  echo "---- lscpu ----"
  lscpu
else
  echo "未找到 lscpu，改用 /proc/cpuinfo 摘要。"
fi

echo
echo "---- /proc/cpuinfo 关键字段（型号/主频等）----"
grep -E '^(model name|Hardware|processor|cpu MHz|BogoMIPS|CPU architecture|Architecture|Revision)' /proc/cpuinfo 2>/dev/null | head -n 120 || true

echo
echo "---- 负载情况 ----"
uptime || true
echo "LoadAvg: $(cat /proc/loadavg 2>/dev/null || echo N/A)"

sep "2) 内存（RAM）信息"
if have free; then
  echo "---- free -h ----"
  free -h
else
  echo "未找到 free，改用 /proc/meminfo。"
fi

echo
echo "---- /proc/meminfo（关键字段）----"
grep -E '^(MemTotal|MemFree|MemAvailable|Buffers|Cached|SwapTotal|SwapFree|HugePages_Total|HugePages_Free|Hugepagesize)' /proc/meminfo 2>/dev/null || true

sep "3) 存储信息"
echo "---- df -hT（容量/使用率）----"
df -hT 2>/dev/null || df -h || true

echo
echo "---- lsblk（块设备结构）----"
if have lsblk; then
  lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINT,MODEL
else
  echo "未找到 lsblk。"
fi

sep "4) NPU 信息（Ascend）"
if have npu-smi; then
  echo "---- npu-smi 路径 ----"
  command -v npu-smi
  echo

  echo "---- npu-smi info（精简：版本 + 关键表格；包含功率/温度/AICore/显存等）----"
  npu-smi info | awk '
    /\| npu-smi/ {print; next}
    BEGIN{p=0}
    /^\+[-+]+\+$/ { if(p==0) p=1 }
    p==1{
      if($0 ~ /\| NPU     Chip/){ exit }
      print
    }
  ' || true

  echo
  echo "（如需完整输出：运行 npu-smi info ）"
else
  echo "未找到 npu-smi。"
fi

sep "5) 系统信息"
echo "---- /etc/os-release ----"
cat /etc/os-release 2>/dev/null || true

echo
echo "---- uname -a（内核信息）----"
uname -a || true

echo
echo "---- hostname / hostnamectl ----"
hostname || true
if have hostnamectl; then
  hostnamectl || true
else
  echo "hostnamectl 不存在（可能无 systemd）。"
fi

sep "6) 网络信息（IP/MAC）"
if have ip; then
  echo "---- IP 地址（ip -brief addr）----"
  ip -brief addr || true
  echo
  echo "---- MAC 地址（ip -brief link）----"
  ip -brief link || true
else
  echo "未找到 ip（建议安装 iproute2）。"
  for f in /sys/class/net/*/address; do
    [ -f "$f" ] && echo "$(basename "$(dirname "$f")"): $(cat "$f")"
  done
fi

echo
echo "---- ifconfig（可选）----"
if have ifconfig; then
  ifconfig || true
else
  echo "未找到 ifconfig（可选安装 net-tools）。"
fi

sep "完成"
echo "已保存到：$out"
```

### 6.9 算子实现分析

查看算子具体实现：

```bash
cat add_custom.cpp
```

**图11：AddCustom算子源代码**

![](C:\Users\young\AppData\Roaming\marktext\images\2026-01-16-23-28-15-image.png)

该算子的主要处理过程分为三个阶段：

1. **CopyIn阶段（数据搬入）**：在此阶段，算子从全局内存中按顺序读取对应的数据片段（长度为TILE_LENGTH），包括输入张量x和y，将其搬运到芯片内部的本地内存中，以便后续计算使用。该过程通过DataCopy接口实现，并将数据暂存于输入队列（inQueueX和inQueueY）中。

2. **Compute阶段（执行加法计算）**：从输入队列中取出已搬入本地的数据，算子在本地执行逐元素加法操作：对x和y中每个对应位置的数据进行计算，结果写入新的本地张量zLocal中。计算完成后，结果张量被压入输出队列（outQueueZ），等待写回全局内存。

3. **CopyOut阶段（结果写回）**：算子从输出队列中取出每个tile对应的结果数据zLocal，并将其写入目标张量z在全局内存中的相应位置。该过程同样使用DataCopy接口实现，确保数据正确存储并供后续程序访问。

以上三个阶段按顺序循环执行，共处理TILE_NUM × BUFFER_NUM个tile，形成完整的张量加法操作流程。各阶段通过队列机制协同，利用双缓冲隐藏数据搬运与计算的延迟，从而提高整体算子执行效率。
