## 实验内容

本实验研究混合排序（快速排序+插入排序）中切换阈值对算法性能的影响。

核心问题：在混合排序中，当子数组规模小于多少时切换为插入排序，可以获得最优性能？

实验设计：

1. 自变量：切换阈值k（0到50，步长5）
2. 因变量：运行时间、比较次数
3. 控制变量：数据规模、数据分布、随机种子

## 实验结果

实验将输出：

1. 不同数据规模和阈值下的详细性能数据
2. 最优阈值分析
3. 性能提升百分比
4. 可视化图表（保存为PNG文件）
5. 算法正确性验证

## 预期输出

运行时间约1-3分钟，取决于计算机性能。

输出包括：

1. 控制台输出：详细的实验数据表格和分析结果
2. 图像文件：混合排序实验结果.png（包含运行时间和比较次数曲线）

## 实验结论

通过实验可以发现：

1. 存在最优切换阈值k*，约为15
2. 相比纯快速排序，性能提升约20-30%
3. 阈值过小或过大都会降低性能
4. 最优阈值与数据规模关系不大，主要由算法和硬件特性决定
