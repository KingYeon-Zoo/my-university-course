💡 Reflexion 核心思想
================================================================================

Reflexion 是一种新颖的强化学习方法，通过"语言反思"让AI从失败中学习：

  1. 执行任务 → 尝试完成任务
  2. 失败检测 → 识别失败原因
  3. 语言反思 → 生成自然语言形式的经验总结
  4. 记忆存储 → 将反思存入短期记忆
  5. 改进重试 → 利用反思改进策略

优势：
  ✓ 可解释性强 - 反思是自然语言
  ✓ 无需重训练 - 不修改模型参数
  ✓ 快速适应   - 从少量失败中学习
  ✓ 泛化能力强 - 反思可迁移到相似任务

❓ 常见问题
================================================================================

Q: 这是真实运行的结果吗？
A: 这是模拟结果，但数据完全基于论文报告的真实性能。由于没有API和
   算力，我们创建了高度仿真的模拟，能够准确展示Reflexion的工作原理。

Q: 可以修改参数吗？
A: 可以！编辑 simulate_reflexion.py，修改 num_envs（环境数量）、
   num_trials（试验次数）等参数。

Q: 图表显示不正常怎么办？
A: 确保安装了matplotlib：pip install matplotlib
   如果中文显示有问题，可能需要安装中文字体。

Q: 可以用于其他论文吗？
A: 这个框架可以适配，只需修改任务类型、成功率数据等参数即可。
