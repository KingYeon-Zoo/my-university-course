# 说明

期末报告是关于该课程教学内容、过程及效果的一种记录和总结，因此，应注意以下事项和要求：

1. 期末报告要求：格式规范，语言表达清楚，数据和程序真实。并能够理论联系实际，认真分析研究中出现的问题与现象，总结经验。

2. 每位同学应独立完成期末报告的撰写，严禁抄袭或拷贝，否则，一经查实，按作弊论取，并取消成绩。

3. 可根据实际需要调整每个章节的标题和篇幅，但是不建议超过40页。

4. 请按照要求填写期末报告。算法的核心源代码（非全部代码）请放置在附录中。

# 本报告的要求如下：

□ 选取一篇满足下述条件的论文进行深入学习：

(1) 发表时间须为近三年内（即2023年及以后）；

(2) 论文主题应涉及智能体（AI Agent）、大模型（Large Language Model, LLM）或检索增强生成（Retrieval-Augmented Generation, RAG）等相关领域；

(3) 论文中有源代码、且代码需要能在自己电脑上跑通;

(4) 论文发表于计算机学会 (CCF) 或人工智能学会 (CAAI) 推荐的 A/B 类期刊与会议、或 IEEE/ACM Transactions 系列期刊 (如 IEEE TKDE、IEEE TPAMI 等), 或虽为预印本 (提交于 arXiv 等平台)、但作者单位隶属于国内外权威机构 (如国内外知名院校, 或谷歌、OpenAI 等工业界领先企业)。

学习要求（需在报告中体现）：

(1) 需阐明该论文所解决的问题及其当前研究现状；

(2) 需阐述论文解决该问题的核心思想；

(3) 需撰写算法伪代码，并对关键步骤添加注释；

(4) 需在本地计算机上运行程序代码, 提供截图, 并尽力理解源代码, 在报告中呈现对算法的解读, 且在实验结果部分展示自行运行代码的相关截图。

# 本报告的目的：

巩固《算法设计与分析》课程中所学的算法设计与分析方法，深入理解论文所提出算法的设计思路、核心原理及性能优化策略；通过成功运行并分析论文源代码，验证算法的可行性与有效性，掌握算法在实际编程环境中的实现细节与调试技巧；同时，结合课程知识对论文中的实验设计、结果分析进行批判性思考，总结算法的优势与不足，培养独立开展算法研究与实践的能力，为后续的专业学习或科研工作积累宝贵经验。
