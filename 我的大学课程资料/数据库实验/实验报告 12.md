**四、实验步骤**

1. 搭建 macOS 下的 openGauss 实验环境

本实验在 macOS 系统中使用 Docker 部署 openGauss 数据库。首先打开 Docker Desktop，确认 Docker 服务已经正常运行。然后在终端中启动 openGauss 数据库容器。

```bash
docker run --name opengauss \
--privileged=true \
-d \
-e GS_PASSWORD=OpenGauss@123 \
-p 15432:5432 \
enmotech/opengauss:latest
```

启动完成后，在终端中查看容器运行状态。

```bash
docker ps
```

如果能够看到 openGauss 容器处于运行状态，说明数据库服务已经启动成功。

【截图1插入位置：macOS 终端或 Docker Desktop 中显示 openGauss 容器正在运行的界面】

2. 使用 DBeaver 连接 openGauss 数据库

打开 DBeaver，选择新建数据库连接。由于 openGauss 与 PostgreSQL 协议兼容性较高，可以选择 PostgreSQL 类型进行连接。连接参数设置如下：

| 项目   | 内容          |
| ------ | ------------- |
| 主机   | localhost     |
| 端口   | 15432         |
| 数据库 | postgres      |
| 用户名 | gaussdb       |
| 密码   | OpenGauss@123 |

填写完成后，点击“测试连接”。如果提示连接成功，说明 DBeaver 已经成功连接到 macOS 中运行的 openGauss 数据库。

【截图2插入位置：DBeaver 成功连接 openGauss 数据库的界面】

3. 创建 EDUC 数据库

连接成功后，在 SQL 编辑器中创建本次实验使用的 EDUC 数据库。

```sql
CREATE DATABASE educ;
```

然后重新连接或切换到 `educ` 数据库，作为后续实验操作的当前数据库。

4. 创建教学管理系统基本表

在 EDUC 数据库中创建实验所需的基本表。本实验创建系表、专业表、教师表、学生表、课程表和学生选课表。由于 openGauss 中不使用 SQL Server 的 `GO` 语句，因此所有 SQL 语句直接逐条执行。

```sql
CREATE TABLE dept (
    dept_id CHAR(4) PRIMARY KEY,
    dept_name VARCHAR(20) NOT NULL,
    dept_director VARCHAR(20),
    phone VARCHAR(20),
    address VARCHAR(40)
);

CREATE TABLE major (
    major_id CHAR(2) PRIMARY KEY,
    major_name VARCHAR(40) NOT NULL,
    dept_id CHAR(4),
    FOREIGN KEY (dept_id) REFERENCES dept(dept_id)
);

CREATE TABLE teacher (
    teacher_id CHAR(10) PRIMARY KEY,
    teacher_name VARCHAR(20) NOT NULL,
    dept_id CHAR(4),
    phone VARCHAR(20),
    email VARCHAR(40),
    FOREIGN KEY (dept_id) REFERENCES dept(dept_id)
);

CREATE TABLE student (
    sno CHAR(10) PRIMARY KEY,
    sname VARCHAR(20) NOT NULL,
    ssex CHAR(2),
    sage INT,
    major_id CHAR(2),
    FOREIGN KEY (major_id) REFERENCES major(major_id)
);

CREATE TABLE course (
    cno CHAR(4) PRIMARY KEY,
    cname VARCHAR(40) NOT NULL,
    cpno CHAR(4),
    credit INT,
    select_count INT DEFAULT 0
);

CREATE TABLE sc (
    sno CHAR(10),
    cno CHAR(4),
    grade INT,
    PRIMARY KEY (sno, cno),
    FOREIGN KEY (sno) REFERENCES student(sno),
    FOREIGN KEY (cno) REFERENCES course(cno)
);
```

执行完成后，在 DBeaver 左侧数据库对象列表中刷新，可以看到相关表已经创建成功。

【截图3插入位置：DBeaver 中 EDUC 数据库下基本表创建成功的界面】

5. 完成数据插入、修改和删除操作

首先向各个基本表插入实验数据。插入数据时需要注意表之间的参照完整性，应该先插入系表，再插入专业表、教师表、学生表、课程表，最后插入学生选课表。

```sql
INSERT INTO dept VALUES
('D001', '计算机系', '王主任', '05510001', '信息楼101'),
('D002', '数学系', '李主任', '05510002', '教学楼201'),
('D003', '电子系', '赵主任', '05510003', '实验楼301'),
('D004', '管理系', '钱主任', '05510004', '文科楼401');

INSERT INTO major VALUES
('01', '软件工程', 'D001'),
('02', '计算机科学与技术', 'D001'),
('03', '网络工程', 'D001'),
('04', '信息安全', 'D001'),
('05', '数学与应用数学', 'D002'),
('06', '电子信息工程', 'D003'),
('07', '通信工程', 'D003'),
('08', '工商管理', 'D004');
```

然后对学生表、课程表和选课表继续插入数据。插入完成后，可以执行查询语句检查数据是否正确。

```sql
SELECT * FROM dept;
SELECT * FROM major;
SELECT * FROM student;
SELECT * FROM course;
SELECT * FROM sc;
```

接着进行数据修改操作。例如，将某位学生的专业号修改为存在的专业号时，操作可以成功执行。

```sql
UPDATE student
SET major_id = '03'
WHERE sno = '20180001';
```

如果将学生的专业号修改为不存在的专业号，则会违反外键约束，openGauss 会拒绝该操作。

```sql
UPDATE student
SET major_id = '99'
WHERE sno = '20180001';
```

然后修改某门课程的成绩，并将 50 到 59 分之间的成绩整体增加 10 分。

```sql
UPDATE sc
SET grade = 85
WHERE sno = '20180001' AND cno = 'C101';

UPDATE sc
SET grade = grade + 10
WHERE grade BETWEEN 50 AND 59;
```

最后插入一个专业号为空的学生，再删除所有未设定专业号的学生。

```sql
INSERT INTO student VALUES
('20189999', '临时学生', '男', 20, NULL);

DELETE FROM student
WHERE major_id IS NULL;
```

6. 完成数据查询与聚集函数查询

在 openGauss 中执行单表查询、多表查询、嵌套查询和聚集函数查询。首先查询全体学生信息。

```sql
SELECT * FROM student;
```

查询计算机系全体学生的学号、姓名和专业名称。

```sql
SELECT s.sno, s.sname, m.major_name
FROM student s
JOIN major m ON s.major_id = m.major_id
JOIN dept d ON m.dept_id = d.dept_id
WHERE d.dept_name = '计算机系';
```

查询每门课程的课程号、选课人数、平均成绩、最高分和最低分。

```sql
SELECT cno,
       COUNT(*) AS 选课人数,
       AVG(grade) AS 平均成绩,
       MAX(grade) AS 最高分,
       MIN(grade) AS 最低分
FROM sc
GROUP BY cno;
```

查询选修课程超过 2 门的学生学号和姓名。

```sql
SELECT s.sno, s.sname
FROM student s
JOIN sc ON s.sno = sc.sno
GROUP BY s.sno, s.sname
HAVING COUNT(sc.cno) > 2;
```

7. 创建并使用视图

根据实验要求，在 openGauss 中创建学生选课成绩视图、学生出生年份视图、学生平均成绩视图和课程平均成绩视图。

```sql
CREATE VIEW v_sc_g AS
SELECT s.sno, s.sname, c.cno, c.cname, sc.grade
FROM student s
JOIN sc ON s.sno = sc.sno
JOIN course c ON sc.cno = c.cno;
```

```sql
CREATE VIEW v_avg_s_g AS
SELECT s.sno, s.sname,
       COUNT(sc.cno) AS course_count,
       AVG(sc.grade) AS avg_grade
FROM student s
JOIN sc ON s.sno = sc.sno
GROUP BY s.sno, s.sname;
```

创建完成后，查询视图结果。

```sql
SELECT * FROM v_sc_g;
SELECT * FROM v_avg_s_g;
```

通过视图查询平均成绩达到 90 分及以上的学生。

```sql
SELECT *
FROM v_avg_s_g
WHERE avg_grade >= 90;
```

8. 创建、测试并删除触发器

在 openGauss 中创建触发器时，需要先创建触发器函数，再创建触发器。下面创建一个在选课表插入记录后自动更新课程表选课人数的触发器。

```sql
CREATE OR REPLACE FUNCTION fn_sc_insert()
RETURNS trigger AS $$
BEGIN
    UPDATE course
    SET select_count = select_count + 1
    WHERE cno = NEW.cno;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

```sql
CREATE TRIGGER tr_sc_insert
AFTER INSERT ON sc
FOR EACH ROW
EXECUTE PROCEDURE fn_sc_insert();
```

插入一条新的选课记录，观察课程表中对应课程的选课人数是否发生变化。

```sql
INSERT INTO sc VALUES ('20180001', 'C102', 88);

SELECT cno, cname, select_count
FROM course
WHERE cno = 'C102';
```

实验完成后，删除触发器和触发器函数。

```sql
DROP TRIGGER tr_sc_insert ON sc;
DROP FUNCTION fn_sc_insert();
```

9. 创建、调用并删除存储过程

在 openGauss 中创建无参数存储过程，用于查询学生表中的所有学生信息。

```sql
CREATE OR REPLACE PROCEDURE proc_query_all_students()
AS
BEGIN
    SELECT * FROM student;
END;
/
```

创建带输入参数的存储过程，根据学号查询学生信息。

```sql
CREATE OR REPLACE PROCEDURE proc_query_student_by_sno(IN p_sno CHAR(10))
AS
BEGIN
    SELECT sno, sname, ssex, sage
    FROM student
    WHERE sno = p_sno;
END;
/
```

调用存储过程。

```sql
CALL proc_query_all_students();

CALL proc_query_student_by_sno('20180001');
```

实验完成后删除存储过程。

```sql
DROP PROCEDURE proc_query_all_students();

DROP PROCEDURE proc_query_student_by_sno(CHAR);
```

**五、实验小结**

通过本次实验，我在 macOS 系统上完成了 openGauss 数据库的部署、连接和基本操作。由于 macOS 无法直接使用 SQL Server Management Studio，本实验采用 Docker 部署 openGauss，并使用 DBeaver 作为图形化数据库管理工具，完成了 EDUC 数据库的创建和实验六至实验十一的主要内容。

在实验过程中，我进一步熟悉了 openGauss 数据库中表、约束、视图、触发器和存储过程的创建方法。通过数据插入、修改和删除操作，验证了实体完整性和参照完整性的作用；通过 SELECT 查询和聚集函数查询，加深了对单表查询、多表连接查询、分组统计查询的理解；通过视图实验，认识到视图可以简化复杂查询；通过触发器和存储过程实验，理解了数据库在自动维护数据和封装业务逻辑方面的能力。

同时，本实验也让我认识到 openGauss 与 SQL Server 在语法上的差异。例如，openGauss 中不使用 `GO` 分隔语句，触发器需要先定义触发器函数，存储过程的创建和调用方式也与 SQL Server 有所不同。因此，在不同数据库系统之间迁移 SQL 语句时，不能简单复制，需要根据具体数据库的语法规则进行调整。

总体来说，本次实验完成了在 macOS 系统下使用 openGauss 重复数据库综合实验的要求，提高了我在非 Windows 环境下进行数据库实验的能力，也增强了我对不同数据库系统之间差异的理解。
