# 实验一、缓存性能分析

# 实验内容：

- 基于SimpleScalar模拟器，通过运行SPEC2000-Alpha基准测试中的workloads并对结果进行分析，深入理解缓存的三个参数（缓存大小、block size、相联度）对缓存性能的影响。

# 实验目的：

- 了解 Cache 的基本概念、基本组织结构  
- 了解影响 Cache 性能的三个指标  
了解相联度对Cache的影响  
- 了解块大小对Cache的影响

# 实验步骤：

1. 安装和测试 SimpleScalar 模拟器 (利用模拟器自带的测试程序进行测试)。该步骤不需要大家完成，已经为大家按照好了，并以虚拟机的形式提供给大家了。  
2. 在基本配置（L1指令和数据缓存均为16KB、2路组相联；L2统一缓存（指令和数据在一起）256KB、8路组相联；块大小统一为64B；均采取LRU替换算法）下运行CINT2000基准测试集下面的3个测试程序(每位同学自行选择，请指明自己选的是哪些测试程序)。统计L2缓存的失效次数（注：配置哈佛架构的二级缓存，指令和数据合在一起）。  
3. 不改变 L2 缓存的其它配置, 仅改变 L2 缓存的容量 (64KB、128KB、256KB、512KB、1024KB), 运行上面选择的 3 个测试程序, 并统计 L2 缓存的失效次数计算失效率, 并对结果进行总结、作图并分析。  
4. 不改变 L2 缓存的其它配置（容量固定为 512KB），仅改变 L2 缓存的相联度（2 路，4 路，8 路，16 路，64 路），运行上面所选择的 3 个测试程序，并统计 L2 缓存的失效次数，并计算失效率，并对结果进行汇总、作图并分析。  
5. 不改变L2缓存的其它配置（容量固定为512KB），仅改变L2缓存的块大小（64B，128B，256B，512B），运行上面选择的3个测试程序，并统计L2缓存的失效次数计算失效率，并进行分析。
