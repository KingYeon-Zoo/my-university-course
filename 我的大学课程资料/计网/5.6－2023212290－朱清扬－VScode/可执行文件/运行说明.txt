2. 安装依赖库
   打开命令行/终端，进入"源程序"文件夹，执行：
   
   pip install -r requirements.txt
   
   或使用清华镜像加速安装：
   
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

3. 运行程序
   在"源程序"文件夹下执行：
   
   python main.py

【功能说明】

本工具是一个基于PyQt5的TCP协议可视化分析工具，主要功能包括：

1. TCP数据包解析
   - 支持读取Wireshark抓包文件（.pcapng格式）
   - 自动解析TCP协议各层数据

2. 三次握手/四次挥手可视化
   - 动态展示TCP连接建立过程
   - 展示连接断开过程

3. 序列号/确认号分析
   - 可视化序列号变化
   - 跟踪确认号演变

4. 流量控制分析
   - 窗口大小变化图表
   - 滑动窗口机制展示

5. 拥塞控制分析
   - 拥塞窗口变化
   - 慢启动、拥塞避免、快速重传等算法展示

6. 重传机制分析
   - 检测重传数据包
   - 统计重传率

7. TCP状态机
   - 展示TCP连接状态转换
   - 可视化状态转换过程

8. 统计信息
   - 连接数统计
   - 数据包统计
   - 流量统计

【使用方法】

1. 启动程序后，点击"选择文件"按钮
2. 选择要分析的pcapng文件（示例文件在"数据库"文件夹中）
3. 程序自动解析并展示各项分析结果
4. 切换不同的标签页查看不同的分析维度

【示例数据】

"数据库"文件夹中提供了示例抓包文件：
- example.pcapng：包含完整TCP会话的示例数据

【常见问题】

1. 如果提示缺少模块，请确保已安装所有依赖：
   pip install -r requirements.txt

2. 如果界面显示异常，请检查qt-material主题是否正确安装：
   pip install qt-material

3. 如果无法读取pcapng文件，请确保scapy库已正确安装：
   pip install scapy
