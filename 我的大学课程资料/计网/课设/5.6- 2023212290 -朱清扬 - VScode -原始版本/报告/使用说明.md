# TCP协议可视化分析工具 - 使用说明

## 一、环境配置

### 1.1 系统要求
- 操作系统：Windows 10/11, macOS, Linux
- Python版本：Python 3.8或更高版本
- Anaconda/Miniconda：推荐使用conda环境管理工具

### 1.2 创建并激活conda环境

#### 步骤1：创建conda虚拟环境
在项目根目录下打开命令行（Anaconda Prompt或终端），执行：

```bash
conda create -n tcp_analyzer python=3.8
```

#### 步骤2：激活conda环境
```bash
conda activate tcp_analyzer
```

#### 步骤3：安装依赖

**推荐方式：完全使用conda安装（最稳定）**

```bash
conda install -c conda-forge pyqt matplotlib numpy pandas scapy pyqtgraph -y
```

**备选方式1：使用pip安装**

```bash
pip install -r requirements.txt
```

**备选方式2：pip + 国内镜像源**

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 1.3 依赖包说明
- **PyQt5**: 图形用户界面框架
- **scapy**: 网络数据包解析库
- **matplotlib**: 数据可视化库
- **numpy**: 数值计算库
- **pandas**: 数据处理库
- **pyqtgraph**: 高性能图形绘制库

## 二、启动程序

### 2.1 激活conda环境
每次使用前，需要先激活conda环境：

```bash
conda activate tcp_analyzer
```

### 2.2 运行程序
在项目根目录下执行：

```bash
python main.py
```

程序将自动启动并显示主界面。

### 2.3 退出环境
使用完毕后，可以退出conda环境：

```bash
conda deactivate
```

## 三、功能使用

### 3.1 加载数据包文件

1. 点击左上角的"📁 加载文件"按钮
2. 在文件选择对话框中，选择wireshark文件夹下的`example.pcapng`文件
3. 程序会自动解析文件并识别所有TCP连接
4. 弹出提示框显示加载成功的信息

### 3.2 查看TCP连接列表

- 左侧面板显示所有识别出的TCP连接
- 每个连接显示：
  - 源IP:端口 <-> 目标IP:端口
  - 数据包数量
  - 连接持续时间

### 3.3 分析TCP连接

#### 3.3.1 连接建立/释放分析
1. 在左侧列表中点击选择一个TCP连接
2. 切换到"🤝 连接建立/释放"标签页
3. 查看详细的三次握手和四次挥手信息
4. 点击"▶ 播放三次握手"观看动画演示
5. 点击"▶ 播放四次挥手"观看断开连接动画

#### 3.3.2 序列号变化分析
1. 切换到"📊 序列号变化"标签页
2. 查看序列号和确认号随时间的变化曲线
3. 分析TCP数据传输过程

#### 3.3.3 重传分析
1. 切换到"🔄 重传分析"标签页
2. 查看检测到的重传数据包统计表
3. 点击"▶ 播放重传动画"观看丢包重传过程
4. 在统计表中查看每次重传的详细信息（序列号、时间差等）

#### 3.3.4 流量控制分析
1. 切换到"📈 流量控制"标签页
2. 查看TCP接收窗口大小的变化曲线
3. 观察窗口大小的动态调整过程
4. 查看最小、最大、平均窗口大小统计

#### 3.3.5 统计分析
1. 切换到"📉 统计分析"标签页
2. 查看连接的基本统计信息（总包数、总字节数、吞吐量等）
3. **RTT分析**子标签：
   - RTT随时间变化曲线
   - RTT分布直方图
   - 最小/最大/平均RTT统计
4. **吞吐量分析**子标签：
   - 每秒吞吐量柱状图
5. **数据包详情**子标签：
   - 详细的数据包信息表

## 四、示例数据

项目提供了示例数据文件：`wireshark/example.pcapng`

这是一个真实的网络抓包文件，包含了完整的TCP连接过程，可以用于测试程序的所有功能。

## 五、常见问题

### 5.1 conda环境相关
**问题：找不到conda命令**
- 确保已安装Anaconda或Miniconda
- Windows用户请使用"Anaconda Prompt"而非普通命令行
- 将conda添加到系统环境变量

**问题：环境激活失败**
- 检查环境名称是否正确（tcp_analyzer）
- 尝试使用完整命令：`conda activate tcp_analyzer`
- 重启命令行窗口后再试

### 5.2 程序无法启动
- 确保已激活conda环境（`conda activate tcp_analyzer`）
- 确保已安装所有依赖包
- 检查Python版本是否为3.8+
- 查看依赖包是否安装成功：`conda list` 或 `pip list`

### 5.3 无法加载pcapng文件
- 确保文件格式正确
- 尝试使用Wireshark重新保存文件

### 5.4 图表显示异常
- 尝试调整窗口大小
- 重新选择TCP连接
