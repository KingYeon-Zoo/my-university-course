# TCP协议可视化分析工具 V2.0

## 📖 项目简介
本项目是一个基于Python和PyQt5开发的**现代化TCP协议可视化分析课件程序**，采用Material Design风格界面，用于直观、生动地展示TCP协议的各种机制和行为。

## ✨ 主要功能

### 🎯 性能仪表盘（新增拓展功能）
- **实时性能监控**：圆形仪表盘显示吞吐量、RTT、丢包率
- **关键指标卡片**：总数据包、总字节数、连接时长等一目了然
- **连接健康评分**：自动评估连接质量并给出健康建议

### 🤝 连接建立/释放可视化
- **三次握手动画**：逐步演示SYN、SYN-ACK、ACK过程
- **四次挥手动画**：展示FIN、ACK交互流程
- **状态转换标注**：实时显示TCP状态（SYN_SENT、ESTABLISHED等）

### 📊 序列号分析（增强版）
- **多视图展示**：图表视图、动画视图、表格视图三种模式
- **交互式图表**：可选择显示序列号/确认号，区分数据包和ACK包
- **智能标注**：自动标记重复ACK，识别可能的丢包
- **动态动画**：数据包传输过程可视化，实时显示序列号变化
- **详细表格**：支持排序、筛选，提供数据包完整信息

### 🔄 重传分析
- **重传检测**：自动识别重传的数据包
- **动画演示**：模拟丢包和重传过程
- **统计表格**：显示重传时间差、序列号等详细信息

### 📈 流量控制
- **滑动窗口可视化**：实时显示接收窗口大小变化
- **统计分析**：最小/最大/平均窗口大小
- **零窗口标注**：突出显示零窗口事件

### 🚦 拥塞控制（新增拓展功能）
- **拥塞窗口估算**：基于数据包模式估算cwnd变化
- **阶段识别**：自动识别慢启动、拥塞避免阶段
- **算法说明**：详细介绍慢启动、快速重传、快速恢复等机制
- **性能分析**：吞吐量与拥塞控制关系可视化

### 🔀 TCP状态机（新增拓展功能）
- **状态图展示**：完整的TCP状态机图形化展示
- **状态转换动画**：逐步播放连接过程中的状态变化
- **历史记录**：详细记录每次状态转换及触发事件
- **交互式查看**：点击历史记录即可查看对应状态

### 📉 统计分析
- **RTT分析**：往返时延随时间变化曲线和分布直方图
- **吞吐量分析**：每秒吞吐量柱状图
- **数据包详情**：完整的数据包信息表格

### 💾 报告导出（新增拓展功能）
- **HTML报告生成**：一键导出美观的分析报告
- **全面数据统计**：包含所有关键性能指标
- **精美排版**：响应式设计，支持打印和分享

## 🚀 使用方法
```bash
python main.py
```

### 操作流程
1. **加载数据包文件**
   - 点击"📁 加载文件"按钮
   - 选择Wireshark捕获的pcap/pcapng格式文件
   - 程序自动解析并识别TCP连接

2. **选择TCP连接**
   - 在左侧列表中选择要分析的TCP连接
   - 查看连接的数据包数量和持续时间

3. **查看分析结果**
   - **性能仪表盘**：查看整体性能概览
   - **连接建立/释放**：播放握手和挥手动画
   - **序列号分析**：切换不同视图模式，查看序列号变化
   - **重传分析**：播放重传动画
   - **流量控制**：分析窗口变化
   - **拥塞控制**：了解拥塞控制机制
   - **状态机**：查看TCP状态转换
   - **统计分析**：深入分析RTT和吞吐量

4. **导出报告**
   - 点击"💾 导出报告"按钮
   - 选择保存位置
   - 生成包含所有分析结果的HTML报告
