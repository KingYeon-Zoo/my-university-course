# 🚀 TCP协议可视化分析工具 - 快速开始指南

## 📋 前置要求

- Python 3.8 或更高版本
- pip 包管理器
- Windows / macOS / Linux 操作系统

## 📦 安装步骤

### 1. 安装Python依赖

打开命令行/终端，进入项目目录：

```bash
cd "5.6- 2023212290 -朱清扬 - VScode"
```

安装所需的Python包：

```bash
pip install -r requirements.txt
```

**可能需要几分钟时间安装以下包：**
- PyQt5 (GUI框架)
- qt-material (主题库)
- scapy (数据包解析)
- matplotlib (图表绘制)
- numpy、pandas (数据处理)

### 2. 启动程序

安装完成后，运行主程序：

```bash
python main.py
```

## 🎮 基本使用流程

### 第一步：加载数据包文件

1. 点击左上角的 **"📁 加载文件"** 按钮
2. 选择pcap或pcapng格式的文件
   - 可以使用项目中的示例文件：`wireshark/example.pcapng`
   - 或使用Wireshark捕获的其他TCP流量文件
3. 等待程序加载和解析（会显示进度提示）
4. 加载成功后会弹出提示框，显示识别到的TCP连接数量

### 第二步：选择TCP连接

1. 在左侧的 **"TCP连接列表"** 中查看所有识别到的连接
2. 每个连接显示：
   - 源IP:端口 <-> 目标IP:端口
   - 数据包数量
   - 持续时间
3. 点击任意连接，右侧会自动加载分析结果

### 第三步：查看分析结果

程序提供8个分析标签页，建议按以下顺序查看：

#### 🎯 1. 性能仪表盘（推荐首先查看）
- **查看什么**：连接的整体性能概览
- **关键指标**：
  - 3个圆形仪表盘：吞吐量、RTT、丢包率
  - 8个指标卡片：数据包统计、时长、窗口大小等
  - 连接健康评分条
- **操作提示**：无需操作，自动显示

#### 🤝 2. 连接建立/释放
- **查看什么**：三次握手和四次挥手过程
- **关键功能**：
  - 点击 **"▶ 播放三次握手"** 观看建立连接的动画
  - 点击 **"▶ 播放四次挥手"** 观看关闭连接的动画
  - 下方显示详细的SYN、ACK信息
- **操作提示**：多点几次播放按钮，观察状态变化

#### 📊 3. 序列号分析
- **查看什么**：序列号和确认号的变化规律
- **三种视图模式**：
  1. **图表分析**：
     - 可勾选/取消 "显示序列号" 和 "显示确认号"
     - 绿色线：有数据的包
     - 蓝色点：纯ACK包
     - 黄色圆圈：重复ACK（可能丢包）
  
  2. **动画演示**：
     - 点击 **"▶ 播放动画"**
     - 观看数据包随时间传输的过程
     - 不同颜色代表不同类型的包
  
  3. **详细数据**：
     - 完整的数据包信息表格
     - 可点击表头排序
     - 数据包背景色表示是否携带数据
- **操作提示**：三种视图切换查看，全面了解序列号机制

#### 🔄 4. 重传分析
- **查看什么**：是否存在丢包重传
- **关键功能**：
  - 点击 **"▶ 播放重传动画"** 观看丢包和重传过程
  - 下方表格显示每次重传的详细信息
- **操作提示**：如果没有重传，会显示"未检测到重传"

#### 📈 5. 流量控制
- **查看什么**：TCP滑动窗口的变化
- **关键指标**：
  - 最小窗口、最大窗口、平均窗口
  - 窗口大小随时间的变化曲线
  - 红点标记：零窗口（接收方缓冲区满）
- **操作提示**：观察窗口是否有突然变小的情况

#### 🚦 6. 拥塞控制
- **查看什么**：TCP拥塞控制机制的运行情况
- **三个标签页**：
  1. **拥塞窗口演化**：
     - 蓝色线：估算的拥塞窗口(cwnd)
     - 红色虚线：慢启动阈值(ssthresh)
     - 浅蓝色背景：慢启动阶段
  
  2. **算法说明**：
     - 详细的拥塞控制算法介绍
     - 包括慢启动、拥塞避免、快速重传等
  
  3. **性能分析**：
     - 吞吐量变化曲线
     - 移动平均线
- **操作提示**：先看算法说明，再对照图表理解

#### 🔀 7. 状态机
- **查看什么**：TCP连接的状态转换过程
- **关键功能**：
  - 点击 **"▶ 播放状态转换"** 观看状态变化动画
  - 右侧显示状态转换历史记录
  - 点击历史记录可查看对应状态
  - 点击 **"🔄 重置"** 回到初始状态
- **状态说明**：
  - 绿色圆圈：当前状态
  - 蓝色圆圈：ESTABLISHED状态
  - 灰色圆圈：CLOSED状态
  - 黄色圆圈：其他过渡状态
- **操作提示**：播放动画，观察从CLOSED到ESTABLISHED再到CLOSED的完整过程

#### 📉 8. 统计分析
- **查看什么**：RTT和吞吐量的深入分析
- **三个标签页**：
  1. **RTT分析**：
     - RTT随时间变化曲线
     - RTT分布直方图
     - 最小/最大/平均RTT
  
  2. **吞吐量分析**：
     - 每秒吞吐量柱状图
  
  3. **数据包详情**：
     - 前100个数据包的详细信息表格
- **操作提示**：关注RTT是否稳定，吞吐量是否均匀

### 第四步：导出报告（可选）

1. 点击工具栏的 **"💾 导出报告"** 按钮
2. 选择保存位置和文件名
3. 程序会生成一个精美的HTML报告
4. 用浏览器打开报告文件即可查看和打印

## 💡 使用技巧

### 技巧1：对比分析
- 可以多次加载不同的文件
- 对比不同网络环境下的TCP性能

### 技巧2：关注异常
- **重传分析**中如果有很多重传 → 网络质量差
- **流量控制**中如果频繁零窗口 → 接收方处理慢
- **性能仪表盘**健康分数低 → 存在性能问题

### 技巧3：学习理解
- 先看 **拥塞控制 > 算法说明**，了解理论
- 再看各个可视化图表，理解实际运行情况
- 播放动画，加深对协议机制的理解

### 技巧4：导出分享
- 将分析报告导出为HTML
- 可以分享给老师或同学
- 也可以作为实验报告的一部分

## 🔍 常见问题

### Q1: 安装依赖时报错？
**A**: 尝试升级pip：`python -m pip install --upgrade pip`，然后重新安装

### Q2: 打开文件后显示"未识别到TCP连接"？
**A**: 确保pcap文件中包含TCP流量，可以用Wireshark验证

### Q3: 界面显示不完整？
**A**: 调整窗口大小，或将窗口最大化

### Q4: 动画播放太快/太慢？
**A**: 目前速度固定，可以重复播放观察

### Q5: 某些标签页显示"无数据"？
**A**: 可能该连接缺少对应的数据，例如没有重传、没有完整的握手等
