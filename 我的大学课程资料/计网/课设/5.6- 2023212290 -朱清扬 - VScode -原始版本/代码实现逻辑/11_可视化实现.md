## 四、动画实现

### 4.1 QTimer动画控制

```python
class AnimationWidget(QWidget):
    def start_animation(self):
        self.animation_step = 0
        self.animation_timer = QTimer()
        self.animation_timer.timeout.connect(self.next_step)
        self.animation_timer.start(500)  # 500ms/帧
    
    def next_step(self):
        if self.animation_step < self.max_steps:
            self.animation_step += 1
            self.update()  # 触发paintEvent
        else:
            self.animation_timer.stop()
```

### 5.1 Matplotlib嵌入

```python
from matplotlib.backends.backend_qt5agg import (
    FigureCanvasQTAgg as FigureCanvas
)
from matplotlib.figure import Figure

class ChartWidget(QWidget):
    def init_ui(self):
        self.figure = Figure(figsize=(10, 6))
        self.canvas = FigureCanvas(self.figure)
        layout.addWidget(self.canvas)
    
    def update_chart(self, data):
        self.figure.clear()
        ax = self.figure.add_subplot(111)
        ax.plot(data['x'], data['y'])
        ax.set_xlabel('X轴标签')
        ax.set_ylabel('Y轴标签')
        self.figure.tight_layout()
        self.canvas.draw()
```

## 八、总结

可视化模块的主要设计特点：

1. **模块化设计**: 每个功能独立为一个Widget
2. **信号槽通信**: 组件间使用信号槽解耦
3. **QTimer动画**: 定时器控制动画帧率
4. **QPainter绑制**: 自定义图形和动画
5. **Matplotlib集成**: 专业图表展示
6. **Material主题**: 现代化界面风格
