# TCP协议可视化分析工具 - 代码实现逻辑总览

## 一、项目概述

本项目是一个基于Python和PyQt5开发的**TCP协议可视化分析工具**，用于读取Wireshark抓包文件，对TCP连接进行全方位分析，并提供丰富的可视化展示功能。

## 二、系统架构

```
TCP协议可视化分析工具
├── main.py                    # 主程序入口
├── packet_parser.py           # 数据包解析核心模块
└── gui/                       # 图形界面模块
    ├── __init__.py
    ├── main_window.py         # 主窗口
    ├── dashboard_widget.py    # 性能仪表盘
    ├── handshake_widget.py    # 连接建立/释放可视化
    ├── sequence_widget.py     # 序列号分析
    ├── retransmit_widget.py   # 重传分析
    ├── flow_control_widget.py # 流量控制
    ├── congestion_widget.py   # 拥塞控制
    ├── state_machine_widget.py# TCP状态机
    └── statistics_widget.py   # 统计分析
```

## 四、技术栈

1. **Python 3.8+**: 主要开发语言
2. **PyQt5**: GUI框架，提供丰富的界面组件
3. **Scapy**: 网络数据包解析库，读取和分析pcap文件
4. **Matplotlib**: 数据可视化库，绘制各类统计图表
5. **qt-material**: Material Design主题库
6. **NumPy/Pandas**: 数据处理和计算
