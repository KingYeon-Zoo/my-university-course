# 《算法设计与分析》第一章复习大纲

## 第一部分：算法的基本概念 (§1.1)

### 1. 算法的定义与特征
*   **定义**：任何一个良定义（well-defined）的计算过程，接收某个值或集合作为输入，产生某个值或集合作为输出。算法是将输入转化为输出的计算步骤序列。
*   **算法 vs 问题**：
    *   **问题**：一般性提问（含参数、取值范围、解的条件）。
    *   **实例 (Instance)**：参数的一组具体赋值（如具体的排序数列）。
    *   **算法**：求解特定计算过程的工具。
*   **算法的5大性质**（课件中重点列出了4条，加上程序对比）：
    1.  **输入 (Input)**：0个或多个外部量。
    2.  **输出 (Output)**：至少产生1个量。
    3.  **确定性 (Definiteness)**：指令清晰、无歧义。
    4.  **有限性 (Finiteness)**：指令执行次数有限，时间有限（这是算法与程序的主要区别）。
    5.  *(补充: 可行性)*
*   **算法的正确性**：对每个输入实例均终止于正确的输出。
    *   *不正确算法*：对某些输入不停机或结果错误（若错误率可控有时也有用）。

### 2. 算法、程序与数据结构
*   **区别**：
    *   **程序**：特定语言实现，可以不满足“有限性”（如操作系统无限循环）。
    *   **算法**：解决问题的思路，无语言界限。
    *   公式：**程序 = 数据结构 + 算法**。
*   **关系**：
    *   **数据结构**（底层）：存储和组织数据，便于访问/修改。
    *   **算法**（高层）：围绕数据结构操作，为数据结构提供服务。

## 第二部分：算法描述 (§1.2)

### 1. 描述方式
*   **伪代码 (Pseudo-code)**：
    *   目的：清晰简洁地说明算法步骤，忽略语言细节。
    *   关键语法约定：
        *   赋值：`←`
        *   分支：`if ... then ... [else ...]`
        *   循环：`while`, `for`, `repeat until`
        *   过程调用：直接写名字
        *   注释：`//`
*   **其他方式**：C++语言描述（结构紧凑）、C++与自然语言结合。

### 2. 抽象数据类型 (ADT)
*   **定义**：数据模型 + 定义在该模型上的一组运算。
*   **优点**：顶层设计与底层实现分离；便于时空权衡；提高可维护性；便于证明正确性。

## 第三部分：算法分析基础 (§1.3)

### 1. 分析的目的与模型
*   **目的**：估计算法所需资源（主要是时间，其次是空间）。
*   **计算模型**：RAM（随机存取机），单处理机，指令顺序执行。

### 2. 复杂性度量
*   **时间复杂性 $T(n)$**：算法运行所需的时间资源。
    *   依赖因素：问题规模 ($N$)、输入 ($I$)、算法本身 ($A$)。
    *   **输入规模 (Input Size)**：
        *   排序/检索：元素个数 $n$。
        *   整数乘法：位数 $n$。
        *   图：顶点数 $V$ 和边数 $E$。
*   **三种情况分析**：
    1.  **最坏情况 (Worst-Case)** ($T_{max}(n)$)：通常关注点，提供运行时间的上界保证。
    2.  **平均情况 (Average-Case)** ($T_{avg}(n)$)：基于输入概率分布的期望值（通常假设等概率）。
    3.  **最好情况 (Best-Case)** ($T_{min}(n)$)：通常意义不大（"骗人的"）。

### 3. 渐进分析 (Asymptotic Analysis)
*   **核心思想**：忽略低阶项和常数因子，关注 $n \to \infty$ 时的增长率。
*   **$\Theta$ 记号 (紧确界)**：
    *   $\Theta(g(n)) = \{f(n) : \exists c_1, c_2 > 0, n_0, \forall n \ge n_0, 0 \le c_1 g(n) \le f(n) \le c_2 g(n) \}$
    *   工程意义：丢弃低阶项，忽略首项常数。
*   **$O$ 记号 (上界)** & **$\Omega$ 记号 (下界)** (课件主要侧重$\Theta$和$O$)。

## 第四部分：经典算法案例分析

### 1. 插入排序 (Insertion Sort)
*   **原理**：类似整理扑克牌，将新元素插入已排序序列中。
*   **分析**：
    *   **最好情况**（已排序）：$\Theta(n)$ (线性)。
    *   **最坏情况**（逆序）：$\Theta(n^2)$。
    *   **平均情况**：$\Theta(n^2)$。
    *   *结论*：对小规模数据有效，大规模数据效率低。

### 2. 检索问题 (Search Problem)
*   **顺序检索 (Sequential Search)**：
    *   最坏情况：$n$ 次比较。
    *   平均情况（假设存在概率 $p$，位置等概率）：
        *   $A(n) = p(n+1)/2 + (1-p)n$
        *   若 $p=1/2$，则 $A(n) \approx 3n/4$。
*   **改进顺序检索**（针对有序数组）：
    *   一旦发现当前元素大于目标值，即可停止。
    *   问题：需掌握其最坏和平均复杂度的变化。

### 3. 合并(归并)排序 (Merge Sort)
*   **原理**：分治法 (Divide and Conquer)。
    *   分解：将 $n$ 个元素分成两个 $n/2$ 的子序列。
    *   解决：递归排序子序列。
    *   合并：MERGE 关键函数，将两个有序序列合并为一个。
*   **Merge函数分析**：合并 $n$ 个元素需要 $\Theta(n)$ 时间。
*   **递归式**：$T(n) = 2T(n/2) + \Theta(n)$ （当 $n>1$）。
*   **复杂度**：$T(n) = \Theta(n \lg n)$。
*   **对比**：当 $n > 30$ 左右时，归并排序通常优于插入排序。

## 第五部分：递归式求解方法 (重点/难点)

### 1. 替代法 (Substitution Method)
*   **步骤**：
    1.  猜测解的形式。
    2.  用数学归纳法验证。
    3.  求解常数。
*   **注意**：处理边界条件和余项（可能需要加强假设，如减去一个低阶项）。

### 2. 递归树法 (Recursion Tree Method)
*   **用途**：用于生成猜测，或直接求和估算。
*   **过程**：将递归式展开成树，计算每层代价，求和。
*   **例子**：$T(n) = 2T(n/2) + cn$ 的树高为 $\lg n$，每层代价 $cn$，总代价 $\Theta(n \lg n)$。
*   **几何级数情况**：关注权重是从根到叶递增、递减还是持平。

### 3. 主方法 (Master Method) —— 核心工具
*   **适用形式**：$T(n) = aT(n/b) + f(n)$，其中 $a \ge 1, b > 1$。
*   **比较对象**：$f(n)$ 与 $n^{\log_b a}$。
*   **三种情况**：
    1.  **$f(n)$ 较小**（多项式地小 $n^\epsilon$）：$T(n) = \Theta(n^{\log_b a})$。
    2.  **两者相当**（$f(n) = \Theta(n^{\log_b a} \lg^k n)$）：$T(n) = \Theta(n^{\log_b a} \lg^{k+1} n)$。
        *   最常见情况 $k=0$：$T(n) = \Theta(n^{\log_b a} \lg n)$。
    3.  **$f(n)$ 较大**（多项式地大 $n^\epsilon$）且满足正则条件（$af(n/b) \le cf(n), c<1$）：$T(n) = \Theta(f(n))$。
*   **局限性**：若 $f(n)$ 与 $n^{\log_b a}$ 的差距不是多项式意义上的（例如只差 $\lg n$ 但不在情况2范围内），则主方法不适用。
