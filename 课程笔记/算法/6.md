# 《算法设计与分析：动态规划》复习大纲

## 第一部分：动态规划基础 (Introduction to DP)
**1. 引例：斐波那契数列 (Fibonacci Sequence)**
*   **朴素递归法**：
    *   缺点：存在大量重复计算。
    *   时间复杂度：指数级 $O(2^n)$。
*   **改进方法**：
    *   **带备忘录的自顶向下法 (Memoization)**：保留递归结构，记录已解子问题。
    *   **自底向上法 (Bottom-Up)**：迭代计算，无递归开销。
    *   复杂度优化：降至线性 $O(n)$。

**2. 动态规划核心概念**
*   **定义**：一种通过组合子问题的解而解决整个问题的表格法。
*   **与分治法 (Divide and Conquer) 的区别**：
    *   分治法：子问题相互独立。
    *   动态规划：子问题重叠 (Overlapping)，且具有公共子子问题。
*   **适用场景**：最优化问题 (Optimization Problems)。

**3. 设计动态规划算法的四个步骤**
1.  **刻画最优解结构**：寻找最优子结构特征。
2.  **递归定义最优解的值**：列出状态转移方程。
3.  **计算最优解的值**：通常采用自底向上计算。
4.  **构造最优解**：利用计算出的信息重构具体方案（如果需要）。

## 第二部分：动态规划原理 (Elements of DP)
**1. 最优子结构 (Optimal Substructure)**
*   **定义**：一个问题的最优解包含其子问题的最优解。
*   **判定方法**：
    *   “剪切-粘贴”法 (Cut-and-Paste) 反证法。
*   **反例分析**：
    *   无权最短路径（具有最优子结构）。
    *   **无权最长路径**（不具有最优子结构，因为子问题不独立/资源共享）。

**2. 重叠子问题 (Overlapping Subproblems)**
*   **特征**：递归算法会反复求解相同的子问题。
*   **数量级**：不同的子问题个数通常是多项式级别（如 $O(n^2)$），而递归树是指数级别。

**3. 实现策略对比**
*   **自顶向下带备忘录**：递归形式，按需计算，查表。
*   **自底向上**：迭代形式，计算所有子问题（如果所有子问题都需要解，此法通常效率略高，节省递归开销）。

## 第三部分：经典案例精讲 (Classic Problems)

### 案例一：钢条切割问题 (Rod Cutting)
*   **问题描述**：长度为 $n$ 的钢条，不同长度对应不同价格，求最大收益。
*   **状态定义**：$r_n$ 为长度 $n$ 的最大收益。
*   **递归公式**：
    $$r_n = \max_{1 \le i \le n} (p_i + r_{n-i})$$
*   **算法实现**：
    *   朴素递归 vs 动态规划（$O(n^2)$）。
*   **解的重构**：不仅输出最大收益，还需输出切割方案（使用 `s[j]` 数组记录第一段切割长度）。

### 案例二：矩阵链乘法问题 (Matrix Chain Multiplication)
*   **问题描述**：给定 $n$ 个矩阵序列，求标量乘法次数最少的完全括号化方案。
*   **关键特征**：矩阵乘法满足结合律，不满足交换律。
*   **状态定义**：$m[i, j]$ 表示计算矩阵链 $A_{i...j}$ 的最小乘法次数。
*   **递归公式**：
    $$m[i,j] = \begin{cases} 0 & \text{if } i=j \\ \min_{i \le k < j} \{m[i,k] + m[k+1,j] + p_{i-1}p_k p_j\} & \text{if } i < j \end{cases}$$
*   **计算顺序**：按链长 $L$ 从 2 到 $n$ 自底向上计算（沿着对角线方向）。
*   **复杂度**：时间 $O(n^3)$，空间 $O(n^2)$。
*   **解的构造**：利用 `s[i, j]` 记录分割点 $k$ 的位置。

### 案例三：最长公共子序列 (LCS)
*   **问题描述**：找出两个序列 $X$ 和 $Y$ 的最长公共子序列（不要求连续）。
*   **最优子结构定理**：
    *   若 $x_m = y_n$，则 $z_k = x_m = y_n$，且 $Z_{k-1}$ 是 $X_{m-1}$ 和 $Y_{n-1}$ 的 LCS。
    *   若 $x_m \neq y_n$，则 $Z$ 是 $X_{m-1}$ 和 $Y$ 的 LCS，或者是 $X$ 和 $Y_{n-1}$ 的 LCS。
*   **递归公式**：
    $$c[i,j] = \begin{cases} 0 & i=0 \text{ or } j=0 \\ c[i-1, j-1] + 1 & i,j>0 \text{ and } x_i=y_j \\ \max(c[i, j-1], c[i-1, j]) & i,j>0 \text{ and } x_i \neq y_j \end{cases}$$
*   **复杂度**：时间 $O(mn)$，空间 $O(mn)$。
*   **扩展**：最长上升子序列 (LIS)。

### 案例四：装配线调度 (Assembly Line Scheduling)
*   **问题描述**：两条生产线，多个工位，工位间转移有成本，求最快通过时间。
*   **状态定义**：$f_1[j]$ 和 $f_2[j]$ 分别表示在第 1 条和第 2 条线上完成第 $j$ 个工位的最快时间。
*   **递归公式**：
    *   $f_1[j] = \min(f_1[j-1] + a_{1,j}, \quad f_2[j-1] + t_{2,j-1} + a_{1,j})$
    *   $f_2[j] 同理$
*   **计算路径**：$f^* = \min(f_1[n] + x_1, f_2[n] + x_2)$。
*   **复杂度**：$O(n)$。

### 案例五：最优二叉搜索树 (Optimal Binary Search Trees - OBST)
*   **问题描述**：给定有序键值 $K$ 和哑键 $D$ 及其被搜索的概率，构造一棵期望搜索代价（费用）最小的二叉搜索树。
*   **期望代价公式**：$E = \sum (depth(k_i)+1)p_i + \sum (depth(d_i)+1)q_i$。
*   **状态定义**：$e[i, j]$ 为包含键 $k_i...k_j$ 的最优树的期望代价。
*   **递归公式**：
    $$e[i, j] = \min_{i \le r \le j} \{ e[i, r-1] + e[r+1, j] + w(i, j) \}$$
    其中 $w(i, j)$ 是概率之和。
*   **计算过程**：类似于矩阵链乘法，需三层循环。
*   **复杂度**：时间 $O(n^3)$。

## 第四部分：总结与扩展
1.  **动态规划适用的两个核心性质回顾**：
    *   最优子结构。
    *   重叠子问题。
2.  **空间优化思想**：
    *   在LCS或矩阵链乘中，如果只需要求最优值而不需要求具体解，往往可以压缩空间（如LCS可压缩至两行）。
3.  **贪心法与动态规划的区别**（简要提及）：
    *   贪心法做局部最优选择，不依赖子问题解；DP依赖子问题解。
