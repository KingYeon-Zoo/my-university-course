# 《算法设计与分析：递归与分治法》复习大纲

## 第一部分：核心工具——主方法（Master Theorem）
> **对应课件：** Page 2
> **核心作用：** 用于快速求解递归方程 $T(n) = aT(n/b) + f(n)$ 的渐进复杂度。

1.  **适用形式**：
    *   $T(n) = aT(n/b) + f(n)$
    *   约束条件：$a \geq 1, b > 1$, $f(n)$ 为正的渐进函数。
2.  **三种情况（Case）**：
    *   **Case 1**：$f(n)$ 增长慢于 $n^{\log_b a}$ （即 $f(n) = O(n^{\log_b a - \epsilon})$）。
        *   **解**：$T(n) = \Theta(n^{\log_b a})$
    *   **Case 2**：$f(n)$ 与 $n^{\log_b a}$ 同阶 （即 $f(n) = \Theta(n^{\log_b a})$）。
        *   **解**：$T(n) = \Theta(n^{\log_b a} \lg n)$
    *   **Case 3**：$f(n)$ 增长快于 $n^{\log_b a}$ （即 $f(n) = \Omega(n^{\log_b a + \epsilon})$），且满足正则条件 $af(n/b) \le cf(n)$。
        *   **解**：$T(n) = \Theta(f(n))$

## 第二部分：递归（Recursion）基础
> **对应课件：** Page 3-5, 9, 42
> **核心概念：** 直接或间接调用自身的算法。

1.  **递归函数的两个要素**：
    *   **边界条件**（Base Case）：递归的出口。
    *   **递归方程**（Recursive Step）：将大问题转化为小问题。
    *   *举例*：阶乘函数、Hanoi塔问题（$T(n) = 2T(n-1) + 1 \Rightarrow T(n) = 2^n - 1$）。
2.  **递归的优缺点**：
    *   **优点**：结构清晰、可读性强、正确性易证明。
    *   **缺点**：运行效率较低、耗费堆栈空间。

## 第三部分：分治法（Divide and Conquer）理论
> **对应课件：** Page 6, 8, 10-11, 41
> **核心思想：** 大事化小，小事化了，各个击破，分而治之。

1.  **基本步骤**：
    *   **分解（Divide）**：将原问题分解为若干规模较小、相互独立、与原问题形式相同的子问题。
    *   **求解（Conquer）**：若子问题规模较小则直接求解，否则递归求解。
    *   **合并（Combine/Merge）**：将子问题的解合并为原问题的解。
2.  **适用问题的四个条件**：
    *   问题规模缩小到一定程度容易解决。
    *   具有最优子结构（可分解为相同的子问题）。
    *   **关键点**：子问题之间相互**独立**（不包含公共子问题）。
    *   分解出的子问题的解可以合并。

## 第四部分：典型算法案例分析
> 这一部分是考试和理解的重点，涵盖了从简单到复杂的应用。

### 1. 基础应用
*   **求幂计算 ($a^n$)** (Page 7)
    *   简单算法：$\Theta(n)$。
    *   分治算法：根据 $n$ 是奇数还是偶数进行二分，$T(n) = T(n/2) + \Theta(1)$，效率更高。
*   **二分查找 (Binary Search)** (Page 15-21)
    *   **分解**：检查中间元素。
    *   **求解**：递归查找左半边或右半边（子问题数 $a=1$，规模缩减 $b=2$）。
    *   **复杂度**：$T(n) = T(n/2) + \Theta(1) \Rightarrow T(n) = \Theta(\lg n)$。

### 2. 排序算法
*   **归并排序 (Merge Sort)** (Page 12-14)
    *   **分解**：数组对半切分。
    *   **求解**：递归排序两个子数组。
    *   **合并**：线性时间合并有序数组。
    *   **复杂度**：$T(n) = 2T(n/2) + \Theta(n) \Rightarrow T(n) = \Theta(n \lg n)$。
    *   *(注：课件P14还有一个特定题目是设合并时间为 $5n^2$ 的特殊情况分析)*

### 3. 搜索与优化
*   **硬币问题 (找假币)** (Page 22-24)
    *   **二分搜索**：分为2堆，$T(n) \approx \log_2 n$。
    *   **三分搜索**：分为3堆（称2堆，留1堆），最坏情况下 $T(n) \approx \log_3 n$。**三分法优于二分法**。

### 4. 组合数学问题
*   **整数划分问题** (Page 25-30)
    *   **定义**：正整数 $n$ 表示为一系列正整数之和。
    *   **模型转化**：引入最大加数 $m$，建立函数 $q(n, m)$。
    *   **递归方程**：
        *   当 $n=1$ 或 $m=1$：$q(n, m) = 1$
        *   当 $n < m$：$q(n, m) = q(n, n)$
        *   当 $n = m$：$q(n, m) = 1 + q(n, m-1)$
        *   当 $n > m$：$q(n, m) = q(n, m-1) + q(n-m, m)$ （**核心公式**：分为“不包含m”和“至少包含一个m”两种情况）。

### 5. 矩阵计算
*   **矩阵相乘 (Matrix Multiplication)** (Page 31-38)
    *   **标准算法**：$\Theta(n^3)$。
    *   **简单分治**：$T(n) = 8T(n/2) + \Theta(n^2) \Rightarrow \Theta(n^3)$（无改进）。
    *   **Strassen算法**：
        *   **核心改进**：将 $2 \times 2$ 矩阵乘法的乘法次数从 **8次减少到7次**（增加了加减法，但减少了乘法）。
        *   **复杂度**：$T(n) = 7T(n/2) + \Theta(n^2) \Rightarrow T(n) = \Theta(n^{\log_2 7}) \approx \Theta(n^{2.81})$。
        *   **现状**：理论上已有 $\Theta(n^{2.376...})$ 的算法，Strassen在 $n \ge 32$ 时优于普通算法。

### 6. VLSI 布局 (超大规模集成电路)
*   **H-树嵌入 (H-Tree Layout)** (Page 39-40)
    *   **问题**：将 $n$ 个叶子的完全二叉树以最小面积嵌入网格。
    *   **长宽分析**：$L(n) = 2L(n/4) + \Theta(1)$。
    *   **结果**：$L(n) = \Theta(\sqrt{n})$，总面积 $Area = \Theta(n)$（非常高效）。
