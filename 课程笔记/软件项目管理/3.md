# 📖 第3章 项目招标与投标 复习大纲

### 一、 项目的来源

项目主要分为两大类，需要对比掌握它们的侧重点和经费来源：

- **纵向项目**：
    
    - **定义**：由国家或省级科技主管部门或机构批准立项的科技项目 。
        
    - **特点**：偏向于理论创新与科研突破，旨在探索未知领域和研究前沿话题 。
        
    - **来源与经费**：经费主要来自政府财政计划（如国家科技部、自然基金委等），常见项目如973、863、自然基金等 。
        
- **横向项目**：
    
    - **定义**：由社会需求单位（企业、事业、政府机构等）委托的科学研究、技术咨询、技术开发、服务等项目 。
        
    - **特点**：注重项目的并行性和灵活性，强调多线程同步进行，与解决具体工作难题和技术难关紧密相关 。
        
    - **来源与经费**：经费通常来自企业或私人部门 。
        

### 二、 合同的前世今生

合同是项目招投标的最终落脚点：

- **概念**：又称契约或协议，是平等主体的自然人、法人或其他组织之间设立、变更、终止民事权利义务关系的协议 。
    
- **起源**：适应私有制的商品经济客观要求而出现，最早的文字记载可追溯至《周礼》 。
    
- **四大特点**：
    
    1. 属于民事法律行为，是当事人协商一致的产物 。
        
    2. 当事人可以是自然人、法人或其他组织 。
        
    3. 内容由当事人依法约定 。
        
    4. 依法成立的合同受法律保护，具有法律约束力 。
        

### 三、 招投标核心概念与流程

招投标是一种保证交易公平公正的机制，由三方共同参与：

- **基本概念**：交易发起方公布标的特征和条件，多方响应报价，通过评审择优选择交易主体 。其根本目的是保证交易的公平公正性 。
    
- **三方关键任务**：
    
    - **招标方（甲方）**：提供准确、清晰、完整的需求（需求定义、商务条件、验收标准），编写招标文件，选择合适的乙方并验收 。
        
    - **投标方（乙方）**：购买招标文件并进行项目分析，判断自身是否有能力满足需求，编写投标文件（建议书和报价单）并参与竞标 。
        
    - **交易中心**：发布交易信息，收集建议书，组织开标评标及结果公示 。
        

### 四、 招标文件与主要招标类型

- **招标书的四个组成部分**：
    
    1. **技术说明**：详细描述采购产品或委托项目的技术需求 。
        
    2. **商务说明**：包含合同条款及对乙方的商务条件约束 。
        
    3. **投标说明**：规定投标背景、标书格式、内容及提交时间等要求 。
        
    4. **评估标准**：对投标书进行评估和打分的依据 。
        
- **四种主要招标方式**：
    
    1. **公开招标**：在公开媒介发布公告，邀请潜在竞标者参与，公开评标确定中标者 。
        
    2. **邀请招标**：直接邀请符合条件的承包商参加，优势在于能更快找到可靠承包商 。
        
    3. **竞争性谈判**：直接邀请3家以上供应商谈判，优势是缩短准备期，使项目更快发挥作用 。
        
    4. **单一来源采购**：针对具备行业内独有资格或技术能力的单一供应商进行采购 。
        

### 五、 评标与招投标异常术语（重点易考词汇）

- **最低价中标**：报价最低者中标。优点是最大化节约资金；缺点是可能存在“看不见的代价”（如牺牲质量、售后、团队支持等），其实施需要全社会高度诚信基础 。
    
- **废标**：评标委员会依法对投标文件进行取消中标资格、不予评审的处理决定 。
    
- **流标**：投标人不足三家，或所有投标都被否决，实质上是一种招标失败 。
    
- **围标**：也称串通投标，几个投标人相互约定操纵报价，排挤他人，谋取不正当利益的手段 。
    

### 六、 项目分析与项目授权

- **乙方的项目评估维度**：技术能力、盈利能力、资源分配（人力/资金/设备）、时间合理性、风险管控 。
    
- **项目授权与项目章程**：
    
    - 签订合同标志着项目的有效开始，随后必须进行**项目授权**，以确认内部知晓并配合实施 。
        
    - **项目章程**：项目执行组织高层批准的一份书面文件，包含对项目的确认、对项目经理的授权及目标概述。签署后，项目经理正式上任 。
        

### 七、 项目经理的职责与素养

项目经理是团队的领导者，为项目的成功策划和执行负总责 。

- **核心任务（5项）**：
    
    1. **制定项目计划**：贯穿全过程，具备全盘考虑、统一计划的能力 。
        
    2. **组建团队**：根据需求选择人力资源 。
        
    3. **目标定位**：准确把握最核心的质量、工期和投资三大目标 。
        
    4. **沟通反馈**：定期向干系人汇报（周报/月报等），听取意见 。
        
    5. **项目决策与谈判**：对不确定性问题拍板决策，解决与干系人之间的矛盾冲突 。
        
- **管理心态与避坑指南**：
    
    - 不要凭经验执行不擅长的领域 。
        
    - 集体智慧很重要，但不能过度民主，该拍板时要果断 。
        
    - 不是所有需求变更都要接受，敢于拒绝客户但要以理服人 。
        
    - 提出问题时要自带解决方案 。
        
    - 保持良好、平和的心态非常重要 。
