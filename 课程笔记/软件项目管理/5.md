### 第5章 软件项目进度计划 核心复习大纲

#### 1. 进度管理与任务分解 (WBS)

项目进度管理是对时间的管理，其核心目标是在给定限制下，用最短时间、最少成本和最小风险完成工作 。

- **时间的独特性**：时间具有单向性、不可复制性和不可替代性，且不具有可加合性 。
    
- **估算并行性**：项目的规模、成本和进度的估算通常是同时进行的，并且需要根据新信息不断调整 。
    
- **任务分解结构 (WBS)**：WBS是面向可交付成果的树形结构，进一步细化了项目需求 。
    
- **工作包 (Work Package)**：WBS中最低层次的可交互成果，完成之后可以作为子项目进行提交 。
    
- **化繁为简**：分解任务符合“做正确的事”这一第一法则，将复杂问题分解至容易解决的子问题 。
    

#### 2. 任务的定义及关联关系

任务定义是面向活动的，是对WBS的进一步分解，任务之间存在相互联系与依赖关系 。

|**关联类型**|**英文简称**|**逻辑说明**|
|---|---|---|
|**完成-开始**|FS (Finish-to-Start)|任务A完成，任务B才能开始|
|**开始-开始**|SS (Start-to-Start)|任务A开始，任务B也开始|
|**完成-完成**|FF (Finish-to-Finish)|任务A完成，任务B也完成|
|**开始-完成**|SF (Start-to-Finish)|任务A开始，任务B才能完成|

#### 3. 进度管理图示工具

项目管理者需要通过各类图表来监督和控制进度。

- **甘特图 (Gantt Chart)**：又称横道图，横轴表示时间，纵轴表示项目，线条表示计划和实际完成情况 。
    
- **甘特图优势**：能直观看出任务的起止时间、计划与实际的对比、依赖关系以及关键路径 。
    
- **里程碑图**：由一系列标志性重大事件构成，代表阶段的结束或开始 。
    
- **里程碑特性**：在项目过程中不消耗资源和时间，是一个时间点，便于对计划进行动态调整 。
    
- **PDM网络图**：优先图法或单代号网络图，节点表示活动 。
    
- **ADM网络图**：箭线法或双代号网络图，箭线表示作业，节点表示事件 。
    
- **虚活动 (ADM独有)**：只表示相邻工作间的逻辑关系，不占用时间也不耗用资源，用于避免逻辑错误 。
    

#### 4. 任务历时估算

历时估算直接关系到项目总时长，估计太长会导致怠工和成本上升，太短则存在无法按时完成的风险 。人月是工作量的计量单位，即参与者工作时长的累计 。

- **定额估算法**：适合规模较小、未考虑任务间关系的项目 。公式为：$T=Q/(R\times S)$ （T为持续时间，Q为工作量，R为人力数量，S为效率） 。
    
- **经验导出模型**：基于大量历史项目数据统计得出 。通用公式为：$D=a\times E^{b}$ （D为月进度，E为人月工作量） 。
    
- **COCOMO模型**：一种具体的经验导出模型，公式形式为 $D=2.5\times E^{b}$ 。
    

#### 5. 进度计划编排与关键路径法 (CPM)

进度计划编制决定活动的起止日期，在编制完成前必须确认资源分配的可行性 。

- **时间参数**：最早开始(ES)、最晚开始(LS)、最早完成(EF)、最晚完成(LF) 。
    
- **浮动时间 (Float)**：不影响项目完成情况下任务可延迟的时间量 。
    
- **自由浮动**：不影响后置任务最早开始日期(ES)的前提下，某活动可推迟的时间 。
    
- **总浮动**：不影响项目最早完成时间的前提下，本任务可推迟的时间 。
    
- **关键路径法 (CPM)**：通过数学分析计算每个活动的单一历时，确定网络中的最长路径 。
    
- **关键路径特性**：任务的最早和最迟时间相同，无可用浮动时间；路径上的任何延迟都会导致整个项目延迟 。
    
- **正推法**：按时间顺序计算ES和EF。存在多个前置时，取其最大的EF作为本任务的ES 。
    
- **逆推法**：按逆时间顺序计算LS和LF。存在多个后置时，取其最小的LS作为本任务的LF 。
    

#### 6. 进度压缩与优化方法

当计算出的进度不满足要求时，需要进行优化，但CPM假设资源无限，实际编排需考虑资源限制 。

- **时间压缩法**：在不改变项目范围前提下缩短时间，包括应急法（赶工）和平行作业法 。
    
- **时间成本平衡**：计算单位进度压缩成本，优先压缩单位成本最低的任务 。
    
- **进度压缩因子法**：软件项目存在无法突破的极限进度 。公式：进度压缩因子 = 期望进度 / 估算进度 。压缩后的工作量 = 估算工作量 / 进度压缩因子 。
    
- **资源平衡法**：通过调节任务时间协调资源冲突，使资源平稳连续且闲置时间最小化 。
    

#### 7. 约束理论与关键链法

关键链法将人们的工作习惯（如帕金森定律）纳入考虑，在因地制宜中提高绩效 。

- **帕金森定律**：人有多少时间就会找多少事做，直到可用时间被填满（即不到最后一刻完不成工作） 。
    
- **约束理论 (TOC)**：所有现实系统都存在约束，约束决定了链条的牢固程度 。
    
- **隐蔽的安全时间**：传统估算中，个人往往会隐藏富余量，导致效率低下 。
    
- **关键链法核心思想**：剔除单个任务中的安全时间，将保留的储备时间集中加在项目末端，称为“管理预留 (Project Buffer)” 。
    
- **其他缓冲类型**：非关键链缓冲 (Feeding Buffer, FB) 和 资源缓冲 (Resource Buffer, RB) 。
