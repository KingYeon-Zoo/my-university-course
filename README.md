> 欢迎来到我的大学课程归档。这里是一个工科生在合肥工业大学（HFUT）计算机科学与技术专业三年里的脚印——包含课程资料、课堂笔记、实验代码，以及一些未曾对外言说的成长留白。

Welcome to my university course archive. This repository records my journey as a Computer Science & Technology student at HFUT (Hefei Campus). It contains coursework, lecture notes, laboratory code, and personal reflections. 

*Though materials may age and code may appear naive, the spirit of open sharing and academic inheritance will endure.*
